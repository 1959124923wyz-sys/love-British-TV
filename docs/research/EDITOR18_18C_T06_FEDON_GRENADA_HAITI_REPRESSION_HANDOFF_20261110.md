# 主编18第十九批｜T06英国格林纳达Fédon镇压、奴役法与海地革命港口战线

- 25件年份史事、30项来源（8保留原始A键+22独立来源）、28章84段完整中文稿、25个正文—Atlas互动链接。
- 主编15 T06原两个合并研究组、9条原候审ID和8个原A来源键，一个不少；1126原始crosswalk与集中ZIP不改写。
- 两组原材料分开：一组是1793/1794/1798英军占据Saint-Domingue部分港口、扶持法国保守奴隶主和终退；另一组是1795/1796 Fédon与奴役者反英国统治的起义。
- 1795年3月Fédon在Grenville与Gouyave进攻，起义方有真实俘虏与杀害英国殖民者事件；反抗运动不同参与者诉求不一。
- 英皇家海军HMS Resource岸上开炮、3月15日Lindsay从Gouyave登陆失利、3月22日海上截弹药、3月26日拦Félicité及4月2日殖民法院处决Pierre Alexandre、4月8日英国150海兵参与攻山，确属英军军事行为。
- 1796英国山地军事获胜后起义相关自由人被判刑、处决、流放及没收庄园；Hamilton据殖民档案估算约460人受审其中约100人处决。Candlin研究估算约7000名被奴役者在整次战争中丧生，两个数不可混作同一英国军队单次死亡。
- 1796年6月7日格林纳达奴役者特殊审判法；1797年5月13日锁链苦役或流放逃亡48小时可死刑法；两项原法条单独登记，不把立法直接等同人数。
- 1793英国占Jérémie、Môle-Saint-Nicolas，1794年6月占Port-au-Prince，1798年逐港撤军；不因欧洲殖民条约或一港占领给全海地涂英属色。
- 6个现代Grenville/Gouyave/Saint George's/Jérémie/Port-au-Prince地名参考年事件；19个空GPS。无未核实英国实际边界Polygon、无假军舰航线、无无证利润/战役损失。
