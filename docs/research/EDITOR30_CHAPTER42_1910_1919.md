# 第42章（1910—1919年）研究记录

## 首批　《罗拉特法》与阿姆利则屠杀：从罢市到戒严

- 1919年3月21日是第XI号法令的总督批准日期，原文见当年英印法令汇编印页26。两名医生的禁演说令、4月9日移送命令及10日执行依据战时《印度国防法》，据亨特报告印页27—34及印度国家档案馆同期材料。甘地在帕尔瓦尔被拘在不同材料记为4月9日或10日，年表取月精度。
- 亨特报告印页31—47区分4月10日铁路桥开枪、11日送葬、13日上午宣读禁会令与下午园内开火。政府依调查与阿拉哈巴德民间团体名单复核约379人死亡，9月公布的291人属先期口径。国大党1920年报告印页61—63采信约千人死亡的目击估算。两者来源与统计方式不同。伤者总数缺乏一致口径。
- 4月14日政府公报刊特别审判条例，15日在拉合尔和阿姆利则公告戒严。亨特报告印页104—106记戒严扩展及逐步解除。印页137—138记19日颁爬行令、26日撤销。古杰兰瓦拉全日11死27伤是地方官员统计，包含地面警方开枪，不能转作纯空袭伤亡。
- 10月14日西姆拉内务部委任决议第2168号，29日在德里开始调查。委员会呈文PDF第36—37页记国大党未出席拉合尔听证与12月申请重开。12月30日甘地动议据《甘地文集》，和其他资料所记国大党决议日期分开。报告在1920年刊行，留下一章。
- 园址取印度旅游部城市总体规划表第34项；海尔丁清真寺和苏丹温德门用同表地名坐标。两条陆路虚线为史料所记端点之间的关联，分别对应汽车押送与送葬。铁路桥、爬行巷、帕尔瓦尔拘押点、空袭弹着点均不填精确坐标，古杰兰瓦拉只落到城市。没有绘制历史管辖面积。
- 继承1909年仍显示的42个地点，另有10处新增地点。开普敦、彼得马里茨堡、广州、贝宁城、旧卡拉巴尔和拉特纳吉里根据新史料分段。比勒陀利亚作为南非联邦政府所在地独立列点，旧集中营不会复活。德里分开记录1911年宣布迁都、1912年旧秘书处落成和1913年立法会议。贝宁王位恢复采用1914年；资料对前王卒年有1913、1914两说，年表录入可确证的1914年葬礼报道。提婆王的流放点以1916年死亡止。
