# 主编21｜第42批：16—17世纪地图右侧多区块与悬停发光批量推广（2026-11-12）

## 用户正式批准
18世纪第41批原地图右侧多区块／悬停区块边缘发光（Draft PR #336）获得用户认可：“很好，就是这个意思。开始大批量推广吧！”

本批**不新增历史疆界、不更改史料、也不增加独立读者模式**。在第41批成果基础上，把已经成功验收的交互推广到项目既有的**1497—1599年正式地图和1600—1699年专题地图**。18世纪1700—1799使用原PR #336代码，保持不变。

## 推广对象：按原地图上当年真正显示的多边形，非整套源文件批量瞎渲染
使用在`app.js`中暴露的只读 `__historicOverlapHost.visibleAreaFeatures()`，遍历15个现有地图组中**已绘制、已通过章节与年份开关筛选的`Polygon`或`MultiPolygon`**。
- **1497—1599都铎时期**：原十多个时期的领土足迹和旧加来／布洛涅的政治控制；军事争夺、战争影响区、英军驻留、登陆、被奴役者遭强制迁移的研究参考面，及晚16世纪爱尔兰土地政策／本地抵抗等已经正式可见的区域。
- **1600—1699十七世纪**：53条英王与公司特许／殖民声索多边形（仅当原地图设为可见）、32条有史料的地区研究关系（只将其中确实作为Polygon渲染的区域纳入，研究关系线仍由原线交互负责），另保留191条17世纪地理证据点的原来查看方式。
- **1700—1799十八世纪**：现有第34—39批629区、421核心和1099时间阶段全留原状，继续直接使用`js/eighteenth-overlap-right-dossier.js`，不重复编写或覆盖。
- **纸面特许原则**：原地图未启用`showMaximalPaperCharters`时，故意隐藏的跨大陆巨型声索不会出现在右栏；与军政行政及贸易的不同性质区分。十六世纪地图中法兰西控制下的旧英属据地按当年的数据治理主体和来源展示。

### 阅读路径
1. 使用普通地图（16、17世纪不需要额外`reader`或`review`参数），点击任一现有的历史地图多边形。
2. 原地图右侧“历史档案与文献”显示**点击点命中的所有现存可见史料区域**。单个区域仍使用相同的简约信息结构。
3. 右侧每项有历史类别、时段、短标题和一句史料事实；鼠标悬停／键盘焦点指向其中某一项时，**地图对应的原有多边形边缘独立金色发光**。
4. 单击某项，固定选中态并在这一项下方展开简短说明、来源链接和边界性质；鼠标移开恢复选中轮廓。
5. 对于虚线或未填充区域，即使直接点击里面没有描边的空白处，若该位置有两块及以上**当前年份已绘制**的史料多边形，也会出现右侧目录。
6. 版图开关关闭、时间轴更换到不含该区域的年份、点击普通故事打开新档案时，高亮自动清除或更新。
7. 16、17世纪外不触发此推广器，18世纪继续由已验收的独立模块处理。

### 史料与坐标要求
- 多边形形状完全来自当前运行中已绘制的现有Leaflet历史图层，不提炼、不外推现代边界，也不创建新的bbox。
- `source_urls`原样读取；只有`source_ids`时通过app已有的`sourcesById`登记查原始URL，避免伪造链接。无可用URL只显示无独立外链。
- 与18世纪保持相同的`L.svg()`金色高亮，不修改历史图层的填充或边界。高亮只表达**当前鼠标所指的原研究对象**，不能当成实测历史边界。
- 只使用当年活跃且已经绘制的区域，兼容16世纪正式发布与17世纪逐年研究；海外集团和原住民族的自主权原史料区分完全保留。

- `js/historic-overlap-dossier-1497-1699.js` 新模块：逐点历史多边形（Polygon/MultiPolygon含洞）命中、描边发光、右侧多史料、来源链接、历史年份状态和空心重叠兜底；**无其他历史数据下载，也无修改地理源数据**。
- `index.html` 装载新模块，复用`css/eighteenth-overlap-right-dossier.css`中已经成功验收的简约详情／金色边缘发光样式。
- `scripts/test_historic_overlap_1497_1699.js` 原史料数量完整性及代码隔离静态审计。

## 审计警告与未来任务
本轮没有提高历时历史边界证据等级。部分早期地理文件只有**示意面**，它们的内部分布只能用于索引来源。若后续继续推广到更多自定义圆圈和不规则航线，应只在原历史上确有独立来源的情况下绑定UI，不得自动把圆圈半径换算为实际土地面积，也不能让事件图标变成“版图”。

保持Draft PR并以PR #336为base，不合并main。
