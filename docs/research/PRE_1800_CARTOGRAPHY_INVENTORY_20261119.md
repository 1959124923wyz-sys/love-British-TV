## 1799 年和跨年接续

1799 年共显示 307 条动态区域记录，由 171 条旧框、128 条独立轮廓和 8 条十七世纪继承形状组成。旧框中亚洲／印度洋和非洲合计 119 条。相对[上一轮十八世纪审计](18C_CARTOGRAPHY_AUDIT_20261118.md)，全世纪旧框从 538 条降至 377 条，独立轮廓记录由 85 条增至 182 条，1799 年旧框由 254 条降至 171 条。

[1799 → 1800 接续台账](../../research/continuity/1800-1819/1799_1800_SPATIAL_HANDOFF.json)仍有 38 条标成待核，其中至少两条已有公开去向。博塞茹尔／坎伯兰堡旧记录 `B36-Z003` 已有同轮廓接续 `fort-cumberland-1800`，加尔各答旧威廉堡旧记录 `B38-I-Z006` 的 1800 年去向是旧址海关点 `calcutta-old-fort-customs-1800`。贝因英堡和塞康第荷兰橙堡各有两条待核记录同址，须逐阶段核对。

## 补绘和验收顺序

1. **西非沿岸驻地先合表。** 以黄金海岸同海段各堡为一组，先对照同址、多国驻堡和跨 1800 年记录。每堡定下实际驻地、出入时间和周边贸易范围的画法，再绘有据的虚线轮廓。

2. **亚洲与北美分区校齐。** 亚洲按安汶—班达、孟买—萨尔塞特—塔那两组核对。北美查新不伦瑞克、圣约翰岛、五大湖和俄亥俄现有图形。加勒比同批核对港口、短占和岛屿分期，优先消除重复旧框。

3. **补齐十六、十七世纪的缺口总账。** 以现有控制关系表、档案地点和参考框逐组对照。爱尔兰按军政核心、司法范围和没收地核查，法国与苏格兰按城堡和旧城核查，十七世纪先核商站、殖民港和接近 1700 年的分期。

4. **每批沿同一台账验收。** 每处登记旧 ID、稳定地理对象、史料、活动或实控时间、几何依据与替代关系。逐年点验起止年、重叠档案和 1699 → 1700 或 1799 → 1800 接续。只有交接或几何已核实的条目才划定制图状态。

## 统计方法

- 1497—1699 取 [历史区域入口](../../app.js#L4186)每年已显示的 `Polygon` 和 `MultiPolygon`，按图层、记录 ID 和几何去除跨年重复。矩形以几何和自身外包矩形重合为准。固定像素的驻地、事件标记、线、现代底图和默认隐藏图层在此口径之外。

- 1700—1799 取[区域数据入口](../../js/eighteenth-overlap-right-dossier.js)与承接的十七世纪几何，排除 `superseded_by` 记录。有显式面几何的为独立轮廓，只有 `bbox` 的为旧框。统计结果的区域 ID 已与实际桌面图层逐年核对。地图上的独立主题证据层、点线与 1800 年接续台账另计。按已有研究分组归区，余下记录按图形中心分派，再对研究中已归组的跨区对象保留原组。

- 上述计数覆盖已录入的图层。未入库和只有点位的对象尚缺逐区名录，须先补全目标清单才能统计应绘轮廓总数。纸面特许、军事行动和商业网络在台账里分别标注证据类型。
