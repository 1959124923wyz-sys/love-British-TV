# 18世纪第一批深入专题｜1713—1764年阿卡迪亚大驱逐及土地转移
**状态：仅研究候审，未并入正式历史地图，未核验历史国界或完整人口损失。最后调查：2026-11-05。**

## 研究目标
追踪欧洲条约、米克马克及Wolastoqiyik政治、阿卡迪亚居民有条件效忠、英法争夺、1755驱逐政策及地方强制拘押、1758岛屿驱逐、地方抵抗和1764返乡后土地归属。**不因英方王室文本而认定本地原住民让地，不因某要塞陷落而将全地划为英国实际统治。**

## 殖民地实际管辖的缺口
- 1699→1700政治控制承接必须先核验王室/新斯科舍对皇家港/安纳波利斯皇家城的每年状态；1710皇家港易手、1713欧洲条约与Mi'kmaq土地并存，不能跳过1710年直接以1755年命令推出1755年的整块英国国土。
- 1749 Halifax、1750 Fort Edward、1755 Fort Cumberland属不同起始、不同有效期的英国军事据点；地理边界待调查时只能用现代具名遗址参考点，实测控制Polygon数为零。
- Île Saint-Jean在1758前后涉及法英欧洲政权主张，Mi'kmaq Epekwitk政治地理不可省略；到1764年的新土地授予还需逐块地籍与移民原档。
- 1654—1697旧阿卡迪亚17世纪专题与18世纪的实际驻地不可割裂。另查1755–1762各移民船航次、受载者名称、1764回迁后的农地地权档案。
