# 19世纪疆域首批制图交接

以第39章的1880年为桌面验收入口。首批覆盖加拿大、澳洲及太平洋部分岛屿、印度洋部分岛屿、塞浦路斯、牙买加和曼德勒，并标明1801年本土政治联合。新增36条有生效年份的区域记录，登记40项文献与地理来源。1880年同时可见12条。殖民行政、王室文书载明范围、受托行政、地方行政区和驻营分别标注。区域均用虚线，淡色仅作区域识别，面积字段留空。

1879年旧文件中有39个当年有效地点，1880年旧文件中有37个当年有效地点，两期旧文件没有区域面。旧点资料继续由原章节管理。新区域用同一份跨章数据按年份筛选。[1879→1880控制去向及1880—1889逐年快照](../../research/continuity/TRANSITION_1879_1880_19C_TERRITORY.json)登记了首批12个上一年要素的去向，其中11个沿用、1个更新范围。1889与1890在本批覆盖范围内使用同一组区域记录。
