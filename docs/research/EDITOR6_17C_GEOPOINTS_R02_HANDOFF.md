# 编辑6｜17世纪地图第二批：代表性地点上图准则与接续（2026-10-19）

## 一、为什么需要这次修改
第一批把来源关联的268个研究事件编入1600—1699十个年代文件，但仅48个有研究组提供的现代地点参考位置。事件清单内容远远多于图钉。编辑6允许在历史事件有明确属地、行政负责机构或影响地域时，使用**代表性地图落点**提升可访问性，前提是必须明示它不等于事件精确发生地。

第二批**仅增加位置元数据，不改变任何事件编号、史实文字、时间、来源、类别或长期ARC关系**：给原220个未落点事件中的219个配了代理坐标，保留`1610S-E011`贝奥图克人在罗素角营地调查因位置不明暂时不定位。至此268个新事件有267个可定位，连同原先另ID出版的1692年格伦科事件，合计268个17世纪地图事件落点。

## 二、三层准入和重要反例
1. **已证具体城市或堡垒**：优先使用所述历史地区/现代遗址参考（但未经测量不写成精确GPS、旧址边界）。例如1670查尔斯顿初始定居点先在Albemarle Point；1680迁到今日半岛，必须不同落点。官方参考：https://npgallery.nps.gov/AssetDetail/NRIS/69000162 。
2. **条约、全岛法律、殖民地管理、受影响地区**：优先用真正主要涉及的地区或殖民行政中心，不强制用英格兰王室所在伦敦。例如1677《中部种植地条约》用弗吉尼亚Middle Plantation/今威廉斯堡地区而非伦敦；巴巴多斯全岛法律用布里奇敦代表点；1667布雷达和约确认新荷兰处置使用纽约地区的**政策影响点**，不得据此声称条约在那里签署。
3. **无唯一地点的王室特许、全国性立法和司法裁判**：确有时代相符的政治决策中心时才用伦敦威斯敏斯特、爱丁堡等；但**1603年英苏共主不等于两国1707年前已合并**，苏格兰议会与苏格兰法令优先爱丁堡。英格兰王室在爱尔兰的行政活动也可用都柏林而非硬套伦敦。

**禁止的“宽松”**：凭法令就假定已经对某个人执行；把被劫持人运输中的死亡画作港口死亡现场；把母条约的首都代替直接可知的暴力现场；使用现代York Factory III准确遗址代替1684年旧York Fort；凭地图图钉补出任何新增殖民疆界、伤亡人数、事实控制区面积、殖民成果。

## 三、字段和界面
| 字段 | 规则 |
|---|---|
| `lat/lng` | **现代地图入口**，不得表达史实测点。地理精度另以文字说明。 |
| `geo_precision` | 新增代理点以 `representative_*` 开头，旧48点沿用原研究记录。 |
| `representative_map_point` | 新增代理点必须`true`，方便以后按精度更替与过滤。 |
| `position_type` | `administrative_policy_decision_reference` 或 `main_affected_region_or_named_locality_reference`。 |
| `geo_reference_code` | 当前84个地域/城镇代理锚点的键，允许多个不同立法共用同一个中心。 |
| `geography_label` / `geolocation_limit_zh` | 中文清楚解释位置是何地区、不能推断什么。 |
| `map_priority` | 新点在概览比例尺允许渲染，由既有聚合机制处理密集同位点。 |
| `historical_control_boundary_verified` | 全部仍为false；不因此绘制实际控制面。 |

地图鼠标提示、左侧事件日期、右侧历史详情都标注“参考点/非事件现场”；不增加顶部任何专题栏目、不改变滑条操作、不主动撰写十年介绍（待定）。
