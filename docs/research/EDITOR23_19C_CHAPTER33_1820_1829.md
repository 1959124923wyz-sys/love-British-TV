# 第33章｜河道战争与边疆改造（1820—1829）

通过 `?review19c=1&year=1826` 审查本分支。已发布的默认范围到1819年。第33章首批涵盖开普、锡兰和第一次英缅战争，重点为东印度公司发动的战争、割地与战争赔款。

## 编辑与来源

- **缅甸**。大英图书馆 IOR/H/680 供档案追查。条约正文和附加条款依据英文印本。第二条涉及阿萨姆等地的声索和曼尼普尔王位，第三、四条才是割让条款。NAM 战役叙述与馆藏题名对仰光登陆给出5月10日和11日，年表用1824年5月。战役原始题名、近代缅甸史和学术研究一并使用。
- **付款**。合同总额、各期应付、已见交付和实际撤军分开。《缅甸王令集》第113—115页载1826年5月14日筹款公函与9月21日的收付记录，第129—130页载1827年6月使节交涉，亚非学院使团日记第822—824页载第二期交付日期争议。第159页载1833年多收款结算，留作第34章的衔接证据。本章未填写无把握的累计付款或英国净收益。
- **开普**。罗兹大学 Cory 档案馆所藏 Knobel 1822年奥尔巴尼图已查阅影像，南非最高上诉法院 Salem 案第35—36段核对分地。威尔希尔上堡开工与下堡选址分记。1829年的上卡特河谷单列事件，与1819年两河下游的安排分别处理。
- **锡兰**。Sivasundaram 全文第945—952页引用英国国家档案馆公函。1822年已经可通马车、后续施工、高地劳役与通行收费作为同一治理过程记录。保留既有科伦坡、康提、加勒与亭可马里地标。

## 年末状态与地图

- 1819年的八处地图要素沿用稳定 ID。两片开普区域延续虚线。奥尔巴尼历史图用于核对地点和分地背景，当前图形沿用前一阶段聚尔费尔德区域外缘，未逐块测绘分地。
- 威尔希尔下堡用现场调查坐标。卡特河事件用政府实测河段作位置锚点。仰光从1824至1826年末为英印军驻地，1827年末转为缅甸王国港口，两状态互斥。
- 若开实兑与德林达依的土瓦、丹老用具名地点。萨尔温江及若开山脉的历史划界需要专门审核。本批没有据现代行政区绘制整块割让面。科伦坡—康提和伊洛瓦底河推进线只连接文献可证的节点，虚线显示。
- `research/continuity/1820-1829/CHAPTER33_TRANSITIONS.json` 记录治理延续、变化、出处与空间限度。年表保留英缅战争 V6 父事件 `19c-event-a-24-01`、V4 原节点 `A-24-E01` 与五个 `A-R3-25-ACTION*` 阶段。开普保留 `19c-event-b-03-01` / `B-EV-0007` 和威尔希尔堡的 `B-EV-0072` 作为来源映射。
