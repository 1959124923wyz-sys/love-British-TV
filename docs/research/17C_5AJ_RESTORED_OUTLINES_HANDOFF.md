# 第5AJ批｜有据概略轮廓的选择性恢复（2026-11-21）

## 结果与原则

5AI批在正式网页上关闭了403条旧矩形参考显示，但其中存在“历史场景仅剩点位”的退化。5AJ不撤销5AI已核验的真实海岸和研究资产，而在**已经核对地点替代、时间段与历史来源**的对象中恢复淡虚线地理上下文。所有恢复轮廓均**不填色、不计面积、不能作为军事控制线、殖民领土或古代地籍实测**。公共页面继续只显示历史事实、人物、行动地点与史料，不插入制图说明段落。

| 口径 | 数量 | 处理 |
| --- | ---: | --- |
| 5AI时记录的原参考矩形 | 403 | 历史基线不改 |
| 17世纪只换成点的旧框 | **23** | 与5AI的30个有据点同时显示，淡虚线、无填色 |

| 18世纪5Y余下不适合恢复的旧框 | **25** | 继续隐藏，包含海上广域联系、停办、不匹配或更细地理对象 |
| 本批恢复的概略参考轮廓 | **55** | 可点击，原有真实点、自然线和面均不变 |
| 原403条中仍不显示的旧矩形 | **348** | 等待逐项实测或单独基于史料重建 |

### 十七世纪23条

原始来源为：
- `data/seventeenth-century-expansive-colonial-claims-1600-1699.geojson` 中11条贸易商馆、港堡、短期占城和区域文献对象；
- `data/seventeenth-century-regional-studies-1600-1699.geojson` 中12条具名战地、港镇或地区阅读框。

两类数据均保留各自原始坐标环、时期和来源，绘图时只有**5AI替代几何全为Point且原档可追溯**的记录才回显旧研究线。5AI的圣赫勒拿、普罗维登西亚、圣基茨／尼维斯三组自然海岸替代完整保留。旧框未升级为当年的准确领土界，恢复仅改善历史活动的空间可读性。

逐ID证据、现状与边框：[`17C_5AJ_REFERENCE_RECOVERY_AUDIT.json`](17C_5AJ_REFERENCE_RECOVERY_AUDIT.json)。

### 十八世纪32条

本批只碰第5Y批已由25个具名地点接替的57条旧记录，**不恢复第5E—5AE批已有高精度历史面**。依据固定源文件 `data/eighteenth-century-editor36-5y-named-sites.json` 的57旧ID和新点档案交叉表，采用以下暂时的可视参考规则：

1. 原记录确有史料链接、时期和局部地理范围，且 `superseded_by` 精确指向相应5Y新具名点，点的逐条历史记录包含同一个旧ID。
2. 原参考范围经度跨度、纬度跨度分别不超过 **0.6°**；这一门槛仅阻止海陆广域参考框重新出现，**不是历史边界测量误差或半径**。
3. 原记录当年有效、替代具名地点当年也有效，两个条件缺一就不显示。尤其布什尔1769—1774商馆停办，不能借恢复参考框反向开启商馆。
4. 排除已经有较成熟地理复核项目的孟买、加尔各答、苏拉特、明古伦、安汶，以及普拉西、布克萨尔战地；这些地点继续用更新的测绘成果或地点表达。其他有实测局部面接替后仍须进一步关闭本批对应参考框。
5. 旧参考框无填色，细虚线，透明度低；点击仍可追溯旧史料。**经纬度框角来自旧编辑参考数据，从未被认证为历史疆域界**。

精确32条ID、时段、来源及25条排除的筛查原则见：[`data/eighteenth-century-editor44-5aj-reference-fallbacks.json`](../../data/eighteenth-century-editor44-5aj-reference-fallbacks.json)。

## 工程交接

- `app.js`：在17世纪两套源图实际渲染函数中增加仅限 point-only 5AI替代对象的参考线，不改变原档与5AI加载验证。
- `js/eighteenth-batch37-spatial.js`、`js/eighteenth-batch39-spatial.js`：增加独立 `referenceLayer`，原 `activeZoneIds` 和精细图的显示、来源、点击逻辑保持不变，日期过滤按原档＋新点双重检查。
- `scripts/test_editor44_5aj_restored_reference_outlines.js`、`scripts/test_editor44_5aj_18c_reference_fallbacks.js`：分别检查17C的23/3分组与18C的32/25筛选、时期、来源、无填色、不可计面积。
- 旧5AI、5Y、17C与18C所有历史快照保持原文不修改；全时期总台账改成区分**旧框历史退役**、**本批概略参考回显**、**真正补绘历史面**。
