## 接手顺序

- [x] **第 5K 批清理五大湖和哈德孙湾。** 先做大陆旧堡、岛上新堡、匹特堡、威尔士亲王堡、丘吉尔上游商站和坎伯兰豪斯。[第 5K 批交接](18C_GREAT_LAKES_HUDSON_BAY_HANDOFF.md)
- [x] **第 5L 批清理南部驻堡和红堡。** 星堡按实存土墙绘虚线，南部各驻点、战场及红堡按证据落点。[第 5L 批交接](18C_SOUTHERN_GARRISONS_AND_FORT_ROUGE_HANDOFF.md)
- [x] **第 5M 批清理新斯科舍港镇和斯塔滕岛。** 三港接续到 1800 年，黑人社区单列，斯塔滕岛旗杆山和海峡岸炮台各自落点。[第 5M 批交接](18C_NOVA_SCOTIA_PORTS_AND_STATEN_ISLAND_HANDOFF.md)
- [x] **第 5N 批清理波士顿及两佛罗里达。** 落图波士顿旧镇和围城工事，按 1763 与 1764 年文件绘佛罗里达省界，逐堡标出西班牙沿墨西哥湾推进。[第 5N 批交接](18C_BOSTON_AND_FLORIDA_PROVINCES_HANDOFF.md)
- [x] **第 5O 批清理北美四殖民地和圣尤斯特歇斯。** 四地按殖民县、教区和司法区分期。圣尤斯特歇斯用主堡、仓储带和锚地接替重复旧框。[第 5O 批交接](18C_ATLANTIC_PROVINCES_AND_STATIA_HANDOFF.md)
- [x] **第 5P 批补绘圣多明各三港。** 对照港镇、奥尔良炮台和西岸两处撤离地，退出 9 条旧框。[第 5P 批交接](18C_SAINT_DOMINGUE_PORTS_HANDOFF.md)
- [x] **第 5Q 批补绘马提尼克。** 本岛、罗亚尔港、圣皮埃尔、圣路易堡分别落图，波旁堡单列具名点。五处逐项接续到 1800 年。[第 5Q 批交接](18C_MARTINIQUE_1762_1802_SOURCE_NOTES.md)
- [x] **第 5R 批补绘多巴哥与圣卢西亚港堡。** 本岛海岸、两座港城、三处堡址与鸽子岛分别落图。两港、两个港防驻地与多巴哥本岛接续至 1800 年。[第 5R 批交接](18C_TOBAGO_SAINT_LUCIA_SOURCE_NOTES.md)
- [x] **第 5S 批补绘背风群岛五岛。** 落图圣基茨、尼维斯、安提瓜与巴布达，接续蒙特塞拉特旧港和四岛港堡。12 处地区或地点接续至 1800 年。[第 5S 批交接](18C_LEEWARD_ISLANDS_HARBOURS_HANDOFF.md)
- [x] **第 5T 批补绘圣文森特、格林纳达、巴哈马拿骚与百慕大圣乔治。** 核对加里富纳土地条约、巴利索岛拘留、费东起义中的港堡与拿骚两次接管。百慕大圣乔治旧港原位接入 1800 年。[第 5T 批交接](18C_VINCENT_GRENADA_NASSAU_BERMUDA_HANDOFF.md)
- [x] **第 5U 批补绘开曼、玛丽加朗特、埃格蒙特港、费拉约港与圣路易斯堡。** 加勒比及中南美、欧洲及地中海两组重点旧框已全部替换。西非圣路易斯堡原址和开曼、玛丽加朗特七处地理对象接至 1800 年。[第 5U 批交接](18C_CAYMAN_MARIE_EGMONT_ELBA_SENEGAL_HANDOFF.md)
- [x] **第 5V 批补绘西非沿岸堡址。** 清完 11 条重点旧框，补记阿诺马布新旧两堡、迪克斯科夫、詹姆斯岛、埃尔米纳、阿汉塔驻点、奥图阿姆、普兰普兰、温内巴和阿达。10 处原位接续到 1800 年。[第 5V 批交接](18C_WEST_AFRICAN_FORTS_AND_GAMBIA_HANDOFF.md)
- [x] **第 5W 批补绘亚洲／印度洋 6 条重点旧框和加拿大大河六族。** 区分港堡短期占领、商馆接管、边境交涉与六族土地文书。11 处接续到 1800 年。[第 5W 批交接](18C_ASIA_INDIAN_OCEAN_AND_GRAND_RIVER_HANDOFF.md)
- [x] **第 5X 批核完 7 条跨年待核记录。** 分绘维达和旧卡拉巴尔的政治、贸易与转运地理，核对哈德孙湾原住民主导的交易和大迪斯默尔沼泽马龙社群，按年代处置阿汉塔袭击旧框。[第 5X 批交接](18C_ATLANTIC_AND_HUDSON_HANDOFF.md)

## 更新这份交接清单

1. 从最新 `main` 读取数据。旧矩形按 `data/eighteenth-century-*.json` 中 `zones` 记录计数，记录有 `bbox`、无 `geometry`、无生效的 `superseded_by` 即计入。1799 年采用当年落在 `periods` 内的子集。用 ID 和源文件追踪去向。
2. 每批登记旧记录、新几何、起讫年份、归属、权威史料及跨年结果。近似历史边界用虚线。和约与实际交割分开，驻点、征收、贸易和控制范围按各自证据记录。为已被细图接替的记录保留原档案及替代关系。
3. 按 [AGENTS.md](../../AGENTS.md) 的检查和发布流程验收。空间审核用 `python3 scripts/audit_spatial_semantics.py --strict`，世纪接缝用 `python3 scripts/test_century_seam_handoffs.py`。桌面点验旧框退出、区域开关、史料档案和 1799 → 1800 的原位接续。
4. 在 PR 记下基线提交、所属批次、变更计数及剩余疑点。合并后核对 Pages，更新上方统计、批次链接与逐条待办。
