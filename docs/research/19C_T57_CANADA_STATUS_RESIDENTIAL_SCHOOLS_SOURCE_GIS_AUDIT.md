# T57 加拿大身份控制与寄宿学校：史料GIS审计

一章24节72段22来源24新事件10分年代GIS点。原档 T57.1 / C58 C34 C29 保留。区分1867前英属加拿大省和之后自治领法律责任。原研究时窗1842–1899；正文已核事件1846–1898；1842/1845 Bagot原卷过大不可读取，不发布精确任命或呈报日期。1859及1857–1876统计待核。

- UNB原印本1850 13&14 Vict c42 p1247 §I及1857 20 Vict c26 pp85–86 §§III–VIII截图核证；1851修法依据UNB目录及政府法史。
- TRC印73–80：1846年金承诺（非实际支付）、1847 Ryerson、两校、105牲畜及30公顷以上耕地、1855疫情及1856在校人数，均不外推；1851作为1850年代初劳动制度的年代锚，精确账期另核。
- TRC印107–109及政府身份法史、U’mista社群史：1869及1876身份规则、1884/1895仪式禁令。
- 1879 Davin、1883 Battleford、1884 Lebret、1898 Sacred Heart据TRC、NCTR及大学档案；Blue Quills历史原址未核。
- TRC印251–255、578：1884出席义务、1894法律与规章、6–16岁有条件送校、Manitoba与NWT通知差异，1920不前移；1898 Star Blanket抵制。
