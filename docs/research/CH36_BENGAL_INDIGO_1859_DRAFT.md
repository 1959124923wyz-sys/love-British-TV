# 第36章候选专题｜孟加拉靛蓝种植与拒种（研究草稿）

状态：研究中，未进入正式专题、年表或地图；基础为 main 2ac9177c2a156ac854581d31aa89ab5b5983756a。第十一批 PR #389 尚未合并，集成时须以最新主分支及该批实际状态重新核对。

## 叙事主线

从种植商以预支款和契约取得农户作物，写到农户反对未经同意在其土地上强行播种，再写巴拉萨特官员、纳迪亚专员和孟加拉政府之间对警察职责的争论。1859年地方命令传播，农户拒绝接受预支款、要求保护。续篇需接1860年的临时强制契约法、调查委员会、农户证词及后续诉讼。种植商、不同层级官员、地主及农户分别叙述，不把各方立场合并。

## 已核史料与事件种子

1. **1859年2月20日｜巴拉萨特。** 官员阿什利·伊登日后向靛蓝调查委员会证称，他就预支款与是否签约发出地方语言书面决定；杰索尔与基什纳加尔的农户取走经认证副本。有关传播及效果是伊登自己的证词。来源：[调查委员会证词，第21—22页，问题3626](https://upload.wikimedia.org/wikipedia/commons/9/91/Minutes_of_evidence_taken_before_the_Indigo_Commission_in_Calcutta_%28microform%29_%28IA_minutesofevidenc00beng%29.pdf)。
2. **1859年3月16日｜巴拉萨特辖区。** 研究者布莱尔·克林根据调查材料记述，伊登在Larmour农户请求保护后，命令米特豪特副法官安排警察防止在农户土地上强行播种。具体日期暂标待查原件；行政区域与事件地、土地具体村址不能混作同一点。[Kling, The Blue Mutiny](https://www.jstor.org/stable/j.ctv513101)；[1859年7月21日政府信转述原命令，印本第111页](https://upload.wikimedia.org/wikipedia/commons/c/c9/East_India_Indigo_Commission_%28IA_in.ernet.dli.2015.195656%29.pdf)。
3. **1859年7月21日｜孟加拉政府复函。** 政府秘书杨给纳迪亚辖区代理专员第4516号信，梳理农户对种植商Larmour准备犁地播靛蓝的申诉、伊登的警察保护令及种植商异议。该信属于具体行政争议文件；契约效力、警察阻止暴力与民事诉讼应分别核对，不写成全面解除现有契约。[同期议会印本第111页起](https://upload.wikimedia.org/wikipedia/commons/c/c9/East_India_Indigo_Commission_%28IA_in.ernet.dli.2015.195656%29.pdf)。
4. **1859年8月17日｜巴拉萨特。** 据殖民政府文件所收地方命令，法官向下级转发7月21日政府函摘录；确切签发地点及文书全文待核。[《孟加拉靛蓝种植文件》第II部分，第352—353页](https://upload.wikimedia.org/wikipedia/commons/9/91/Papers_relating_to_Indigo_Cultivation_in_Bengal_%28Selections_from_the_Records_of_the_Government_of_Bengal%2C_No._XXXIII.-Part_II%29_%28IA_dli.granth.106819%29.pdf)。
5. **1859年8月20日｜卡拉罗阿警区。** 地方副法官向警区负责人发出第1603号命令，称农户应保有土地、可种所愿作物，种植商不得凭契约以暴力强种；契约争议可诉诸民事法院。该文本存于种植商请愿所附译文；种植商将事态归咎于官员传播，是请愿者的解释。地点为警区参考地，不能直接当作发生强种的村庄坐标。[同上，第353页](https://upload.wikimedia.org/wikipedia/commons/9/91/Papers_relating_to_Indigo_Cultivation_in_Bengal_%28Selections_from_the_Records_of_the_Government_of_Bengal%2C_No._XXXIII.-Part_II%29_%28IA_dli.granth.106819%29.pdf)。
6. **1859年7月29日｜班斯巴里亚相关案件报告。** 官方印本记三宗约4月26日提出的指控：三名申诉人称White与工厂雇员掠夺住房、搬走作物；副法官7月29日称对其中四名雇员指控成立。后续司法结果及案件地点需要逐页核清，不能将指控直接写成种植商本人定罪。[议会印本第相关段落](https://upload.wikimedia.org/wikipedia/commons/c/c9/East_India_Indigo_Commission_%28IA_in.ernet.dli.2015.195656%29.pdf)。
7. **1860年6月5日｜农户证词，跨章候选。** 昌德布尔农户Hadji Mulla向委员会表示不愿再种靛蓝，即使涨价也不愿意。出处为调查证词第二卷第67页，需核原卷与具体所在同名地点后再决定定位。[印度国家教育研究与培训委员会教材，含原证词出处](https://www.ncert.nic.in/textbook/pdf/hess203.pdf)。
8. **1861年4月19日｜伦敦议会，跨章候选。** 下院辩论者称一份1859年11月29日合同要求农户及继承人以持续种植偿还预支款，并称该合同伪造、农户因此入狱；以上均须明确归于议员在1861年所述，并查对应官方文件与诉讼时间。[Hansard原始辩论](https://hansard.parliament.uk/commons/1861-04-19/debates/4b28c797-e4c4-4cf5-bda0-5d083051dd78/IndigoPlantingInBengal)。
