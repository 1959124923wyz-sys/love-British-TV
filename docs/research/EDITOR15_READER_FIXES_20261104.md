# 主编15｜专题阅读器缺陷修复（2026-11-04）

基线：已发布 PR #287。**仅修阅读器状态与异步切换，不修改历史事件、专题原文、史料或殖民地图。**

## 已确认的缺陷

1. 从不同事件打开长篇专题时，文章数据由异步fetch读取。若读者在网络请求未结束前切换到另一事件/关闭档案，旧请求回调仍可能写入档案容器，把读者的最新选择覆盖。修复：在 `HistoryStories.onEventOpened` 与 `onReset` 增加 `requestSerial` 失效令牌；原 `openStory` 的完成前一致性检查据此拒绝过期返回。
2. 已展开的「专题史事年表」在读者双击事件进入档案并点击「返回重大历史专题」后被重新折叠，破坏刚才的浏览位置与连贯性。修复：打开事件前保存年表展开状态，回到原专题后按状态重新展开，再恢复现有阅读滚动距离；新打开另一专题时重置，避免串稿。

## 验收与制图约束

扩展 `scripts/browser_editor15_story_year_index.py`：从爱尔兰征服专题打开1640/1650年代事件，双击进入原事件档案后返回并确认年表仍展开；人工延迟另一篇文章的fetch，切换原事件档案后释放旧请求，确认不会覆盖当前档案；原先1497年的16世纪专题入口照旧运行。

这两项不涉及历史事实更改，也不改变17世纪默认近四年事件动态窗口，地图政治版图仍只展示当年、无法确认的疆界继续虚线。独立分支保留完整提交记录。
