# 十八世纪动态地图审计｜1700—1799

审计底本为 2026 年 11 月 18 日主分支 `abf0e4c`（第 4B 批及华盛顿堡修订）。本次检查桌面版正式入口使用的数据、分期和地图交互，涵盖十个十年窗口以及 1699、1800 两个接缝。

**进度判断。** 十八世纪已可逐年查看。现有地图由少数成组细绘的历史区域、大量旧参考框和地点组成。安大略湖—圣劳伦斯河、魁北克法界和若干旧港城的资料足以支持局部细读。全世纪的殖民省、各岛易手、公司驻地和地方政治关系，仍缺同一尺度的底稿。收尾应优先勘定主要控制关系、交接年份和重叠图层，再补外围炮位及零散事件。

## 可直接复核的分期与重叠问题

1. **圣卢西亚 1778—1782。** `ST_LUCIA` 显示英国占领，另一活跃记录 `B39-C-Z025` 以归法法政范围为题，在同一时期显示为非英军控制。圣卢西亚政府研究报告明确记载 1778 年被英军占领、1783 年归还法国。应统一分期及源记录。 [政府报告](https://www.govt.lc/media.govt.lc/www/resources/publications/FINAL%20REPORT%2030-03-2011.pdf) · [旧加勒比区域表](../../data/eighteenth-century-b39-caribbean-1759-1763.json)
2. **萨凡纳 1778。** `B38-S-Z045` 有十二月底的夺港档案，`SAVANNAH_GARRISON` 与 `B38-S-Z046` 的持续驻城从 1779 起。按项目公历年末口径核对入城对应的首年。查尔斯敦驻城也应并查 `CHARLESTON_GARRISON` 与 `B38-S-Z034`。 [美国国家公园局历史名录，第 8 节](https://npgallery.nps.gov/GetAsset/49356d25-7cff-4d85-b6ce-092498ef7628) · [南部战役区域表](../../data/eighteenth-century-b38-south-campaign.json)
3. **亭可马里 1795。** 费雷德里克堡、奥斯滕堡的事件档案记 1795 年英军攻占，`CEYLON_TRINCOMALEE` 与 `B37-I-Z059` 的版图分期从 1796 年起。 [锡兰事件档案](../../data/stories/serial/chronology-preview-ceylon-coastal-invasion-1791-1797.json) · [锡兰旧区域表](../../data/eighteenth-century-b37-india-ocean.json)
4. **哈瓦那 1762 和海岸角 1799。** 哈瓦那已有细图，`B37-C-Z038` 与其相连点仍在。海岸角的旧几何与多批矩形须按单座要塞、年代和交易关系重查。 [哈瓦那交接](18C_HAVANA_HANDOFF.md) · [非洲区域表](../../data/eighteenth-century-b37-africa.json)
5. **冈比亚詹姆斯堡。** `GAMBIA_JAMES` 与 `B37-A-Z019` 使用长期连续分期。UNESCO 申遗档案记有 1709 年后离弃及 1710 年代拆毁和重建。按堡址状态和商站活动分别核实。 [申遗原档](https://whc.unesco.org/uploads/nominations/761rev.pdf)

## 世纪接缝

- **1699 → 1700。** 旧案有 27 条纸面范围和 17 个旧参考点。旧参考点分为 4 个同地名锚、8 个仅属旧年事件、5 个待核。七个 1700 年证据据点中，马德拉斯、加尔各答、约克堡、皇家港四处已有后续细图；孟买、本古伦、海岸角仍须细化。需把初查表和现行加载的 22 条十七世纪继承轮廓逐项对照，优先检查确实发生迁治、撤离或交接的对象。 [1700 年交接](../../research/continuity/1700-1709/HANDOFF.md)
- **1799 → 1800。** 现有台账 392 条，其中 188 条链接 154 个不同的十九世纪图形，79 条待核，125 条保留为其他史料记录。明确标明同一几何接续的 107 条，坐标和几何类型全部匹配。部分待核行已由细图接替，例如旧威廉堡 `B38-I-Z006` 和博塞茹尔堡 `B36-Z003`，还需要更新台账，故 79 是记录数。 [期末台账](../../research/continuity/1800-1819/1799_1800_SPATIAL_HANDOFF.json)

## 建议推进顺序

1. **重整全世纪底稿与已证实冲突。** 以 1700、1713、1748／1749、1763、1775、1783／1784、1799 为控制变化检查截面。逐组列出期初、关键交接、期末、主要主体、原档、实际显示记录和后继 ID。优先核圣卢西亚、亭可马里和现有重叠旧图，同时核对两个世纪接缝。 [既有路线图](18C_CARTOGRAPHY_ROADMAP.md)
2. **补完北美与加勒比主线。** 萨凡纳—查尔斯敦按一组港口推进，完成年末驻城、实际撤离、港堡与征用档案，再复核殖民省和佛罗里达、加勒比逐岛变更。北部已细绘地区优先清理重复和交接缺口。
3. **接印度洋和非洲。** 先锡兰逐堡与沿岸，再迈索尔分割、槟城及材料成熟的东印度公司驻地。西非海岸角—冈比亚—塞内冈比亚和塞拉利昂依堡、岛、实际贸易设施逐组核，随后查开普并回填接续。
4. **集中接清世纪末。** 回核澳洲流放驻地及原住民地理、跨世纪仍在用的港堡与主要界线，以及台账中待核记录的真实去向。对下一步仍欠材料的地点保留档号和可执行的调查目标。

一组完成的标准是关键阶段有档可查、同一对象的新旧表达衔接、足以支持地理判断的形状或线段已落图、桌面可以点开交接前后档案。难以确定的外廓继续用虚线，原住民和其他地方主体的地理关系随证据细化。
