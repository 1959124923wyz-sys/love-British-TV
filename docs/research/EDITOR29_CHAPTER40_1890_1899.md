# 第40章（1890—1899年）研究记录

## 首批　贝宁王廷覆亡：从通商条约到王宫财物外流

新增50条年表事件（42条可定位）、8处新增地图地点、4条可点击虚线，承接前章40处地图地点。

- 采用 V6 B-22、B-47 主记录。1899年南非战争起点按 B-54 跨章记录，1900年以后的营地见下章。
- 1892年3月26日条约读奥萨多洛印页207—208及史学研究所引英国原档 FO 403/171。菲利普斯1896年11月16日公文为 FO 403/234 第139号。伦敦延期电报依据 FO 403/248，遇袭初报据 C.8677。
- 远征按伦敦公报2526—2532页区分萨波巴分队9日抵营、11日遇袭与主力12日登陆、18日进城。19—20日焚毁与21日大火分录。阿加吉和阿沃科的旧址未核，保留年表。陆路虚线连接有据地点。
- 罗斯1897年来函与外交卷宗区分8月归城、废黜、9月审讯及放逐。9月13日开始移送，15日在乌戈通一带登船，旧卡拉巴尔抵达日未核。
- 贝宁旧王宫的地图点用当代王宫所在街区作地名参照。黄铜器与象牙件分别依据英国王室收藏、霍尼曼、大英博物馆、牛津档案和柏林馆采购链，不以个别记录外推远征总收入。
