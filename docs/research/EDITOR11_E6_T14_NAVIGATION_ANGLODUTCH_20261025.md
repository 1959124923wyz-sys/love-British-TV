# 主编续编｜E6-T14-NAV 1651—1699航海法、英荷海战及私掠制度：研究交接（2026-10-25）

## 版图与年代不可越过的边界

- 本篇是E6-T14母系列中的独立、具来源的法制与英荷战争子篇；**E6-T14母系列继续research_only**。这不能替代逐案核对每艘获委任的私掠船、船旗、判决与战利品金额，也不等于已完成欧洲及海外17世纪所有航次史料。
- 1651年共和国《航海条例》与1660年查理二世时期新《航海法》不是同一法律；1662/1663法规逐项限制特定贸易链。法定禁令不能直接推导出实收关税、海上封锁有效范围、船只损失或英方海上主权。
- 1652—1654第一次英荷战争、1665—1667第二次、1672—1674第三次的舰队成败不得表示英格兰或荷兰占有北海/海峡海面。英法联合作战不等于英国控制法国殖民地。
- 1664英方夺新阿姆斯特丹、1667布雷达外交确认、1673荷军实际夺回、1674年威斯敏斯特和约及11月实际交接：四套不同时间及法律事实。NY原住民土地、非洲裔奴役与殖民政权不能凭和约涂画一个巨大现代纽约州面。
- 1667梅德韦袭击由荷兰舰队实施；Kent政府HER及RMG的Sheerness—Upnor—Chatham地名可以定性确认，**不能**从油画或矩形推算炮击界、烧船范围、舰队航迹、永久占领地界。
- 1672 Solebay 与1673 Texel中的荷方防卫、英法联军战事和战果须保留差异，尤其RMG指出Texel没有大型舰艇确认被夺/毁。
- 1688威廉来自荷兰的远征是英格兰政局变化和英荷战略结盟背景，荷兰联省没有与英格兰融合成一个地理殖民实体。1707以前不得泛称「英国」已合并苏格兰。
- 1695年议会法在legislation.gov.uk登记为“Plantation Trade Act 1695 (7 & 8 Will 3 c 22)”；其中特定船籍与移运条文明确**1698年3月25日以后**适用。1680—90年代个别年份的“1696法”俗称及“1695标题年”需与具体条款施行分离。
- 1670英西马德里条约与1671摩根袭击巴拿马两事不能演绎为“英军征服并长期统治巴拿马”。摩根的委任、条约生效、消息传递及事后皇家责任是尚待逐件海事档案审查的议题。
- 本篇的9个新增Atlas现代坐标是**代表性参考点**：Westminster立法中心、南部北海宽域、Suffolk沿岸、Texel岛近海、Brixham现代城镇。不存在真实舰队GPS轨迹、现代海籍转历史疆界、英方实控海域或可相加航线面积。Medway一处红色虚线矩形全由人工排版，不可提供面积测量或作为任何政治控制面的替代物。
