# 19世纪疆域第四批制图交接

[地图数据](../../data/nineteenth-century-territorial-areas-batch4.geojson)增加5个区域、11条分期、33个来源记录。四批数据共144条分期。第四批均依据档案和同期测绘描线，使用现有可点击虚线和年份轴。

## 香港新界大陆

1898年6月9日清英签订《展拓香港界址专条》，租期自7月1日起，附图以海湾间一段直线表示待勘北界。条约在所列条件下保留九龙寨城内清方官员管辖及附近登岸权。1899年3月19日双方就深圳河北岸、康头山径、沙头角旧河床和高潮线等段落议定陆界。英国4月接收时遇新界村民武装抵抗，5月派兵进入寨城，12月27日又以枢密令单方面将寨城纳入殖民地管辖。清廷继续交涉。[清档《专条》](https://www.grs.gov.hk/ws/rhk/en/1890s.html) · [条约附图](https://commons.wikimedia.org/wiki/File:Map_of_The_Convention_for_the_Extension_of_Hong_Kong_Territory_in_1898_-_1.jpg) · [1899年勘界记录](https://oelawhk.lib.hku.hk/items/show/1018) · [九龙寨城史料](https://www.amo.gov.hk/filemanager/amo/common/form/140meeting/AAB-30-2009-10-Annex-B.pdf) · [12月枢密令](https://www.amo.gov.hk/filemanager/amo/common/form/140meeting/AAB-30-2009-10-Annex-D.pdf)

1899年轮廓从英国国家档案馆 MPG 1/796 的五分经纬网配准，描画深圳河旧河道及大填海之前的岸线。1898年用同一历史岸线，与两湾之间的附图直线接合。1898年九龙寨城留有凹空，参照城墙和上城的近年考古、地籍测绘图，用现存南门定向定位。1899年末显示英方单方面改变管辖后的范围。两期的南缘接续第三批1860年割让图，共用边线；大屿山、南丫岛继续由第三批各自显示。海湾、其他离岛与登岸地适用的地理范围另行核绘。[1899年原图，PDF第16页](https://cdn.nationalarchives.gov.uk/documents/hong-kong-and-the-opium-wars.pdf#page=16) · [寨城测绘图2](https://link.springer.com/article/10.1007/s10708-025-11358-w/figures/2)

## 槟榔屿对岸的威省

| 年份 | 绘制范围和法定文书 |
| --- | --- |
| 1800—1830 | 东印度公司从吉打取得沿海地带，1802年文件确认。沿W. Fletcher 1820年割让地测图描线。 |
| 1831—1868 | 1831年划界明确穆达河、吉辇河及若干内陆界标。用1820和1867年轮廓重叠部分、莫尼奥1853年测图的海岸和内线复核，保留确能落图的沿海地带。其余内陆界另核。 |
| 1869—1873 | 1867年殖民地测图标有重划边界，1868年签订的协议未获英方批准。1869年5月6日英暹条约取代该文本，第三条为本图采用界线的依据。 |
| 1874—1899 | 《邦咯条约》第十二条包括吉辇河以南、向该河汇流的土地。根据皇家亚洲学会1898年图勾绘，用1892年霹雳测图确认南界。 |

## 马六甲与天定

- 马六甲从1833年落图。1832年英国远征占领塔波、改组南宁，1833年英方分别与林茂和柔叻订界。纽博尔德1839年调查给出林吉河、吉双河及内陆地名序列。早期富拉顿图的内陆位置与同期地名偏差较大，改以1898年皇家亚洲学会实测线为地理底本，按1833年文书和1839年地名回核早期概略范围。1858年与1867年分别改变管治档案。1825年荷英交割和1832年以前的南宁控制过程仍保留在年表与既有专题，早期完整范围待查。[马来西亚自然资源主管部门关于两份1833年定界文件的记录](https://www.nres.gov.my/PustakaMedia/Kenyataan%20Media/Press%20Statement%20YBM%20KATS%20Majlis%20Perjanjian%20Sempadan%20Melaka-N9.pdf) · [1839年调查卷一](https://upload.wikimedia.org/wikipedia/commons/3/32/Political_and_Statistical_Account_of_the_British_Settlements_in_the_Straits_of_Malacca_-_Viz._Pinang%2C_Malacca%2C_and_Singapore%2C_in_2_Vols.Vol-1_%28IA_dli.granth.36652%29.pdf) · [1886年测图档案 M.47](https://www.arkib.gov.my/images/penerbitan/edaran%20awam/puspawangsa/Puspawangsa%20Bil.1.2022.pdf)
- 邦咯和邦咯劳勿两岛按1874年第十一条修订后的天定行政阶段绘制。天定大陆直接描摹1898年地图的北部、南部陆地及州界，河口水面留出。现图所见最北界的确定年份待查，大陆形状从有这幅地图证明的1898年起显示。[《邦咯条约》](https://eprints.usm.my/4144/1/HSM_313_-_DOKUMEN-DOKUMEN_DALAM_SEJARAH_MALAYSIA_I_OKT_04.pdf) · [霹雳土地与矿务局](https://ptg.perak.gov.my/portal/en/web/manjung/info-ringkas) · [1898年地图原档](https://gallica.bnf.fr/ark:/12148/btv1b53029747c)

马六甲和天定的像素定位来自各自图段周边四个整度经纬交点，以双线性变换配准。沿原图的海岸、河界、实测界与未测界描线，地图只使用迹线几何。原图为法国国家图书馆 GE C-2635，公共领域；扫描件链接可用于重绘与复核。[完整扫描](https://commons.wikimedia.org/wiki/File:A_Map_of_Malay_peninsula_compiled_by_and_published_for_the_straits_branch_of_the_royal_asiatic_Society,_Singapore_1898_-_btv1b53029747c.jpg)

## 时间承接与验证

[1859→1860台账](../../research/continuity/TRANSITION_1859_1860_19C_TERRITORY.json)更新威省及马六甲。1868→1869威省更换东界，1873→1874承接吉辇河南侧。1897→1898增加新界初期租借和天定大陆，1898→1899更换新界北界、更新九龙寨城在英方单方面变更后的范围。第四批末年五个稳定范围在1900年继续存在，其中寨城管辖争议延续；20世纪独立图层和控制边线仍待续画。

桌面测试检查威省四期、马六甲三期、新界1898/1899切换、九龙寨城覆盖变化及1899原图链接。GDAL/OGR检查环、狭口与多边形有效性，新界与1860年割让区共边、内部无重叠。
