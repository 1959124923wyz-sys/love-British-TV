# 第35章｜战后条约与殖民边疆（1840—1849）

首批随第34章向后衔接。桌面入口 `?review19c=1&year=1840`。新增八篇专题、59条年表事件、八条新空间记录和两组行动虚线；1840年代共有49条空间记录（其中41条继承自1839年末），前章台账中的58项本章均有去向。

## 年末地图与史料

| 专题 | 关键证据及制图取舍 |
| --- | --- |
| 第一次鸦片战争 | 《南京条约》以 FO 93/23/1b 手稿和完整条约本核对，签署日8月29日，拒用陆军博物馆页面的17日。五月广州赎城款与条约第IV—VII条分开，前者不是条约赔款的一个付款期；二千一百万银元是条约规定额，实际付款档案继续核对。定海1841年先撤后再占，1846年先议约再交接，保留独立事件和年度末变化。上环采用古物古迹办事处所指遗址。港岛条约范围已核，历史岛岸配准未完成，本批仅落具名点。镇海落招宝山，三元里落誓师的古庙，不误作牛栏岗战地。 |
| 英阿战争与卡拉特 | 印度事务档案、英国陆军博物馆和《伊朗百科全书》交叉核对。波洛克抵达喀布尔日期有15日、16日之异，年表采用月份。恰尔恰塔集市毁坏独立保留；1842年9月再次进入和10月退出不画全年英军驻地。甘达马克用同名村地名锚点，贾拉拉巴德是撤退目标，连线不意味着整支队伍抵达。卡拉特1840年反攻和英军再入各立节点，1841年汗王获承认，1842年英方撤离。 |
| 纽波特三人 | 蒙茅斯地方档案、议会请愿、HO 11/12名册及澳大利亚传记核对。开庭归1839年，宣判、求赦、改判和抵达归1840年，1841年请愿另列。三个工作地点保留正文，等待各自设施和日期核查。 |
| 怀巴莱纳与瓦杰马普 | 怀巴莱纳采用原住民土地委员会、澳大利亚国家博物馆与1846年请愿研究，人数在馆载资料中有47和49之异，本批不列人数。怀巴莱纳于1847年关闭，普塔利纳接替。瓦杰马普1849年暂闭，依据西澳档案和岛管理局资料，1855年复开交后章。 |
| 亚丁、阿萨姆杜阿尔 | Aitchison条约集分记亚丁反攻、协议与津贴。1843年亚丁协议的双方义务不扩大为对拉赫季的领土控制。阿萨姆七处杜阿尔的接管与达旺所属卡里亚帕拉1844年书面协议分开。1841年布里古马由既有范围转为具名点，待核管理范围后再绘。 |
| 兰利堡与俄勒冈分界 | 加拿大公园管理局资料区分1839年迁建和1840年火灾后重建。温哥华堡1846年进入美国一侧但仍经营，1849年美军驻地与公司贸易并存。温哥华岛1849年授地另待按原文编入。 |
