# 17世纪殖民地图重叠减负与专题标题层级｜2026-11-02

## 用户反馈与执行原则

用户1699年局部截图显示，马萨诸塞湾省、纽约、新泽西、特拉华、马里兰、宾夕法尼亚等在同一片地区出现大量淡紫/金色虚线互相压叠；相邻图斑的多次透明叠色容易在视觉上夸张英国统治力度。同一页面的事件列表、地图悬浮提示、专题页标题和正文链接标题偏长，首次阅读无法抓住主体和行为。

原则：**不改变任何原始历史地名、事件时间、史料文字、区间外廓或多边形面积**。只做“概览→聚焦→详细来源”三个信息层级；短标题是独立编辑展示层，不是历史事实的新表述或替代原始文章标题。

## 一、重叠殖民地的默认总览与按需高亮

- 默认「殖民区域概览」保留已核准的53块史料宽取参考面的点面交互，但单块填充透明度统一降至 **0.055**，独立虚线改为细 .85px / opacity .22，叠加后不会形成截图中的显著网格或深色交错。
- 在图例新增「显示各殖民地详细边界」复选框。**默认不选中**；使用者研究特定区块时开启，恢复各类别着色和约2.15px虚线轮廓。
- 每块有效的殖民范围在鼠标悬停时暂时显著加亮（线宽2.8px），移开恢复；点击原有位置和目录进入相关历史档案、来源以及上一轮完成的竞争声索切换列表。大区的点击优先级和历史控制图层优先级不变。
- 上一轮屏蔽的7块跨大陆巨型纸面特许保持默认关闭且无填色；本次细节开关不能让那些巨大外廓变成实控版图。
- 不使用 GIS `union` 合并多个殖民政府疆界。它们互相重叠可能反映**相互竞争的历史特许、未实测线和原住民土地主权**，不能为了制图干净而伪装成一个已经实际控制的统一政区。

## 二、统一的短标题体系，保留完整历史标题

原有10个 `data/atlas-1600-1609.json` 至 `data/atlas-1690-1699.json` 文件合计 **514条**历史事件。其标题长度（Unicode JS码单元）中位数约21，超过28字的约65条。17世纪正式发表并获得编辑批准的独立长篇专题共 **29篇**。

- 新增 `js/editorial-headlines-17c.js` 纯前端编辑映射：以已发布稳定 `event.id` 人工编写65条左右的准确短标题（例如“1699年牙买加法令授权召集追捕马龙等逃亡或抵抗者的武装队伍”→“牙买加法令组建追捕马龙队伍”）；对尚未人工重写的其余事件，只删除已在年份小标签中展示的**冗余开头公历年份**，不机械截断语义、删除历史参与主体或改写正文。
- 同一文件为**全部29篇**正式17世纪专题逐一编写短标题。例如原题“1604—1699年阿卡迪亚：米克马克土地、苏格兰殖民与英法皇家港争夺”以“阿卡迪亚多方殖民争夺”展示。
- `app.js` 中的事件卡片、地图悬浮与散点聚合列表、历史区域关联事件及事件档案主标题接入这一套短标题。事件完整原题仍存 `item.name` 并在档案“完整事件名称”折叠区可见，卡片保留完整名称的无障碍标识。
- `js/history-stories.js` 中的专题入口、相邻专题推荐、专题正文主标题、章节目录、章节小标题以及正文的超长事件链接使用相同编辑标题或谨慎的第一语义分句提炼。专题原始完整标题放入“完整专题题名”可展开说明，章节原始完整标题保留在标题提示信息；专题正文中对于史料辨析的详细叙述、历史事件ID和原始时间字段全部保留。
- 所有16世纪历史事件维持原名；除这两个显示用的JS文件与页面脚本链接外不改动原始故事JSON、事件JSON，也不对历史日期/坐标做新的断言。
- 增加Node回归验证短标题非空、65条左右超长事件获得足够精简、29篇正式专题有短标题，16世纪旧事件名不变；地图测试同时验证默认简洁边界及手动详图模式仍然能突出单块。

## 质量与后续待办

- 若史学编辑认为某一短标题遮蔽了重要的**争议、不确定性、主体或法律性质**，应在映射中调整，该短标题不得直接写回原始事实字段。

- 页面仍不提供历史实控面积：`boundary_verified:false`、`actual_military_control_polygon:false`、`area_sqkm:null` 元数据持续不变。
