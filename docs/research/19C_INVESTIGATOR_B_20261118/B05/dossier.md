# B05 桑塔尔起义与1857年后的英方报复

四个子案已存在候审专题。桑塔尔重点是达明伊科开垦、放贷与官差申诉、村级动员、焚村和特别法。德里以威尔逊9月军函及后续出入城文件串联接管红堡、驱逐穆斯林、选择性恢复通行和财产登记。两组分别按民事命令及实际军队行动登记。［B05-S01、S02、S03］

坎普尔的萨蒂乔拉渡口、比比加尔杀戮和英方重占后的报复有三条责任链。6月29日尼尔对里诺的行军处置与7月25日尼尔对比比加尔的命令是两份不同命令，延续至个别处决和财物追缴。阿杰纳拉的八月处决由阿姆利则殖民官 Frederic Cooper 下令；285和282在其后件叙述中并存，公开叙事多用237枪杀、45拘押死亡。［B05-S04–S08］
