# B02 第二次鸦片战争与圆明园

广州段分英国西摩炮击、商馆大火与英法联合进攻。大沽分别为1858年攻占、1859年英方试图进河遭击退、1860年英法联军再次进攻。1860年北京段把圆明园进入及抢掠、英方毁园照会、英军焚园、安定门接收、签约分别存证。［旧档广州与北京篇；B02-S05；B02-S06］

克里洛克（Henry Hope Crealock）呈献的乾隆时期如意具有王室收藏编号 RCIN 70708。王室专题叙述把该件接在英方组织的战利品出售之后，馆藏说明还保留早期来源的表述。对应地点为圆明园、呈献地待核、英国王室收藏。购得日期、竞得价和登记单待查。［B02-S04］

北京续约英方八百万两包含二百万两广州英商补偿与六百万两战争费用。英方要求交给被拘遇害人员家属的三十万两在何伯记述中另有条目。沙面已垫额从广州首期扣除，随后从开放各口海关总收取五分之一。三类款项与海关逐季交割凭据对照。［B02-S02；B02-S06］
