# B10 马来半岛、海峡殖民地与婆罗洲

南宁（Naning，今马六甲一带）优先查土地制度解释、十分之一征收要求、1831与1832两次出兵和实际任命。殖民当局称有征税权，多尔·赛义德（Dol Said）维护地方自治；1832夺塔波、10月殖民官任命辖区首领、1834本人降服分开。［B10-S01–S02］

霹雳1874年邦咯协定同时处理苏丹继承、驻扎官、行政建议与税务。霹雳地方史和州博物馆分别支持签约与驻扎官 Birch 后续在 Pasir Salak 被杀。执行上，先检税权从谁手中移出、何处任命征收者和最早征到多少；再对英方干预、地方首领回应及增派军队。［B10-S03–S05］

砂拉越古晋的 Brooke 政权、文莱苏丹让渡和英国王室取得纳闽属不同主体和文书。1846年12月18日纳闽割让条约有附属小岛措辞，驶抵、升旗和总督到任分录。煤矿特许、财政拨款与实际收入分别查。［B10-S06–S08］
