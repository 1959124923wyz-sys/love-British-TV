# 第34章｜废奴、驱逐与边疆重组（1830—1839）

首批预览从 `?review19c=1&year=1830` 进入。覆盖塔斯马尼亚围捕和强制迁移、牙买加起义与废奴、开普第六次边疆战争、不丹边境交涉。乔治敦、锡兰、丹那沙林和哈德孙湾公司的事件同时服务跨年代衔接。

## 第33章末的接续

`research/continuity/1830-1839/CHAPTER34_TRANSITIONS.json` 逐项对照第33章全部28个地图要素。之前结束的仰光英印军驻地、温哥华堡高地旧址、格什姆镇临时英军驻地未重新绘制。持续据点沿用原稳定 ID 和定位。英属若开和丹那沙林、缅甸王国的仰光、阿散蒂库马西、巴赛杜据点与哈德孙湾公司经营点保留各自主体。读者界面按年显示来源与当地历史，不显示地图编审备注。

- **布里古马。** 沿用彭伯顿史图虚线几何，1830—1833年末显示公司暂扣，1834年起显示不丹方面恢复治理。两种状态没有重叠。班斯卡暂扣另立1836年事件；彭伯顿使团组沿用 V6 起年1837，抵达普纳卡的单条事件按史料列于1838年4月。
- **开普。** 聚尔费尔德与奥尔巴尼继续显示。原大鱼河—凯斯卡马河下游安排在1835年战争及设省时改变。威尔希尔下堡在战争初期一度撤出，1836年短暂回驻后永久撤离，所以年度据点显示到1834年，1836年变化以事件展示。威廉王城和考克斯堡保留1835年驻地标识。省的声称范围、1836年撤军与1837年正式放弃主权声称分别记录。后继条约的土地安排继续核验。
- **北美和圭亚那。** 兰利堡德比河段旧址显示至1838年，上游新址从1839年开始。贸易牌照日期按1859年官方文书所引1838年5月30日，保留 V6 原始记录的异文。乔治敦位置持续，1831年随德梅拉拉、埃塞奎博和伯比斯合并切换行政名称。
- **亚洲。** 锡兰沿用四处治理据点，1833年改革由斯里兰卡国家档案馆校验。土瓦和丹老的1830年反抗分别列事件，年末仍显示英方治理。基图尔的1830年规例用于核对接管后的行政延续，城堡内部驻防情况另核。

## 史料与地理取舍

- **塔斯马尼亚。** 澳洲国家博物馆藏弗兰克兰1831年刊印行动图与1830年报载命令提供史料。虚线连接公告指名的滑铁卢角与埃科湖，表示初期部署参照；队伍轨迹和原住民迁移航迹不据此推导。怀巴莱纳用塞特尔门特角的历史地名点，泻湖营地与小马瑟尔罗湾交涉留在年表，避免借后来的安置点定位。1831年迁移、1833年设施设立、1835年曼纳拉根纳去世分记。1847年牡蛎湾接续保留在交接表。
- **牙买加。** 镇压原件采用英国国家档案馆 CO 137/181，肯辛顿庄园起火依据牙买加官方人物资料与国家图书馆馆藏索引。蒙特哥贝以夏普广场一带标记，西班牙镇用城市定位。1833年法案以法令原文为准，1834年实施与1838年结束学徒制用牙买加公告和西班牙镇地方史。二千万英镑为法定拨款，1835年起的支付另采英格兰银行研究。肯辛顿庄园遗址仍待旧图复核。
- **待续。** 本批覆盖起始于1830年代的 V6 主记录中八组。南宁战争、鸦片战争前夜、澳大利亚其他屠杀事件、英阿战争和印度土地起义等仍在后续制作范围。
