# 阿卡迪亚驱逐与牙买加奴役法规，原编号核对

本批新增两篇研究试阅、13条年表事件，其中10条可定位。阿卡迪亚与牙买加共23条旧候选由归并组关联推进到原编号级核对。315条优先候选中，299条已具原编号对应，16条尚停在归并组级。

- 原E18A5-ACD-OCT8-EMBARK的两个名字是船长。温斯洛10月8日日记记约80户合计，丘奇的船由10月13日航令核为“豹”号，米尔伯里的船由租船账第292页核为“伊丽莎白”号。9月10日230名男子被押上船、10月8日约80户家庭、各日名册及后期到港数字分别保留。10月23日表列两船178和186，另有后期记录把“伊丽莎白”号记为242。新斯科舍劳伦斯堡、霍顿登陆地及马里兰安纳波利斯港的地点分别核定。埃贝尔住宅在史料不足时只写地点范围。
- 1755年布鲁萨尔的6月8日行动可由菲德蒙与蒙克顿日记互证。6月16日袭营以蒙克顿与《加拿大人物传》对读。会见日期以英方军务日记的20日立档，另保留传记的18日。9月3日珀蒂科迪亚克交战没有据此给布鲁萨尔安排指挥身份。10月1日劳伦斯堡逃脱人数据蒙克顿，布鲁萨尔在逃脱者中据加拿大公园管理局。
- 马龙条约的C-A05-001是年度条约合并记录，分别回链到卡乔与夸奥的两份档案。1769年搜捕报酬原印本第155–157页旁注12月23日通过，明载1770年3月1日生效。1788年1月10日马龙镇法与年末整编奴役法独立。后者的下议会日期11月6日、参议会12月5日、副总督12月6日，翌年1月1日生效。法定刑罚的设定与已经执行的裁决分别记述。
