# 十九世纪殖民活动专题调查与主编交接

## 主编选题汇总

本轮先推进莫兰特湾戒严、孟加拉靛蓝抗争、怀卡托战争与土地没收。三题分别有皇家调查、农民证词和地方公报等可复查材料，也能在地图上呈现当地人的行动及其后果。牙买加废奴赔偿、鸦片战争、贝宁、迈奥尔溪已有候审稿，本轮所获材料用于核账、补证与修订。保留英属圭亚那糖园枪击为下一篇短专题候选。

| 次序与专题 | 主编处理建议 | 最先写入的证据与地点 |
| --- | --- | --- |
| 1 莫兰特湾戒严 1865–1866 | 查重后新立。以地方请愿、法院冲突、戒严和调查为一条主线 | 斯托尼古特、莫兰特湾法院、金斯敦与押送；皇家委员会统计 |
| 2 孟加拉靛蓝抗争 1859–1860 | 查重后新立。以拒种、合同执行与调查听证为一条主线 | 第 XI 号法、具名农民证言、加尔各答与克里希纳纳加尔听证 |
| 3 怀卡托战争与没收 1863–1865 | 建立过程专题，接入仓库现有1865年没收面 | 芒阿塔菲里溪越界、兰吉里里和奥拉考、各批敕令的生效节点 |
| 4 圭亚那糖园枪击 1872 | 新增德文郡堡种植园个案，接已有契约劳工文章 | 庄园罢工与开枪、死者姓名、殖民政府报告 |
| 补证 牙买加废奴赔偿，鸦片战争，贝宁 | 沿用旧专题。优先补具体赔偿案、财政分母、器物的独立流转链 | 春园种植园、加尔各答拍卖至虎门案、贝宁城与可证入藏地 |
| 补证 迈奥尔溪与塔斯马尼亚黑线 | 沿用旧专题，增补原始证词及当地社群材料 | 牧场与悉尼审判单列；黑线部署和后续迁移分年 |

选题以具名地点、可追责主体、起止时点、受害人和当地抗争为入口。能直接证明的利益包括赔偿领取、专卖毛收入、种植园合同和王室没收；关于工业化或英国崛起的宏观因果，须另有统计或追踪证据。三卷覆盖加勒比、南亚和东亚、非洲和大洋洲，并核列加拿大与英国本土的后续选题。北非可续查 1882 年亚历山大港炮击，南部非洲可续查 1878–1879 年对祖鲁王国的最后通牒和入侵。 [英国议会的亚历山大港炮击电报](https://hansard.parliament.uk/Commons/1882-07-11/debates/9ed1ec38-c86a-4bb7-af3a-a15a89d354f0/Questions) · [英国国家陆军博物馆的祖鲁战争档案](https://www.nam.ac.uk/explore/zulu-war)

## 地图与史料交接

- 查重以仓库母题和相同史事、年份、地点为单位。分期沿同一地理对象延续。牙买加旧稿 `E19-JAMAICA-BAPTIST-WAR-EMANCIPATION`，鸦片旧稿 `E19-OPIUM-TRADE-CRISIS` 与 `E19-OPIUM-WAR-TREATY-PORTS`，贝宁旧稿 `E19-BENIN-PALACE-LOOTING`。怀卡托沿用 `waikato-1865-raupatu`。仓库基线为主分支提交 `24958d186289a4663e00ab8ef9b76c6ae10b23ac`。 [母题索引](https://github.com/1959124923wyz-sys/love-British-TV/blob/24958d186289a4663e00ab8ef9b76c6ae10b23ac/data/stories/serial/index.json) · [怀卡托疆域数据](https://github.com/1959124923wyz-sys/love-British-TV/blob/24958d186289a4663e00ab8ef9b76c6ae10b23ac/data/nineteenth-century-territorial-areas-batch6.geojson)
- 逐条绑定日期、行动者、受影响者、地点和来源。原件、当事人证言、转录、档案目录与学术解释分别登记。区分法令、文书签署、执行与交割。城镇可作有根据的地点参照，尚未消歧的地名留空。
- 地点、行动次序、贸易流动及土地范围分别表达。有依据而边线未定的范围用虚线，研究轮廓不进入面积统计。沿用项目正式事件 ID 和文章内跳转机制；新事件先去重登记，再安排桌面跨年切换与回跳验证。 [项目空间叙事规范](https://github.com/1959124923wyz-sys/love-British-TV/blob/24958d186289a4663e00ab8ef9b76c6ae10b23ac/docs/HISTORICAL_SPATIAL_NARRATIVE_STANDARD.md)
