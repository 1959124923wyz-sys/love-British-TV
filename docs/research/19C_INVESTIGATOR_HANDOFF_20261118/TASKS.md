# 十九世纪三个调查员的任务总表

研究范围为1800—1899年。A负责加勒比、美洲与不列颠及爱尔兰，C单独负责加拿大。B负责亚洲及印度招工端。C负责非洲、大洋洲、加拿大。每组按编号顺序推进。每次完成一批便更新本组累计 ZIP，最后三组合入一份总 ZIP 交总编。既有专题先核具体缺档，以相同地点、日期、行动和来源核查重复记录。

| 编号 | 调查专题 | 重点查什么 |
| --- | --- | --- |
| A01 | 牙买加莫兰特湾戒严 | 从村社请愿、法院冲突查到戒严令、押送、军法庭、焚村、伤亡和议会问责。核皇家委员会报告、受害者姓名、当年萨里郡边界和金斯敦例外。 |
| A02 | 牙买加废奴赔偿与学徒制 | 查1831–32年停工起义、1833年法令和1834–38年劳役。以春园种植园追名册、赔偿申请、裁定、付款和最终受益人，把英国财政安排与个案连上。 |
| A03 | 英属圭亚那糖园契约劳工 | 查1838年船册和到港后分配、庄园工资与罚则、1871年调查，深挖1872年德文郡堡罢工和枪击，逐一核五名死者及总督初报。 |
| A04 | 特立尼达契约劳工与霍赛节枪击 | 查1845年到港、庄园配工与移民基金，另列1884年圣费尔南多游行限制、警察布控、开火及伤亡名单。 |
| A05 | 巴巴多斯、德梅拉拉与巴哈马的种植园反抗 | 分查1816年布萨、1823年德梅拉拉和1830年埃克苏马事件。追停工或迁移命令、军事处置、审判、流放和具名庄园。 |
| A06 | 牙买加马龙社群跨洋流放 | 查十九世纪初当事人在新斯科舍的处境和转往塞拉利昂的名单、人数、船只与航次。前情接既有十八世纪专题。 |
| A07 | 英属洪都拉斯与莫斯基托海岸 | 查伐木劳役及土地登记，另查格雷敦与河口的军舰行动、条约、地方政体和实际驻点。 |
| A08 | 爱尔兰征税、饥荒与驱逐 | 分查反什一税冲突和大饥荒时期。一至两个教区对读征收或驱逐令、救济变化、粮价、济贫院及地方死亡与移民记录。 |
| A09 | 苏格兰高地清场 | 挑选有完整记录的庄园和村庄，查租约、驱逐令、执行者、房屋毁坏、村民去向及庄园收益。 |
| A10 | 英国本土工人与殖民流放 | 查托尔普德尔结社案、纽波特镇压与流放。纺织与煤矿选具名工厂或矿井查童工、工资、事故和监察。跨海部分接 C。 |
| A11 | 南大西洋的军事与商业施压 | 分查1833年福克兰群岛／马尔维纳斯群岛军政交接和拉普拉塔河英法封锁。对核当事各方档案、实际撤离与留居、扣船和封锁地点。 |
| B01 | 印度鸦片财政与第一次鸦片战争 | 分查孟加拉专卖、马尔瓦过境税、私人输运和英国出兵。核1830年代财政分母、虎门箱袋差异、舟山进退、条约及实际开埠。 |
| B02 | 第二次鸦片战争与圆明园 | 分查广州炮击、大沽与北京战事、圆明园掠夺和焚烧。追英法各自责任、拍卖账、具名物件流向、割地及赔款。 |
| B03 | 孟加拉靛蓝抗争 | 查定价、预付款、强制种植和拒种。优先核马古拉请愿、具名受害者、1860年法令和委员会证词，回查厂场、村庄与听证地点。 |
| B04 | 印度饥荒期间的救济政策 | 以1876–78年一两个有账可查的地区入手，逐月核救济工价、领粮、粮价、运输、疾病和死亡口径，查具体命令及执行。 |
| B05 | 桑塔尔起义与1857年后的英方报复 | 按地区分案。桑塔尔查地租、放贷、戒严和焚村。德里、坎普尔、阿杰纳拉查命令、处决、驱逐和没收，与既有专题逐条去重。 |
| B06 | 信德、旁遮普与阿瓦德 | 分查1840–50年代各地吞并，追战费或战利品账、条约、王室财产、地契与税收变更。阿瓦德兼并与1857年后土地处分分年登记。 |
| B07 | 阿萨姆茶园与契约劳工 | 查土地授予、招工和运送、逃离与处罚、工资和监察。将辛波或卡西抵抗落到能核实的驻点及具体行动。 |
| B08 | 锡兰夺地、镇压和咖啡园 | 核康提占领与乌沃起义、土地法与1848年马特莱起义，追咖啡园地契、南印度劳工、工资及欠薪。 |
| B09 | 三次英缅战争 | 分查割地、赔款、港口接管、柚木争端、迁村和矿权。逐次区别战争行动、法令吞并和实际交接。 |
| B10 | 马来半岛、海峡殖民地与婆罗洲 | 查南宁征税战争、霹雳邦咯协定及后续干预、砂拉越与纳闽。逐案追地方权力关系、英方驻点、武力行动和税矿账。 |
| B11 | 阿富汗、亚丁与波斯湾 | 分查英阿战争与撤离、亚丁攻占、湾区海上远征。查毁城毁船、赔偿与港口驻守，明示当地政体和协议的实际范围。 |
| B12 | 印度出境招工 | 查招工商、合同和招募费用、加尔各答或孟买登记、登船名单及死亡。加勒比到港交 A，毛里求斯和斐济到港交 C，以船名及航次互认。 |
| C01 | 新西兰怀卡托战争与没收 | 追越界、兰吉里里、兰吉奥瓦希亚与奥拉考，核命令、毛利方证词、伤亡和撤离。按公告补齐既有1865年没收图层的分批地块与返授材料。 |

| C08 | 开普、祖鲁王国与南部非洲矿地 | 分查科萨战争的毁粮赶牲畜、祖鲁战争及后续土地政治、1890年代特许公司扩张、1899年布尔战争开端。查具体村庄、敕令、劳工与矿权档案。 |

## 累计 ZIP 的写法

- 每组建一个工作目录，按任务编号建子目录。每题存调查笔记、事件年表、史料登记和可保存的档案或地图。收录网页时登记机构、作者、题名、档号或页码、链接和查阅深度。只有目录或摘要时写清所见层级。
- 事件表至少记录日期、旧今地名、实施主体、受影响人、当地反应、后果、数字口径和对应来源。能核实的地点附来源。边界有疑问标出依据及不确定段，留作虚线研究层。无法定位的事件保留文字。
- 每一批更新本组进度表，记录已核、待核、新增或订正和对应的现有专题。把旧批与新批一并保存，重打包为同一份本组累计 ZIP。
- 三个分身若在各自对话工作，最后保留 `19C-A.zip`、`19C-B.zip`、`19C-C.zip` 各自最新版，三份一起放进 `19C-research.zip`。已有共享目录时直接将 A、B、C 三个目录打进总包。
