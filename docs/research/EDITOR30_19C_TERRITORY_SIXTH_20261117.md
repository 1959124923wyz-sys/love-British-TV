# 19世纪疆域第六批制图交接

[第六批地图数据](../../data/nineteenth-century-territorial-areas-batch6.geojson)新增8组区域、13条年度分期，共37个来源条目。所有新几何接入既有虚线区域、事件联动和年份轴。六批疆域数据合计174条分期。

## 亚丁、曼德海峡和阿拉伯海

| 年份 | 区域及档案 |
| --- | --- |
| 1839、1858 | 1839年1月19日英军炮击并占领亚丁。拉赫季苏丹6月签下约定，11月当地部众反攻。1849年3月7日协议第五条明确霍尔马克萨尔桥及其以南的地峡界线。1858年印度行政转归英国王室，亚丁仍由孟买政府管理。 |
| 1857、1858 | 佩里姆岛英方在1857年重新占领，部署驻军、驻舰并安排建灯塔。图上1858年起与亚丁一同列入英属印度行政。 |
| 1869 | 4月2日阿克拉比首领阿卜杜拉以3万德国银元交售小亚丁半岛和所列港湾，月津贴由30元增至40元。印度事务部1868—1869年度报告第39段和双方签约日期一致，采用1869年。 |
| 1886 | 4月23日英方与苏丹阿里·本·阿卜杜拉在基什恩签约。第一条规定保护索科特拉及苏丹管辖的属地。地图先落主岛。 |
| 1854、1856 | 库里亚穆里亚割让书正文与签署栏均为1854年7月14日，条约集小标题误作6月。1857年英国下院答复再次确认7月14日。1856年许可证把其中三岛鸟粪肥料的开采、运出权授给约翰·奥德等人为期五年。 |

亚丁主半岛取大英图书馆藏1880年港图，参考第7号海图和1863年半岛图档案。使用1350像素宽的1880年图，四控制点为马什阿格角（1050,78）、马尔巴特角（650,928）、沙姆桑山（920,541）、席拉岛（857,100），拟合残差约67米。地峡北缘按旧桥位置在两岸间概化接线。1839年以同一具名半岛范围呈现，按1849年可核北限闭合。小亚丁用英国海道测量局第7号海图描绘半岛岸形，对照1893年Harris图和1869年契约所列地名。小亚丁半岛内陆一侧按地形概化闭合，1869年同时涉及的港湾、1882年谢赫奥斯曼及伊马德沿海购地、1888年半英里沿岸购地待分别勘绘。席拉岛与索科特拉属岛待在各自档案下复原。[条约汇编第十一卷](https://dl.tufts.edu/downloads/6108vp897?filename=9g54xw036.pdf) · [1863年半岛图档案](https://www.qdl.qa/en/archive/81055/vdc_100000010791.0x000001) · [小亚丁成交报告](https://www.qdl.qa/en/archive/81055/vdc_100152862995.0x000038) · [亚丁第7号海图](https://commons.wikimedia.org/wiki/File:Admiralty_Chart_No_7_Aden_Harbour,_Published_1907.jpg)

佩里姆使用英国海军部第2592号1857年实测、1858年刊印海图。以OpenStreetMap自然岸线的四处岬角匹配 1500×1124 像素扫描，均方根残差约145米。控制像素依次为（304,551）、（551,362）、（855,723）、（746,878），使用西、北、东南与南端地物配准。港水、潮滩和海峡对岸未并入陆地面。库里亚穆里亚参考美国地理空间情报局《航路指南》第9.29节逐岛认定，提取五处物理岛岸。该五岛几何来自 © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)，按 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) 授权。索科特拉主岛岸线来自 Natural Earth 1:10m 陆地。[佩里姆1857年原始往来](https://www.qdl.qa/archive/81055/vdc_100107714444.0x0000ad) · [佩里姆第2592号海图](https://commons.wikimedia.org/wiki/File:Perim_Island_1858_chart_by_Walker_Lamb.jpg) · [索科特拉1886年条约](https://www.qdl.qa/en/archive/81055/vdc_100023462215.0x00000c) · [库里亚穆里亚割让书](https://www.qdl.qa/en/archive/81055/vdc_100023462215.0x000092) · [1857年下院记录](https://hansard.parliament.uk/commons/1857-02-23/debates/6fb42222-8adf-46d3-9ecc-320b920cf7ee/TheKuriaMuriaIslands%E2%80%94Question)

## 怀卡托及丰盛湾东部

怀卡托及奥克兰南部画1865年1月至9月累计的十个地块。1864年12月是没收意向，翌年各次公告开始实施。取怀唐伊审裁庭《豪拉基地报告》图14中依据1927年委员会测图 B43 标注的范围，8个 LINZ 控制点以 NZTM2000 配准，均方根残差1.58公里。官档所记约120.2万英亩为各批没收总量，约31.4万英亩后来返还毛利人。返还地、留置地和后续出售尚未按宗地勾绘。[怀卡托五月公告](https://library.victoria.ac.nz/databases/nzgazettearchive/pubs/gazettes/1865/1865%20ISSUE%20019.pdf) · [九月公告](https://library.victoria.ac.nz/databases/nzgazettearchive/pubs/gazettes/1865/1865%20ISSUE%20035.pdf) · [审裁庭图14](https://forms.justice.govt.nz/search/Documents/WT/wt_DOC_68330839/Hauraki%20Vol%201.pdf#page=256) · [王室与Raukawa和解文书](https://www.govt.nz/assets/Documents/OTS/Raukawa/Raukawa-Deed-of-Settlement-2-June-2012.pdf)

丰盛湾东部按1866年9月1日修订、9月11日刊行的公告勾绘，从怀塔哈努伊河、普陶阿基山顶，经奥希瓦港以南折向哈帕拉帕拉河。东向一段经原始公报和1870年法附表核为20英里。采用审裁庭《特乌雷韦拉报告》图4.1内陆虚线、原图海岸，6个 LINZ 控制点拟合均方根残差1.10公里。部分东段后来撤销，逐宗地延续待查。[1866年公告](https://library.victoria.ac.nz/databases/nzgazettearchive/pubs/gazettes/1866/1866%20ISSUE%20051.pdf) · [1870年法原件](https://www.legislation.govt.nz/act/public/1870/62/en/1870-09-12/official_scan.pdf) · [审裁庭图4.1](https://forms.justice.govt.nz/search/Documents/WT/wt_DOC_134632524/Te%20Urewera%20Vol1WS.pdf#page=248)

## 格里夸兰西

1871年10月27日巴克利发布公告，格里夸兰西成为英方领地主张，奥兰治自由邦继续争议钻石矿区。1873年设单独管辖的王室殖民地。1876年7月13日英方与自由邦议定东界，包括普拉特山、瓦尔河界点和若干农场例外，并约定英方支付9万英镑。1880年10月按1877年并入法归开普，地图沿用并入时旧省轮廓。

1871与1873阶段依据林德利1873年《Adamantia》图D明确标作英方公告界线的橙红实线，15处地理控制点薄板样条拟合。控制点残差3.29公里、留一检验27.24公里，适用于区域级呈现。1876与1880阶段以《大英百科全书》第九版第5卷《开普殖民地》图版I着色边缘为底本，9个经纬交点拟合残差2.94公里。1883年北界委员会图仅用来核对既有边界，图上的ST、TU建议线未作为改界。条约所列农场例外待地籍资料。[1871年公告范围图D](https://commons.wikimedia.org/wiki/File:LINDLEY(1873)_Adamantia_p358.jpg) · [1876年协定](https://archive.org/details/mapofafricabytr01hert/page/215/mode/2up) · [1870年代开普图版](https://commons.wikimedia.org/wiki/File:Cape_Colony_Map_1878_-_Encyclopedia_Brit.jpg) · [罗得斯大学1883年测界图](https://digitalarchives.ru.ac.za/s/cory/item/10937) · [钻石矿权研究](https://scielo.org.za/scielo.php?pid=S1021-545X2018000100002&script=sci_arttext)

## 连续性与验收

[1859→1860台账](../../research/continuity/TRANSITION_1859_1860_19C_TERRITORY.json)登记亚丁、佩里姆与库里亚穆里亚跨年；1860年代补入怀卡托、丰盛湾东部及小亚丁的年度状态。本批各行政地位延续到1900年，格里夸兰西随开普承接，毛利两项数据保留的是公告时的历史范围。

桌面核查覆盖各年新增、改界与交接、点击区域档案、澳洲及香港沿用的轮廓、1879年世界总览与开普敦近景。OGR校验全部新多边形与来源关系。
