# T14｜信德、旁遮普与阿瓦德：英国征服、战利品及土地剥夺的证据与GIS审计

**日期** 2026-11-22；**阶段** R2制作稿（未完成发布）；**研究原案** B06；**章节** T14.1、T14.2、T14.3；**主要范围** 1842—1859年。本文聚焦英印当局实行的武装征服、财产扣押、军人分赏、王室宝藏转移、王廷破坏、没收地权与政治流放。所有有争议数字均按来源原口径，不擅自合算。

## 五、仍须调取的一手原件

1. 信德海得拉巴王廷原库存、Talpur家族私人财产与村镇损失清册；1843英军战报、俘虏与家属名册。
2. 1848—1850信德完整战利品财会总账与分给纳皮尔和英印海军人员的实收凭证；核对Low所说683522卢比、八分之一是否原数。
3. 1846割地及赔款国库实收、1846阿姆利则750万卢比付款总收据、巴罗瓦尔每年220万卢比军费实际收支。
4. 1849《拉合尔最后条约》原印与1849年4月7日达尔豪西信原手稿逐页；锡克国库逐项清册、光之山运输与王室收藏登记。
5. 1856《Papers Relating to Oude》草约和拒签书原PDF影像的原印页码校验；王族被迫迁居的物业与经费清单。
6. 1858年3月凯萨尔巴格各英军团所取宫苑宝藏与财物账本、民间受害者财产登记及英国博物馆后续收购链。
7. 1858没产公告六名列名例外与其法定地权；各区土地没收与发还簿、1859年新契据实领户及未获返回的佃农。
8. 1849旁遮普与1855阿瓦德原调查地籍、地图比例尺、行政边界与现有示意地图配准；未经原件精确校准仍全部虚线。
