# T53 加拿大编号条约、保留地及通行证：史料GIS审计

制作态 editorial_review / not_submitted。三章29节87段25来源29新事件13分年代GIS点；制作候审，专项CI及独立出版待核。归责区分1862加拿大省殖民行政、1867以后加拿大自治领及1888英国枢密院司法委员会。

## 核心证据

- 第六号条约1876签署、1879与1882加入书；饥疫与医疗条款；DCB记录Big Bear因粮食签约。
- Parks Canada明确通行证制度属于法外限制；PAS S-E19 File 35.a No.15、78分别为探亲与跑步比赛许可。原证件影像未逐字转录，其他证号留待核。
- 2024 SCC 12 ¶¶8–13、83：1882初测约650、1883改划547.5、应得710、少划162.5平方英里。差额与1889 Akers 440英亩另案不可相加。
- 1888 UKPC 70：1883许可证上限一百万英尺木材，不等于实际产量、利润；安大略利益裁判。
- 1899报告给付26974加元，按7、23、2187领取人分类；非土地市场价值。
- Wiikwemkoong社群治理文献与1862条约东部例外并读。
