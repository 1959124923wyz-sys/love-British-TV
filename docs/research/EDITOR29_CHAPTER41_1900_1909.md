# 第41章（1900—1909年）研究记录

## 首批　南非战争中的集中营：从焚毁农场到强制迁移

新增49条年表事件（32条可定位）、10处新增地图地点、2条可点击虚线，承接前章42处地图地点。

- 南非战争于1899年爆发，开战条目归上章。1900年的焚毁农场命令分1900年6月14日电令、6月16日公告和6月19日公告。文特斯堡事件依军方与同期议会记载，以现镇定位。
- 1900年12月20日招降公告和21日向各指挥官发出的内部命令分别入档。福西特报告1901年12月12日在德班签署，1902年才刊行。营内调查所记人口与死亡依各营和各期口径。
- 奥兰治河站的布尔营和黑人营分别记录，共用铁路站地名参照。黑人营旧址仍待查。德赖哈茨用考古图分别定位住处和墓地，铁路转运虚线只连有据地点。赫宁斯普鲁特申诉按原信档案取1901年11月23日，地图取同名车站。博斯霍克据牛津出版研究采用月精度，营址待查。
- 和会在弗里尼欣，签字在比勒陀利亚。黑人营的后续返乡计划与实际返乡人数分开。克鲁格斯多普、德赖哈茨、布隆方丹与金伯利按各自记录停用。
- 1901年澳大利亚联邦成立后，阶段地图将前章的具名殖民地行政中心作为对应州政府显示。纳闽根据1906年敕令，于1907年1月1日并入海峡殖民地。贝宁与旧卡拉巴尔按1900年尼日利亚行政改组接续。
