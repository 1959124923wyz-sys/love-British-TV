# 爱英TV｜17世纪跨十年滚动四年事件窗口（2026-11-03）

## 需求

读者希望选中1650年时默认显示**1647、1648、1649、1650这四年**的真实事件；切至1651年则自动显示1648—1651年，地图和事件列表同步更新。此模式既能显著降低1699年以往连续十年积累的事件图标，又不会把一个跨十年的历史过程从1650年突然切断。年份滑块和原十年目录仍然保留，可按年连续播放。

## 已实施的产品逻辑

1. **仅17世纪**默认 `rolling4`：若当前选择年份为 `Y`，事件窗口为 `[max(1600,Y-3),Y]`。1600—1602窗口对最早年份适当截断；1599年以前仍保持已获批准的原地图交互。展示年份不等于政治实体边界持续生效年份。
2. 追加「仅本年」「近四年」「本十年至今」三个互斥切换。仅本年显示`Y`的事件，近四年滑动展示`Y-3...Y`，十年模式展示本十年元年至`Y`。右侧档案仍可独立开启本十年完整历史资料（包含未来事件，但不会提前作为地图上的事实绘制）。
3. **真正跨十年读数据**：原项目已在网页初始化时从`data/atlas-1600-1609.json`至`data/atlas-1690-1699.json`加载了全部十份原始档案，代码使用现有`serialPreviewByDecade`逐年代读取，再用原始事件ID去重；不为早年信息造假、不复制任一记录、不改事件坐标或来源。项目的`sourcesById`原本已经跨十年加载所有来源，因此前十年事件可以保持同样的史料抽屉与地图焦点。
4. **前后三年有区别**：当前年份仍显示金色「本年新」提示，之前1—3年事件图标视觉上适当变淡，但可以正常点击。滚动四年模式下，所有**已定位**的历史事件层级都允许进入地图聚合；此前为了远距缩放隐藏的补充事件也不被遗漏。世界地图原有聚合仍发挥作用，不会恢复「几十图标同时弹开」的问题。
5. 窗口标签实时注明年份及此期实际入库、可定位记录数。专题数据、殖民声索、行政区、占领与抵抗等非事件类型参考层继续**严格使用所选单一年份**，不能将四年范围当作同一时期被英国控制的统一疆界。17世纪七块最大纸面特许仍默认隐藏，其他图形仍保持历史不确定性虚线语义。
6. 只对地图事件符号及左侧事件列表应用滚动窗口。右侧文献档案、长篇专题文章和已经存档的514条事件始终可从原始ID访问；正式专题内完整百年历史仍保持原始事件引用。未来若建设「专题专属时间轴」，可直接复用`seventeenthEventsForWindow`，再在此结果上按`event_ids`过滤，而不用重新发明年份算法。
