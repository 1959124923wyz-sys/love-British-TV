## 读者场景与改造方案

### 优先级1：地图从“一次显示全部”改成“读者一次看一类”
读者可选：
- 驻军与殖民行政（默认）：仅标英国有军政文献的地点或行政背景
- 抵抗、战争与控制中断：当地自主、奴役伤害、围城、外国驻军及英军撤离；空心线条
- 税收与贸易：公司财政权与商贸路线，**不涂作英军占地**
- 条约及纸面声索：外交法政关系，空心虚线
- 全部类型（研究）：作为史料检索而非英国疆域图

地图选定类型后，只画一层**合并后的可读参考几何**；在屏幕像素距离近的参考框按同类分组，一处显示一个数量徽标。其他类别不丢弃，仍然能从该位置打开。原有彩色框仅在自愿选择“查看原始重叠图层”时恢复。

### 优先级2：一个地点“一次点击，看到所有历史资料”
每个可视化色块和数字标记：
1. 鼠标悬停：简短标题、**年份起止、类别、具体史料摘要**、合并了多少记录。
2. 点击：右侧出现“**这里有 N 条历史地理记录**”，先说明为何会重叠，再列出同一位置的记录，每张卡显示标题、类别、年份与一段事实。
3. 点击某条卡片：进入**事情是什么／如何理解色块／历史资料来源链接**；可返回这个地点所有史料。
4. 地图空白处若覆盖示意框也可点击；不需要猜被另一块颜色遮住的色块顺序。
5. 同时提供**按年份搜索**，可搜地名、殖民行政、军事、奴役抵抗等关键词。

### 优先级3：避免为了可读性丢失旧研究
- 第35–39批605个参考框：原始JSON不改，简化后**渲染的是合并的代表框，非地籍真实界**。
- 第34批24个复用17世纪几何的研究记录：从 `data/seventeenth-century-expansive-colonial-claims-1600-1699.geojson` 映射旧`geometry_key`，纳入右侧同地检索和来源卡，**不在试验版重新涂为18世纪领土**。
- 第34批15个核心以及第35–39批406个带source_url的核心保持原始数据。读者图层显示聚合标记，而非421个堆在一起的圆圈。
- 不修改原34篇专题、1126条档案、六批旧JS模块的绘制规则，正式main不变。

## 下一步产品层面的明确改进建议（本批先不修改原始研究内容）
1. **地理对象规范化**：每座城市／堡垒设稳定`place_id`，其下挂不同年份和法律关系的`record_id`。目前仅按包围框中心像素聚合，若未来拥有可靠坐标应替代之。
2. **信息字段规范化**：每条记录补`actor`（行为主体）、`action`（具体行为）、`effect_on_people`（被影响者）、`date_precision`、`evidence_confidence`（明确引用依据），将`note`由编辑备注升级为读者事实摘要。
3. **历史疆域几何级别区分**：实测／历史地图配准边界、城镇位置、宽幅贸易走廊、纸面声索应采用不同几何表达，绝不把现代矩形示意同真实行政边界混算。
4. **审查聚合误判**：现有按像素相近合并是一种地图UI上的去噪，若不同地方偶然相近，须通过`place_id`和来源进一步拆分；数字表示“记录数量”，绝非战斗人数、商贸额、面积或统治强度。
