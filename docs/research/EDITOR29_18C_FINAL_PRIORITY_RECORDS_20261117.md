# 18世纪315条优先候选核对完成

本批新增达连围城与撤离、爱尔兰惩罚法两城迁离、1798年爱尔兰起义中的囚犯与平民三篇试阅，并扩充既有塔斯卡罗拉专题。新增9条年表，其中2条可定位。315条入选候选全部逐项对应到年表，162个归并组均保留。原1126条档案交叉表不改。另16条历法或史实待审材料不属于315条入选候选，继续保留原状态。
