# 新资料第二批：1537年阿斯克、1547年流浪者法、1569年达勒姆北方起义

## 处理结果

1. 1537年约克：Robert Aske，圣恩朝圣运动领导者，遭亨利八世王室处决。English Heritage明确关联Clifford's Tower与1537年处刑；坐标采用Historic England登记的现存塔所在地NGR SE6046351467，**不是断言行刑架精确位置**。只记年份，不混用二手网站对7月具体日期的冲突。
2. 1547年英格兰《Vagabonds Act》（1 Edw VI c.3）：法条规定V字烙印、两年强制服役及逃跑的更严刑罚。仅作为全国性法令编入年表，坐标保持null，不创作某座城市的受害者事件，也不据法条估算现实执行数量。
3. 1569年达勒姆：北方叛乱的两伯爵1569年11月14日进入达勒姆并在大教堂举行弥撒；归责为**反王室叛乱方活动**，不是英王镇压。官方遗产NGR NZ2736042144仅为大教堂今址。
