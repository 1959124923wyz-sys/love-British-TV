# 17世纪殖民区域档案：外部来源辨识、图层性质明示与短标签（2026-11-02）

## 已确认的可读性问题

1699年右侧殖民区域档案里部分区域的来源块只有两三个内容完全相同的「阅读 ↗」按钮。来源URL各不相同，却没有任何可见的辨识信息，降低权威史料核查效率，亦不利于使用键盘逐项选择。多重声索目录的完整长区域名仍可能占据大量行。事实栏很多时候仅有历史时段，图中淡紫色概略范围究竟是否实测、是否可当作实控面积，难以在右侧立即看清。

## 本批处理

- 对既有来源URL`source_urls`逐项显示**实际HTTPS链接的hostname**，例如`avalon.law.yale.edu`或`nationalarchives.gov.uk`，而非三个同名的「阅读」。这一标签是可核验的网络地址属性，**不自动臆测史料作者、年代和档案题名**；目标仍为原始完整URL。键盘焦点清晰。
- 在17世纪殖民文件史料事实栏明确显示`图层性质`及`边界说明`——「概略示意外缘 · 非实测边界 · 不得计算实控面积」。原本7块跨大陆纸面特许继续默认隐藏，显示时仍不填色。
- 地图同一点的竞争性法理声索切换列表使用此前审核的短区域显示名，完整原始名称仍可在目标档案的「完整区域名称」中展开核对。
- 严格保留原有53份GeoJSON、来源URL本身、开始/终止年份、已出版专题、事件ID和所有资料；**不因可读性改善改变历史地理的面积或地权判断**。
