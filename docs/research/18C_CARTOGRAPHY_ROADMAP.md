# 十八世纪制图路线图｜1700—1799

本路线以 1699 年末已有控制关系作为起点，以 1799 → 1800 年去向台账作为终点。每组围绕一场战争、一组条约或同一地区的连续变更，先核期初持有者，再按实际交接绘制期间各次变化。一个港口、岛屿或辖区跨过章界时保留地理身份。底图和治理阶段各有证据，变化只更新有依据的那一项。

## 已有底稿

- 正式站的十八世纪区域档案选择器读取 628 条区域记录及 421 条地点记录，其中包含不同批次对同一地点的补充、矩形参考区和贸易或法权记录。它是检索起点。各地真实外廓和可延续的控制关系须按稳定 ID 分别复核。
- [1699 → 1700 初查](../../research/continuity/1700-1709/HANDOFF.md) 已清点 27 条旧参考面、17 条旧空间点，核实七处欧洲商馆或要塞及达连撤离，保留尚待追查的范围。
- [1799 → 1800 台账](../../research/continuity/1800-1819/1799_1800_SPATIAL_HANDOFF.json) 已清点 298 条旧期末记录，75 条已有 1800 年对应空间记录，89 条待查几何、驻地或退出时间。修订 1799 年且仍延续的对象时，核对 1800 年地图中的 ID、位置和首期治理状态。
- 原 [18 世纪专题与档案总目录](../../research/18c/consolidated/README.md) 和 [优先档案核对](EDITOR29_18C_FINAL_PRIORITY_RECORDS_20261117.md) 提供事件和源链接。地图进度按区域、机构或政体的交接计算。

| 5 | 1784—1799，期末集中接续 | 先完成锡兰和迈索尔分期，再查加尔各答、马德拉斯、澳洲流放驻地和原住民治理，以及开普、塞拉利昂驻地和辖地。对照期末台账补去向。 | 1788 新南威尔士、1792/1799 迈索尔分割、1795—1798 锡兰逐堡交接、1795 开普、1797 特立尼达、1799 → 1800。 |

单批选一个关联地区群，先完成该组的地图和交接表。遇到材料不足，把具体缺口和已查档号写回本页，继续同组内证据成熟的对象。题目研究可以并行，进入正式地图和发布按本表顺序。

## 每批交付

1. 登记期初、期末和每次变化的公历年末状态。分别记和约日期、实际接收、当地持续治理。短期行动可在同年事件层呈现。
2. 从实测地图、边界条款及现场单位证据绘制区域、旧岸线和局部驻地，保留坐标方法与资料出处。近似历史边界用虚线。贸易、征税、军事活动与持续管辖分别入图。
3. 复用稳定 ID 及已核几何，校验每个交接年前后、十年章界和世纪章界。逐项记录待继续的位置及原因。
4. 在桌面正式站验证实际形状的命中、悬停和来源档案。检查图层开关及邻区遮挡。发布后回填此表和批次证据。

第一组已完成西地中海和北大西洋两批。第二组已完成皇家岛、路易堡与奇涅克托地峡。下一批转入乔治亚与西属佛罗里达边境，先查弗雷德丽卡堡与圣奥古斯丁，核 1730 年代筑堡、1740 年围城和其后的驻防变动。

### 第 1B 批 · 北大西洋

普拉森舍皇家堡、纽芬兰法国渔岸、海斯河约克堡和阿卡迪亚安妮堡已按交接阶段绘制。渔岸只沿海岸，安妮堡与约克堡第三站同址接入 1800 年。普拉森舍以遗址点呈现，史图图像页和旧堡墙线仍待取得。下一批查皇家岛与路易堡的建立和首次易手。 [分期、史料与方法](18C_UTRECHT_NORTH_ATLANTIC_HANDOFF.md)

### 第 2A 批 · 皇家岛与路易堡

以 1744 年法国图和 1745 年测绘图补出路易堡主城城垣，接续 1745 年失守、1748 年议定归还、1749 年实际移交、1758 年再度失守和 1760 年拆防。圣安妮多凡港与皇家炮台逐年分开呈现。布雷顿角的 1784 年单设殖民行政沿同一地理外廓接入 1800 年。 [分期、原图与交接](18C_LOUISBOURG_ROYALE_HANDOFF.md)

### 第 2B 批 · 奇涅克托地峡

分开绘制博巴桑村址、劳伦斯堡遗址和博塞茹尔堡主堡，补入加斯帕罗堡与周边焚村记录。1755 年环节按陆上攻占、扣押和离港分阶段归入相应地点。坎伯兰堡看守状态同形接入 1800 年。 [地峡档案与制图交接](18C_CHIGNECTO_HANDOFF.md)
