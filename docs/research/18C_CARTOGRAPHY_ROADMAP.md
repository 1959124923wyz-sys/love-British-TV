# 十八世纪制图路线图｜1700—1799

本路线以 1699 年末已有控制关系作为起点，以 1799 → 1800 年去向台账作为终点。每组围绕一场战争、一组条约或同一地区的连续变更，先核期初持有者，再按实际交接绘制期间各次变化。一个港口、岛屿或辖区跨过章界时保留地理身份。底图和治理阶段各有证据，变化只更新有依据的那一项。

最新批次、剩余旧框与逐项跨年待办见 [1497—1799 年主编交接清单](PRE_1800_CARTOGRAPHY_HANDOFF_20261119.md)。

单批选一个关联地区群，先完成该组的地图和交接表。遇到材料不足，把具体缺口和已查档号写回本页，继续同组内证据成熟的对象。题目研究可以并行，进入正式地图和发布按本表顺序。

## 每批交付

1. 登记期初、期末和每次变化的公历年末状态。分别记和约日期、实际接收、当地持续治理。短期行动可在同年事件层呈现。
2. 从实测地图、边界条款及现场单位证据绘制区域、旧岸线和局部驻地，保留坐标方法与资料出处。近似历史边界用虚线。贸易、征税、军事活动与持续管辖分别入图。
3. 复用稳定 ID 及已核几何，校验每个交接年前后、十年章界和世纪章界。逐项记录待继续的位置及原因。
4. 在桌面正式站验证实际形状的命中、悬停和来源档案。检查图层开关及邻区遮挡。发布后回填此表和批次证据。

## 当前进度

第一组已完成西地中海和北大西洋两批。第二组已完成皇家岛、路易堡、奇涅克托地峡、乔治亚与西属佛罗里达边境，以及波托韦洛和卡塔赫纳。第三组已补绘安大略湖、尼亚加拉河、圣劳伦斯河、哈瓦那、马尼拉与甲米地，以及马德拉斯、加尔各答和孟加拉的要塞与财税驻地。第四组已完成魁北克战后改界及五大湖、俄亥俄河谷与拉布拉多的配套驻地。第四组已续绘纽约港、纽波特、费城和特拉华河防务。第四组已补绘萨凡纳和查尔斯敦，续做加勒比六岛和锡兰沿岸与康提。迈索尔两次分治已补到 1800 年。槟城和吉打的海峡两岸及澳洲早期流放驻地已补绘。开普与塞拉利昂的驻地、关押设施及实际交接已补绘。接下来集中验收 1699 → 1700、1799 → 1800 两处接缝，并关闭台账中已有可靠证据的缺口。
