# 19世纪346个单记录事件复核｜V3交接（2026-11-12）

**编辑原则：一个宏观专题包含多个有据地理的聚合事件，每个事件包含完整细节节点。**

## 审核结果

此前V2以「原始专题内每3年一组」得到532个暂定事件块。其中346项只有1条原始行动记录。经逐条分类，对原始史料、上层主题、同地区/同年行动、已登记来源和代表性外部史料交叉检查，得到：

| V3结果 | 数量 |
| --- | ---: |
| 与其他同一区域行动直接合并 | 18 |
| 作为既有事件的史料、报告或司法后果 | 18 |
| 保留为重大/独立事件候选 | 181 |
| 保留为制度/土地权利/政治状态研究节点（不画局部暴力区） | 79 |
| 仅留专题背景或研究资料 | 38 |
| 已吸收其他行动的主事件候选 | 6 |
| 暂缓，需补原始史料或地点 | 6 |

**532→496个候审事件组，83个宏观专题不变、408个原始题目不变、1339条节点原封可追溯，2148条来源关联完整。** 36个旧事件分组的可逆别名及目标归属见 `data/research/19c/singleton-audit-v3-aliases.json`。

## 已核的编辑合并示例

- **1840 Fighting Hills＋Fighting Waterholes**：同处澳大利亚维多利亚州Coleraine周边、相隔约一个月的两次不同屠杀，作为同一地区连续暴力专题下的一个事件块，不合并具体死者及事件证词。澳大利亚纽卡斯尔大学的Colonial Frontier Massacres地图分别登记两处：
  https://c21ch.newcastle.edu.au/colonialmassacres/timeline.php
- **1882—1884 Skye Crofters' War**：Braes的警民冲突与Kilmuir海军陆战队驻岛干涉，属于苏格兰斯凯岛连续土地抗争；分别记录地点及年份。High Life Highland：
  https://www.highlifehighland.com/archives/highland-archive-service/online-exhibitions/the-battle-of-the-braes/the-aftermath
- **1858 Fraser Canyon**：淘金者与Nlaka'pamux人的冲突和James Douglas的殖民干预纳入同一个政治／军事事件；**不得把淘金者造成的暴力直接归责于英国正规军**。Dictionary of Canadian Biography：
  https://www.biographi.ca/en/bio.php?BioId=39077
- **1819 Ras al-Khaimah**：A/B两位助手提到同一英印军远征，消除重复。
- **1888 Sarawak protection agreement**：跨题相同条约合并，但此事属于政治关系/制度变化，不能涂成英国直接占领全砂拉越。文本：
  https://www.jacar.archives.go.jp/acv/contents/pub/pdf/B06/B06150949700.b20140.2-1182.00000009.pdf

## 发布流程

1. 主编确认本批合并是否达到「同一地带、同一行动链」要求；所有36条归并与附属关系可以恢复原ID。
2. 专题编辑把研究节点写为历史叙事，并将与年份准确对应的已审事件链接进正文。
3. GIS审核有据锚点后，按点、线、**虚线局部影响区**或独立政治状态图层制图。候审阶段geometry永远null。
4. 编辑+GIS+桌面交互测试通过才有资格移入正式Atlas及专题索引；左栏概览保持简洁，技术性史料备注留在后台，不铺满读者页面。
5. 每个专题由主编追踪「原始题目→事件块→证据ID→来源URL」全路径；不准因合并漏掉遇害者、事件或地方抵抗。
