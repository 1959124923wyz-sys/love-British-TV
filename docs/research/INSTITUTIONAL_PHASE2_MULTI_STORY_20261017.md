# 事件多专题入口｜代码变更记录
原界面 card 保持原样；将历史专题查找表变为「事件ID → 有序且去重的专题ID数组」。一个事件有两篇专题时，在同一原详情卡片下显示两个阅读按钮；单专题事件继续保留其单个按钮和年份小字。
实际证据案例 `1580S-E029`：分别链接德斯蒙德战争以及芒斯特殖民地契两个既有专题。该事件已出现在第一篇的manifest并在第二篇的正文related_event_ids中，第二篇manifest增加同一ID，不生成事件新点位。
测试限制所有其它事件只能有一篇；如将来新增其他多专题关系，须先对应扩充测试和史料审查。浏览器测试同时覆盖桌面与移动端选择、打开及返回原事件。脚本不更改历史坐标、年份、控制区、原始来源记录。
