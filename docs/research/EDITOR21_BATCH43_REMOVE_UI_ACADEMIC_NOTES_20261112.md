# 主编21｜第43批：删除读者可见的制图学术备注，简化跨世纪原地图（2026-11-12）

## 用户要求
> “很好，现在修修bug，优化交互。将所有‘殖民省行政外缘不等于各地持续驻军／虚线为概略历史地理参考，边界未经历史地图实测配准。’等类似的学术备注全部删去，一字不留！给读者一个清爽的页面。”

本批严格执行**读者界面删减**，不修改JSON、GeoJSON、历史资料出处或地图不确定性（仍然虚线绘制）。不会删除原始历史来源中的政治争议／地方反抗事实。

## 已清理的读者层
1. **右侧所有重叠区域**（16—17世纪和18世纪两个工作模块）：移除“边界说明”“非实测／配准”“参考面积不累计”“复杂图层比较”等技术段落；新增统一正文清理器 `js/atlas-reader-copy.js`，只处理屏幕文案、不覆盖原JSON。只有经清理后有事实的段落才显示，没有内容就留标题＋类型＋年份＋史料链接。
2. **阅读效率**：卡片收紧行距，未展开时显示一段摘要，已展开时不再重复显示摘要，而是集中显示事实说明、时期／类型、可折叠的直接来源。悬停轮廓发光、选择固定高亮完全保留。
3. **18世纪六套地图旧层**：第34–39批单击详情和tooltip删除制图方法文字，包括“未曾按照历史地图配准”“概略包络”“不提供占领地平方公里”等。史实及来源仍从原存储读取。
4. **16/17世纪旧专题详情及tooltip**：删除代表性地图坐标提示、方法说明、现代考古边界编审提醒、17世纪殖民声索“非实测边界”附言。依选定年份呈现当年有据治理主体，保留相关历史事件按钮和档案来源。
5. **侧栏地图图例**：去掉第34—39批冗长版本更新叙述及反复的GIS免责声明。只保留一条简明操作说明、七类颜色／符号对照及原先4个有效设置入口。
6. **事件年代简介**：删除“统计不完整、现代位置非实控面积、未正式发表”等编审说明，保留该年事件计数、当年新发生事件数和实质性历史时段。

## 不变的底线
- 原本的地理数据不重绘、战役年份不改、行政与军事区别不改、原住民族和被奴役者行动史实不删、source_urls链接不删。
- **625+参考区**以及第41—42批右侧hover选择不减少；由于本批没有编辑任何历史数据库，既有 **629区域、421核心、1099阶段**原样保留。地图未测绘区域仍保持虚线。
- 只删页面上的方法论提醒，不把临时港口占领改成完整国土征服，不把公司外交权误记作主权。
