# 第45章（1940—1949年）研究记录

- 巴当加里采用英国最高法院 Keyu 判决第1及8—30段。两日死者24人，11日一人、12日23人。英方密电26人、远东陆军报告25人、《海峡时报》把本案与别地合报，均不当作本案死者名单。家属与军人证言分别写明身份。夹注采用家属民事陈词、访谈及名单，2025年英国大臣信按原文记为承认旧叙事错误并表达遗憾。
- 双溪勒莫采用历史庄园地名点（GeoNames 1742630），与同名镇及溪口分开。胶园工棚、墓地、焚毁范围、12日具体行车道路仍待核。乌鲁音采用村镇级参照。妇孺被带离的点到点联系依据家属法律陈词；瑞天咸港、海口、香港、厦门与汕头分别记录船上护送人员的叙述和港口档案。船舶航迹留待核实。
- 峇都亚兰外围军事行动引英军 WO268/603 与帝国战争博物馆口述，由 Hack 的档案研究对照。卡肖的61所及约400人分别核下院记录和研究。第17D条集体拘押、17C条个人遣返、签发令、批准遣返、在押及实际离境人数各用各自口径。
- 联合邦1948橡胶产量69.6978万吨为 A/1269/Add.2，港口占比及商品出口值为 A/3108，英镑区美元储备为1949年7月14日财政部答复。1949年7月12日加拿大驻新加坡商务专员列四处熔炼厂、每英长吨554英镑的固定价和英国供应部专买。科伦坡计划报告仅证部分企业利润以股息和资本汇出，英国公司利润总额依下院答复留空。
- 对1939年末52处地点逐项承接。港九、纳闽、缅甸按占领与行政变更分年。缅甸部分旧据点只有地区政权变更来源，个别驻防和恢复行政确日仍待核。天津和沙面区分日军战时控制、1943年交还条约和战后状态。印度、巴基斯坦、锡兰与爱尔兰按各自政治变化分列。
- 孟加拉饥荒附列沿海拒止中的征船、毁船及粮食转移，数字采用1945年调查委员会。该线仍可扩充为独立专题。
