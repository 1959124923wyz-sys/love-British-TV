# 历史事件视觉层级与注意力引导规范 v1.0

状态：正式设计规范（2026-10-11）；应用范围：1490年代至当代的所有专题。

## 1. 研究依据与设计转换

- Nintendo 官方开发者访谈（《塞尔达传说：王国之泪》，第5部分）强调：稳定、一致的视觉规则及标志可以让玩家无需额外说明也能理解哪些对象值得交互。[Nintendo 开发者访谈](https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-9-the-legend-of-zelda-tears-of-the-kingdom-part-5/)。
- Nintendo 官方访谈第3部分提到，在已有世界里添加值得探索的内容，会改变玩家观察地形的方式；设计者还注意到远处的天空岛过小会像视觉噪点。[Nintendo 开发者访谈第3部分](https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-9-the-legend-of-zelda-tears-of-the-kingdom-part-3/)。
- 任天堂的《旷野之息》设计总监和美术、技术负责人在 [GDC 2017《Change and Constant: Breaking Conventions with The Legend of Zelda: Breath of the Wild》](https://www.gdcvault.com/play/1024562/Change-and-Constant-Breaking-ConventionsInteresting) 讨论打破传统设计惯例。其理念用于启发自然探索，但**本地图不复制游戏机制，也不声称下述历史事件等级来自任天堂**。
- Nielsen Norman Group 的[视觉层级研究综述](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/)强调颜色对比、尺寸和分组可以引导注意；[渐进披露](https://www.nngroup.com/articles/progressive-disclosure/)和[降低认知负荷](https://www.nngroup.com/articles/minimize-cognitive-load/)支持初始只给用户必要信息，次级内容按需打开。

**设计转换**：将广阔地图当作探索界面；远看见少量地标，靠近看到上下文，悬停得到线索，点击进入可核验档案。用对比度与节奏引导，不用强制镜头、频繁弹窗、闪烁警报去夺取注意力。

## 2. 两套相互独立的分类

### A. 历史重要性（significance.level）

| 级别 | 评价名称 | 判定条件 | 地图设计 |
|---|---|---|---|
| 3 | 全球／帝国结构性转折 | 改变大区域权力结构、跨洋体系、长时段殖民制度、持续性国际关系；历史研究广泛视为关键节点 | 最大的清晰实心符号（约23px），高对比描边；可选独立地标提示。默认显示 |
| 2 | 区域重大事件 | 对殖民地或区域的法律、社会、军事、劳工、贸易形成重要影响 | 中等符号（约16px），普通对比。默认显示 |
| 1 | 地方与背景事件 | 小规模行动、局部登陆或贸易站、单一文件、主事件补充 | 小点（约10px），低对比；地图初始隐藏，用户可显式勾选“次要事件”显示 |

对于 1588 年英西无敌舰队战争一类具有帝国战略意义的事件，应考虑第3级；但这**仅是未来数据审核的分类示例，不是首版1497年数据的一部分**。小岛登陆不必因为“地理面积小”就自动判1级：若造成重大人口影响、长期制度变化，仍可以升为2或3级。

不得直接用人员死亡数、殖民财政收入、民族主义叙述或“新闻热度”当作显著性分数；尤其不能将受害人数少的群体等同于不重要。

### B. 证据确定性（certainty / geo_precision）

记录真实程度、地点精度、不同学术解释，应**独立于历史重要性**。一个全球重要的事件仍可能拥有模糊位置：使用醒目的地标样式加“？”、虚线或不确定范围，不凭高重要性推断高坐标精度。数据库仍保留独立 source_ids。

## 3. 长期通用的符号语法

| 类别（category） | 视觉语法 | 常用色 | 备注 |
|---|---|---|---|
| 有效政治统治 | 领土填色 | 英格兰本土紫色；后期控制区橙赭色 | 先判定实际控制、保护国或公司统治 |
| 航行／贸易／奴隶运输 | 路径与方向箭头 | 棕金/褐色 | 资料不足的路线必须是虚线 |
| 殖民战争／暴力镇压 | 盾／交叉标记／血红 | 暗红（#b94b50） | 不允许用动画渲染真实苦难 |
| 抵抗与独立 | 旗帜／抗争标记 | 绿色（#55a27a） | 抗争发生与独立完成分开标记 |
| 制度／皇家特许 | 档案／法令标记 | 蓝灰或金铜 | 普通许可通常为1/2级 |
| 登陆地点不确定 | 虚线圈／问号 | 浅金 | 无可证精确点时仅示意区域 |
| 经济节点（矿山、港口等） | 方形或港口符号 | 褐铜色 | 对应数据来源、年份与性质 |

注意：**色彩主要表示事件种类，尺寸主要表示重要性，虚实主要表示确定性**。不要给所有重大事件都涂血红，也不要用红色代表“重要”，否则会混淆层级与事件性质。色觉障碍用户必须还能依靠形状、描边、文字和图例区分。

## 4. 信息呈现的四个层级

1. **远景**：只显示2／3级已审核事件与线／面，确保地图可辨认；不主动弹框。
2. **接近**：点击“次要事件”或放大后，用户可选择展开1级细节。不得自行插入大量点。
3. **悬停**：最多一句简述 + 事件年份 + 重要性或史料确定性；不能把详细史料塞入 tooltip。
4. **点击**：侧栏打开历史经过、主体、证据来源、争议、经济数值口径；点击时**不自动平移、缩放或强制定位**。

每个事件永久有唯一 ID。对同年同地重叠点后续需做聚合或偏移，禁止无依据更改历史真实坐标。地图缩放级别改变时，可根据可用像素进行重叠处理，但不能改变事件的重要性标签。

## 5. 数据契约

正式字段：

```json
{
  "id": "example",
  "category": "voyage",
  "significance": {
    "level": 2,
    "rationale": "说明何以产生区域历史影响",
    "review_status": "provisional"
  },
  "certainty": "documented",
  "geo_precision": "regional-symbol-only",
  "source_ids": ["scholarly-source"]
}
```

- significance.level 只能是整数 1 / 2 / 3；未知时默认1，待核验。
- 更新级别必须记录理由、审查状态及提交记录；公开重大节点优先由至少两个相互独立的可靠资料交叉验证其重要性。
- category 和 certainty、geo_precision 各自独立；符号等级**不是历史道德评价，也不是因果证明**。
- 航线只在确有资料时标为已知实际航路。1497、1498年均只能画方向示意。

## 6. 验收条件

- 默认地图可一眼区分重大节点与普通背景；大型点不应铺满屏幕。
- 鼠标 hover 航线与点均显示短提示，click 显示来源；航线有不显眼的加宽命中区域。
- “历史事件”关闭后地图点消失；“次要事件”开启后才出现1级点；放大缩小时保留选择。
- 默认收起左右边栏，让地图成为主视觉；用户随时可以自主开关。
- 年份切换、事件点击与 hover **不修改地图视角**，仅用户按“定位”按钮主动定位。
- 底图无需 API key；外部地图服务受其服务条件与网络影响，若加载失败应明确提示。
