# 爱英TV｜历史空间叙事与军事影响区正式标准（v1.0）

**生效：2026-10-15。适用：所有历史调查员、主编、维护智能体以及未来全部章节。** 与 [地图优先总纲](MAP_FIRST_CARTOGRAPHY_STANDARD.md)、[战争控制与争夺区规范](WAR_CONTROL_AND_CONTESTED_ZONES.md)、[已批准交互规范](APPROVED_MAP_INTERACTION_STANDARD.md)、[时间叙事规范](PUBLIC_NARRATIVE_AND_TIME_MODEL.md)共同执行。此文明确补足“有具名地名却长期不敢落图”的空缺；**历史真实性、政治控制分类、年度状态的限制高于视觉叙事需求**。如发生冲突，优先采用不伪造历史事实的解释并记录冲突。

## 一、建设目标与必要纠偏

本项目不是一套逐平方米重建16世纪地籍的军用GIS。地图既要显示主权和真实控制的历史变化，也要让英国入侵、毁城、掠夺、奴隶贸易、殖民庄园剥夺以及当地反抗在**时间、地点、行动及后果**上能被直观看懂。

**“真实史事发生地点是否已知”与“事件具体战斗轮廓是否经过测绘”是两个问题。** 史料明确“1595年罗利攻入特立尼达圣何塞”，允许将历史圣何塞对应今天St Joseph的**城市级参考坐标**落入正式事件图层；不需要等到发现16世纪城墙角点。但不能因此声称此坐标就是罗利俘虏总督的准确房屋，也不能以它为中心自动推演占领半径。

已具名的城镇、岛屿、海湾、行政地区都可使用现代**对应地点**作为参考，精度随证据等级而异；不应因无法考证精确经纬度而让所有这些事件永久显示“无法地图定位”。若有同名歧义、历史遗址迁徙、地点争论，则保留待核，不以猜测解决。

## 二、六种空间对象：历史含义必须区分

| 对象 | 进入地图的最低资料条件 | 适合表现 | 历史上**不能**据此推断 |
| --- | --- | --- | --- |
| A 政治管治／殖民领土（含公司**实际**治地） | 同期主体、管治时段、控制关系；面需可核的边界依据 | 经核实的政治区域面、城市统治参考点；制度类别独立配色 | 贸易特许自动等于公司领地；短暂劫掠等于主权 |
| B 区域性军事行动影响区 | 具名地区内有连续/多地点/区域性军事活动的文献；或同一局部行动跨多个可靠锚点 | 极浅红填色+虚线的**概略**研究面，独立史事点 | 面内所有村落被烧、整个岛屿被夺、面边线是实测战线 |
| C 单点事件 | 原始档案、权威机构研究或可靠历史研究记录具名地点 | 正式分类SVG事件点及可点击史料 | 已知城名等于有精确炮位或伤亡分布 |
| D 有据行动顺序／路线 | 文献证实A到B的行动**顺序、方向或经过** | 点间淡色虚线、可点击路线说明；真实航迹有测绘史料才按航迹 | 直线是船只GPS、现代公路是当时行军道、沿线居民全部遇袭 |
| E 港市袭击／短期军事占城 | 具名被袭城镇及攻守结果，可确定何时撤离优先 | 具名点+低倍率固定像素位置提示/局部示意符号；失败与成功短占不同色 | 港口周边虚线圆是历史城墙、短占即长久殖民 |
| F 贸易、特许公司商业、外交、领事网络 | 文献确认具体地名和活动/交往主体 | 青绿色地点或贸易联系线 | 公司取得贸易许可即有土地管治，贸易/外交自动属军事入侵 |

**关于B类：** 两处具名地点是绘制**有据关系线**的充分入口，不自动证明可以画一大片影响区。只有史料将这些地点联系于同一次当地军事行动、具名地区遭反复扫荡或同一局部范围，才可绘制很谨慎的**局部阅读包络**；相隔千里的海港属于航次网络，不能因同一舰队而用红面横跨海洋。一个孤立的受袭城也可绘制**屏幕级符号**（E），但不是实测影响多边形。

## 三、地名与坐标准入（必须执行）

1. **史实核验**：事件的主体、行动、日期/年、具名地名有可靠史料；区分当事人自述、敌对方档案、后世研究与仅有档案目录，绝不把目录当已细读原件。
2. **历史地名对应**：优先官方遗址、国家图书馆、档案局、历史地名索引；历史名称与现代地名应能交叉对照。明确地名可使用现代城市中心或具名遗址的参考坐标；省份、岛屿范围不明确时只能使用**标注为region/island-level的代表点**，不称精确战地。
3. **精度字段**：`geo_precision` 和 `position_type` 必须说明 `modern_named_city_reference_not_exact_16c_site`、`modern_named_site_not_verified_historic_footprint`、`island_level_reference_only` 等；`geography_label` 保留历史与现代对应。禁止将现代定位点宣传为当年城墙/营地/登陆点的复原经纬度。
4. **主事件与研究层同步**：同一地点已在补充GeoJSON核实并上图，而正式 `atlas-*.json` 事件仍 `lat/lng=null`，必须回填**经审定的同一现代参考坐标**、改正右侧资料卡精度说明及该章detail notes；避免观众看见“无法定位”。
5. **无可靠现代对应**：多种相冲突地名、遗址迁移未经核证、仅有泛指“海外”等，继续保留 `null`，清楚登记缺口；不可编造坐标。
6. **防重**：同一原始事件即使同时在点、线、研究面中被引用，不应冒充三件独立历史事件。复用事件ID、`related_event_ids` 和来源ID。

## 四、B类“区域性军事行动影响区”具体审核标准

满足其一可**提出**局部概略面：①史料明确指明某具名地区的反复扫荡、围城、破坏或战争波及；②至少两个可查证具名战事地点处在同一**地方性连续行动**中；③可靠历史地区图件足以识别一块具有一定地理含义的军事活动区。审核时必须记录关联地点及是否存在未核实的实际行动范围。

绘制要求：
- 淡红/低透明填充，**醒目虚线**边界；不同主体的爱尔兰抵抗或其他反抗行动不得全部使用“英国新增占领”颜色。
- 明确标注 `historical_boundary_confirmed:false`、`fill_authorized:false`（**此字段指没有政治领土实色填充授权，并非禁止示意层浅色填充**）、`territorial_claim:false`、`area_sqkm:null`、`exclude_from_area_aggregation:true`。须有 `mapping_method` 或 `research_geo_method` 说明顶点如何确定。
- 具名锚点应位于相应示意区内；若只有一个城镇袭城，优先E类屏幕符号，不用任意几十公里buffer伪称受灾区域。
- 示意图必须**排除**出所有殖民面积汇总；不可依据示意面统计英国疆域、军事占领、焚毁面积、人口死亡、殖民收益；没有证据不能猜事件间受害情况。
- **全局可见**：很小的地理面在全球低倍率会不可见，允许改为**固定屏幕像素的提示圈**；放大后返回原局部示意面。屏幕圈的像素尺寸永远不是地面受损半径或面积。
- 原有红色B类、黄赭色土地剥夺政策研究面、紫色城市短期占据参考符号、青绿色当地反抗区不得混为同一种领土控制图例。观众不需要满屏精度警告；在详情与后台保留必要限制即可。

**旧有获批准例**：1540年代英苏战争研究交战区、1580—1583芒斯特英军扫荡与战争破坏、1584—1589芒斯特庄园政策研究面、1585—1586德雷克港市袭击位置符号、1595特立尼达西班牙人港—圣何塞局部行动影响区、1598黄渡口英军失败和爱尔兰抵抗。案例存在不等于每块几何边线都实测。

## 五、从一条史事发展成完整空间叙事

每一条适合地图叙事的记录至少检查：

| 内容 | 应回答的问题 | 数据/界面 |
| --- | --- | --- |
| 点 | 哪个具名地点发生了什么？历史与现代地名对应是否明确？ | 有来源的主事件点；点击后不再误称无法定位 |
| 线 | 史料是否真的说明从哪儿到哪儿，先后顺序是什么？ | 仅在确有顺序时补连接线；不把中间直线当真实行军路径 |
| 区 | 是否有独立的局部区域行动/具名地区波及证据？ | B或E的概略虚线面/固定像素位置提示，**不是自动从两点生成“历史边界”** |
| 后果 | 真实发生了杀害、毁城、赎金、拘押、短期撤离、土地剥夺或反抗吗？ | 资料卡清晰写谁对谁做了什么、后果、结局；有根据才写 |
| 来源 | 哪种来源支持每项关键断言？是否核查原文还是只核查目录？ | `source_ids` / `source_urls`，可点击原始研究与档案 |

**1595年特立尼达示范**：罗利舰队到Puerto de los Españoles（今Port of Spain）；再到San José de Oruña（今St Joseph）攻击、俘虏总督Berrío及焚城。有据二城可分别落点；按历史先后加直线示意；围绕两城可用浅红虚线的**局部叙事范围**。不能称英军占有特立尼达全岛；不能据直线推导实测行军路线；王室最终收益、原住民行动与伤亡数量没有证据不填。依据：NALIS国立图书馆地方史、British Library Add MS 36315/36316档案目录、原C11-S23/24及其已公布的1595事件。

## 六、时序、分层与前台交互

- 事件遵循发生年逐年揭示，已发生事实在同章可累计；**临时行动示意面/线应按其有证活动年份出现并结束**。一张1595年军事行动示意面不能因章节到1599年仍被当作实时驻军。与之不同，已证实的长期政治控制跨年延续至史料可支持的结束年。
- 按年末判断持续统治；明确跨月的短期驻城记录具体起止月日，不把当年的短期占据作为年末长期主权。
- 默认OSM现代地名底图保留，方便今昔位置对照。新对象复用已有“版图/事件”开关、数字事件聚合和右侧资料卡；不增加常驻复杂图例或冗长告警。
- 不再把原来仅有贸易航次次序线统一画成英军进攻线：D线根据行动主体和性质配色。线路必须有点击史料并在资料卡说明不是实测轨迹。
- 现有地图视觉仍以 [APPROVED_MAP_INTERACTION_STANDARD.md](APPROVED_MAP_INTERACTION_STANDARD.md) 的交互合同为准，不能因增加面/线遮挡原事件点或破坏双击地图定位功能。

## 七、团队GitHub发布与验收门禁

1. 先阅读 `AGENTS.md`、本规范、战争影响区规范、当前章节研究包和对应 `atlas-*.json`；避免重复研究及重复事件ID。
2. 优先权威历史档案、大学、博物馆及有注释研究；记下来源、原文检索深度、时间、地名精度和主体，不能造数字。若关系仅有编目，则如实标注 `catalogue_only`，不伪称已核原文全文。
3. 新增事实必须检查点→线/区→后果的**可证部分**；做不到的可保留点而不虚构路线与区域。每个新增对象必须有类别、时间、精度、史料索引和实际不意味着什么。
4. **主正式事件缺坐标但有已核具名地名，应作为优先修复**；改动对应detail notes、相关研究GeoJSON和自动回归，不改变原始事件ID或统计总量。
5. 保留历史界限未确认的机器约束、分期控制数据以及地图默认交互。新增测试必须验证年份启停、同地坐标对应、相关事件点击、线段只是顺序、虚线面的无面积统计，以及左栏事件双击可定位。真实浏览器截图与CI均通过才可合并。
6. 在**独立分支**提交并维护PR；合并后检查 GitHub Pages 部署，不能把PR创建或静态检查当作已上线。无法部署如实交接。新章初版有更新需在 `README.md`、相关技术文档和研究交接中链接此标准。
