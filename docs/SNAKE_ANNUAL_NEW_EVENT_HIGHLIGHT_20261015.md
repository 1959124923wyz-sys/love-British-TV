# 🐍 用户体验审查：逐年新增事件立即可见

2026-10-15｜独立风险审查员「蛇」｜1497—1599年时间轴

## 发现的问题

读者由1511年滑向1512年时，虽然新事件（奥唐奈重建奥马城堡）实际已经进入当前地图，现有标记却与已存在数年的历史事件无区别。越往16世纪后期，资料密集且多个地点被聚合成数字标记，读者更难知道**当年新发生了什么、发生在哪里**。仅靠增加新事件记录不能解决这个问题。

## 本次直接上线功能

1. **本年新事件始终突出**：每年仅对已发生且`event.year === selectedYear`的正式事件赋予金色外环和小型「新」标记；年号改为另一年时旧事件的金圈退出。红色战争影响区、历史政治领土、地区研究面、航线、长期驻军点**不会因只是持续存在而标记成当年新事件**。
2. **聚合也可以看出新内容**：如果旧事件与新增事件靠得太近，地图仍保留原数字聚合逻辑，旁边另标`+N新`，其中N只数该聚合里本年新增的正式事件。
3. **当年的记录放前面**：左侧事件列表只把`year===selectedYear`的事件优先排列，保留此前各年档案的时间顺序，并加上「本年新」小标签；避免过去发生的事件排在新事件前面。
4. **让结果可解释**：地图年号旁及事件列表上方显示“本年新事件N”或“本年无新增事件记录”；有无可靠地点分别对待。历史事件若没有可靠坐标，仍计入当年正式事件数，但**不会被虚构为一个新地图标记**。若关闭事件层，地图年号提示“事件图层已关闭”，不会假装金圈仍可见。
5. **保持观众掌控**：不因为时间轴切换而自动移动地图、强制缩放或打开文献；需要查看具体事件时使用现有的列表点选和资料卡中的「在地图上定位」。

## 时间连续性：1511→1512可复现

正式`data/atlas-1510-1519.json`中1511年没有新增事件记录；1512年有唯一一条事件：`1512-OMAGH-ODONNELL`，具备正式经纬度参考，标记在奥马附近。旧制度只会累计已发生事件，这次通过一年一年的新事件状态区分出新旧。

验证路径：访问`?year=1511` → 滑动至1512 → 看地图金色「新」环、左侧第一项`1512-OMAGH-ODONNELL`以及新增1项 → 1513年更新为4项 → 倒回1511时标记退出。

## 后续风险

本次标记**仅代表被记录为该年发生的事件**，不是该年新增的所有殖民利益、伤亡数量或政治控制面积。一个新发生事件可能只有城市或地区级定位，也可能根本没有可定位坐标；系统以实际证据区分，不能假设一年中没有记录就绝无英国军事行为。

对没有实测外边界的历史地区继续使用虚线；不能为了突出新增事件给旧殖民控制区强加新增红色疆域。
