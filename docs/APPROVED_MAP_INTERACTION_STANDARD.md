# 爱英TV · 已批准的地图交互模式

**版本：Approved UI Contract 1.0 · 基线 v0.9 · 2026-10-12**

**状态：用户明确批准，后续各年代、各维护者默认沿用。** 历史研究继续更新；本规范约束交互、图层和叙事呈现，不把当时的历史资料或年份范围冻结。

## 1. 地图的第一眼

- 地图作为视觉中心，使用现行深色版式。地图上以**简洁年份卡 + 可拖动章节时间轴**为主要常驻操作组件。
- 其他图层开关与图例收在侧栏，详细资料通过覆盖式右侧抽屉阅读；打开详情保持当前视角、年份和缩放。
- 每章原则上覆盖约10年，重要制度转折可独立切分。**本章所有已发布历史事件在本章中始终可浏览**；逐年滑动只移动时间焦点。历史形成的有效政治状态按照证据支持的起止年持续显示。
- 单独地点的一条事件用16类正式 SVG 类别图标；同区域多事件**默认一个小型深蓝金边数字主标记**，数字仅表示记录条数。最高重要性事件存在时强化边框。

## 2. 同地点多事件 · 正式交互

1. **未展开**：每组只显示一个36px数字圆点，不覆盖城市的底图信息，不出现大面积悬浮资料背景板。
2. **悬停或点击主点**：在当前地点周围**按需展开各条独立SVG小图标**。同时仅展开一组；点击另一组切换；点击空白或再次点击已固定主点收起。
3. **摆放顺序**：优先在右侧，实际空间不足时评估上方、左侧、下方。按当前容器像素检测页面边界及邻近主点，选择遮挡较少的横排或紧凑矩阵。
4. **没有合并内容丢失**：同一坐标的所有不同ID历史事件都可展开，每个子图标可以单独悬停和点击。缩放、切换年份或图层重新计算布局，不修改史实坐标。
5. **展开图形**：子图标为独立的透明 `divIcon`（类 `atlas-flyout-icon`）；只看到图标和非常轻的临时连线，**不出现整片方形/胶囊形背景**。
6. **地理精度**：不确定地点仅使用图标外圈虚线等形状信息，不在每个图标外侧外挂小问号。后台保留 `geo_precision` 等字段。

## 3. 事件简介始终压过小图标

- **主数字点不绑定常驻说明气泡**。用户一眼先看数字，只有选择展开后的具体事件图标才显示简介。
- 子事件悬停弹出短文字提示，使用专用 Leaflet `eventTooltipPane`，当前层级 `z-index: 820`，高于普通 marker（通常600）。
- Tooltip 采取紧凑宽度、可读行距和方向自适应；不能压在事件图标下面。点击事件后关闭该悬停提示，再在右侧抽屉显示完整事件详情。
- 右侧一级详情为简洁历史叙事；第二级「历史文献与详细考证」可展开读背景、影响、财政统计口径和原始出处。
- 地图缩放、改变年份和阅读史料时，保证不会出现挡住地图的大型信息板、残留聚合展开层或样式遮挡。

## 4. 历史地理边界显示

- 具有可靠实际控制证据的行政区与**仅据历史地点推导的参考范围**必须分层；推定范围只使用独立淡填充与高辨识度虚线。
- 加来历史地理参考范围采用约3.4px紫色短虚线、0.12轻填充和弱轮廓光晕，仅是帮助定位的研究图形。后续各地区可按缩放调整可读度，但始终以虚线表达证据状态。
- 不因研究包络几何面积计算殖民领土面积或利润；数据源与历史解释见独立研究文件。

## 5. 必须保留的技术契约

| 组件 | 规范 |
|---|---|
| 主点 | `atlas-aggregate` 深色圆形，约36px，金边 |
| 子点 | `atlas-flyout-icon` + `expanded-event`，外容器透明 |
| 图层 | `groups.cluster` / `groups.clusterExpanded`，同一时间一组展开 |
| 展开函数 | `expandCluster(group,pin=false)`，屏幕空间选择展开方向并避让邻点 |
| 简介层 | `eventTooltipPane`，z-index 820，高于标记层 |
| 简介触发 | **具体子事件**悬停，主数字点无大块浮动说明 |
| 悬浮关闭 | 点击具体事件、切换组、点击空白、章节/缩放重新绘制时清理 |
| 数据精度 | 保存历史原坐标，视觉排列只在像素坐标操作 |

项目后续可以重构代码、升级 Leaflet 及扩展时段，但必须保持**用户可观察到的行为**和上述数据约束；若采用其他等效实现，应同步调整测试以证明相同行为。

## 6. 维护交接与防回退

1. 接手先读本文件、`PROJECT_STATUS.md`、`CHANGELOG.md`、`RESEARCH_HANDOFF.md`。
2. 在提出任何地图标记改版前，以**v0.9 已批准模式**为默认基准；未经用户明确批准不恢复满图自动扇出、每处独立问号徽标、永久展开的地图侧挂板，或低层级提示框。
3. 在 `scripts/validate_atlas.py` 的 UI 规范断言和 GitHub Actions 发布流程中保留相应回归检查。涉及UI的提交必须验证：
   - 同区域至少2件事件可从一主点展开，分别点击；
   - 展开容器背景透明，仅有图标；
   - 简介置顶、悬停主圆点不生成巨大遮挡板；
   - 点击地图空白关闭并可再次展开；
   - 与周边点碰撞时转向、避让；
   - 十年本章所有事件可读，政治状态持续展示；
   - 经过考证的真实控制区与虚线推定包络各守其图层。
4. 回归还要关注桌面版真实截图。代码通过静态校验、GitHub提交成功均不能替代真实浏览器视觉验收。
5. 如未来用户明确批准新的模式，新增新的正式规范版本、测试和更新日志，保留旧版本的基线供追溯。
