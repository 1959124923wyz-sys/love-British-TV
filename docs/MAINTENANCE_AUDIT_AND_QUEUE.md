## 历史时间轴不可回退的验收约束

1. 事件图标、聚合数字、左栏、航线和里程碑只能在发生年份及以后显示。查看完整档案不改变地图年份。
2. 十年是章节组织单位，**不清零持续控制**。加来在已有史料支持区间内贯通相邻章节；图尔奈城市控制只在1513—1518年末快照可见，1519年末消失。
3. 证据不足的行政界线用独立虚线、浅填充；历史城市核心的确证驻军可用独立实色符号。不可把现代海岸线/地名凸包当作真实历史领土面积。
4. 点击地理对象不会产生方框，也不会移动视角；打开的右侧史料抽屉在拖动时间轴时保持打开，若倒退到尚未发生的事件之前则清空其详情。
5. 所有改动在独立分支完成、CI成功再合并发布；绝不把 GitHub commit 成功当作线上浏览器已验收。

## 安全重构规则

- 必须保留 `baseline/approved-ui-v0.9-20261012` 参考与完整研究来源。
- 结构性清理分批提交；一次只动一个可验证的子系统。每次提交都跑 `python3 scripts/validate_atlas.py`、`python3 scripts/validate_approved_ui.py`、`node --check app.js`、两份JS回归测试。
- 桌面实际视觉效果、边界点击、不同缩放等级及历史逐年动画，需在生产发布后再验收；CI静态检查不足以代替。
