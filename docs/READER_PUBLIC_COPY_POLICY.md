# 爱英TV｜读者界面文案永久约束（强制）

生效：2026-11-12。适用：全部世纪、全部图层、地图悬浮卡、右侧详情、专题文章、图例、章节标题/导语、年份状态、搜索、无障碍文案和未来新增组件。

## 一句话发布要求

**读者应当只读到历史事实、发生的时间、参与者、受影响者、结果和史料来源。不要向读者显示制图学术备注、数据工程解释、审稿／研究状态说明。**

### 严禁出现的语言类型

- “虚线为概略历史地理参考，边界未经历史地图实测配准。”
- “区域海河贸易通道，非英国河两岸主权。”
- “殖民省行政外缘不等于各地持续驻军。”
- “重叠的示意区块各有独立史料，不能将多层颜色叠加计算历史占地。”
- “该位置只是现代参考坐标”“矩形示意框不能代表实际占地”“边界仅作大致参考”“不能以该区块面积计算疆域”“未经历史测绘”“不作真实辖区推定”及其他换词版本。
- “本图只是研究试阅”“当前待核版图”“研究候审节点”“边界尚未完整审核”等编辑流程说明。

以上只是示例。以**内容用途**判断，不能用同义句、括号、提示图标、底部说明或折叠详情绕过禁令。

### 正确的读者正文

- 例：**“1762年英军攻取哈瓦那，1763年根据《巴黎和约》将其归还西班牙。”**
- 例：**“1783年之后，哈德孙湾公司在约克工厂附近重新开展毛皮贸易，与当地原住民商贸网络保持往来。”**（前提：相应原始记录有史料依据）
- 例：**“1710年英军及新英格兰部队攻取皇家港，城堡随后更名为安纳波利斯皇家。”**
- 对实际历史政治争议可以写事实本身：**“双方对某地的主权存在争议”**；不要写地图不能证明某类主权的编辑提示。

## 源数据与公开展示的严格分离

| 原始史料 / 地理数据 | 读者界面 |
|---|---|
| 保存 `note`、`source_urls`、`source_ids`、`geo_precision`、`geolocation_limit_zh`、`historical_boundary_confirmed` 等字段 | 使用清理后的简洁标题、当年的事实、有效史料来源 |
| 对空间不确定性、原住民主权、面积不可累加等事实做精细内部标记 | 地图几何仍以虚线/实线区分；不显示工程备注 |
| 保留历史原始文献、学术争议以及真实政治控制差异 | 可以写历史争议和真实治理关系，不能把制图谨慎语当正文 |

**切勿大规模替换底层JSON、GeoJSON、专题原稿、来源链接；不要在精度不足时画假实心历史疆域。**

## 每个前端作者的实现步骤

1. **先读AGENTS.md本节。** 新增可见字段时，输出前调用 `window.AtlasReaderCopy.clean(value)`；标签或类别名使用 `window.AtlasReaderCopy.label(value)`。
2. `note` 常包含编辑备注。**不要直接** `escapeHTML(item.note)`、`textContent = item.note` 或 `bindTooltip(item.note)`。简洁展示 `clean(item.note)` 的非空历史内容；如果为空直接省略段落。
3. 不添加“未实测”“非实际控制区”等 `title`、`aria-label`、HTML提示、地图字幕或章节旁注。
4. 最终保护器 `js/atlas-public-ui-guard.js` 在页面所有模块加载之后执行，监听后续DOM变化，过滤新加入的文本节点和属性。**不得绕过、移除或在保护器之后清空其监听器。**
5. 本地运行：`node scripts/test_atlas_47_public_copy_guard.js`、`python3 -m http.server 8765`，再在另一终端执行 `python3 scripts/browser_atlas_47_public_copy_guard.py`（需 Selenium/Chrome）。如果不能运行浏览器，提交Draft PR交GitHub Actions执行，**不得宣称已验收通过**。
6. 浏览器验收必须覆盖16世纪、17世纪、18世纪，以及北美单一区域和哈瓦那重叠区域；检查地图悬停提示、右侧全文、专题打开/返回、侧栏、图例、`title`和`aria-label`。
7. 新增一个同类案例时，先把原文加入 `scripts/test_atlas_47_public_copy_guard.js` 的样本，再修正文案处理链路；不允许仅让测试跳过。

## 审核门槛及现有清单

- 固定自动化：`.github/workflows/atlas-47-public-copy-policy.yml`。对新分支和PR运行Node文案测试、既有交互回归、Chrome UI文本扫描。
- 逐项宽口径扫描：`python3 scripts/audit_atlas46_editorial_copy.py`。第46批扫描935个文件、产生6332个宽标准候选片段（其中大量为纯研究元数据和假阳性）。GitHub Actions附件含每条文件路径、JSON字段或行号。
- **CI 通过、页面真实可见文本为零、历史原始记录保持完整，三者同时满足才可验收。**

## PR审查专用问答

- 有没有把历史文献中的“地图不代表……”说明直接拼接到 HTML 或 tooltip？
- 是否逐条区分历史事实与“我们如何画图”的编辑说明？
- 是否改变原始史料、原住民自治、历史控制属性、source_urls、虚线？
- 是否给所有新增的独立地图组件补了真实点击和可见文案浏览器测试？

不满足则退回修复。
