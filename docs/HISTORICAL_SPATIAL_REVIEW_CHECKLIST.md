# 爱英TV｜点、线、区及军事影响区审核清单

**生效：2026-10-15**。每位调查员/主编提交地图研究PR，按本清单自查。完整约束：[历史空间叙事与军事影响区正式标准](HISTORICAL_SPATIAL_NARRATIVE_STANDARD.md)。

## 史实与地点
- [ ] 事件的主体、行为、发生年、后果有史料支持；区分档案原件已读与目录仅见
- [ ] 史料明确给出具名地点：落历史-现代对应的城市/遗址/地区**参考点**，无须等待精确城墙坐标
- [ ] `geo_precision`、`position_type` 与 `geography_label` 诚实说明现代参照位置及限度
- [ ] 研究文件已有可信坐标但正式事件`lat/lng=null`：是否同步回填正式事件、详情和相关测试？
- [ ] 同名异地、遗址争议或地理尚不可识别：是否保留空坐标而非猜测？

## 军事空间叙事
- [ ] 是否分别评估点、顺序/行动线、局部影响区、历史后果；**两点不自动生成面**
- [ ] 关系线的行动顺序有证据？非实测行军/航海路线是否在数据和资料卡说明？
- [ ] B类影响区是否有具名地区多点/区域军事证据？是否限定在相应局部，不因同航次跨海连接成灾区？
- [ ] B类虚线淡填充和低倍率固定像素提示是否清晰区分屏幕符号与地理范围？
- [ ] 是否明确区分英军进攻、爱尔兰及其他原住民反抗、失败袭击、短期占城、土地剥夺、贸易与外交？
- [ ] 是否严禁将任意buffer、现代行政边界、战地包络当历史真实被焚面积、驻军边界或英王主权？

## 可审计数据与时间
- [ ] 每项数据有`start_year`、`end_year`与经核来源`source_ids`或`source_urls`
- [ ] 示意对象均`historical_boundary_confirmed:false`、`fill_authorized:false`、`territorial_claim:false`、`area_sqkm:null`、`exclude_from_area_aggregation:true`
- [ ] 每个研究面有具名锚点、`mapping_method`/同等方法说明、禁算面积与精度解释
- [ ] 时间轴无未来信息泄露；长期领土跨期延续，短期袭击/占城按实际年份/日期退出
- [ ] 新增对象不是重复历史事件ID；点击能追溯来源，资料卡写出**行动与后果**
- [ ] 自动测试覆盖坐标一致、年限、控制类别、面积禁令、图层开关、缩放可见性；浏览器全站回归通过

## Git协作与交接
- [ ] 提交在独立分支；文档指向规范与研究来源，不要求不懂编程的用户手动修改
- [ ] CI通过再合并；确认Pages真实发布状态，清楚区分“已提交PR”与“已上线”
