# 公共地图叙事、章节事件与持续状态规范 v1.0

> **交互规范优先级更新（2026-10-12）**：地图的同地聚合、事件展开、提示层级与避让现在统一按已获用户批准的 [v0.9正式交互规范](APPROVED_MAP_INTERACTION_STANDARD.md) 实施。以下历史叙事/章节状态规则继续有效；文中早期聚合列表或全图默认扇出方案属设计沿革，已由v0.9替代。

更新：2026-10-12 · 已由用户明确确认，网页维护与研究对话共同遵守。

## 一、公众语言
- 以当时人物、机构、地点和行动为中心，平铺直叙具体发生了什么。叙事语言自然，事实与来源相符。
- 事件正文建议1—3句，先事件本身，再在确有可靠证据时概括一句历史影响。读者可通过折叠的“历史文献”进入源材料。
- 地图详情不连续使用“并非、不能、不等于、没有证据表明、有限、无法证明”等反复否定句；需要说明地理精度时优先使用**正面命名**：例如“卡里克弗格斯城堡位置”“英王驻加来”“可能登陆的纽芬兰北部海岸”，由虚线/问号承担不确定性。
- 不在正文堆砌学者姓名、论文发表年份、证据等级与方法评论；此类信息留在 sources / research metadata / 点击展开的文献列表。
- 若某事件的结果范围证据很有限，优先只写可证的动作和具体结果，例如“基尔代尔军队攻占奥马，拆毁城堡后撤离”，由用户自行推断。
- 不得因减少提示而删除事实基础或夸大殖民控制、奴役人数和金钱额；原始source_ids、复核状态及不确定性字段继续保存，不影响内部审查。

## 二、时间模型
- 当前交互：1497—1499为第一章；1500—1509为第二章。今后原则上十年一段，在1707等重大制度节点灵活切分。
- 章节事件：进入某一章节后，列表始终显示**该章节全部已发布事件**，无需先把年份拨到事件当年。
- 地图：该章节的2/3级事件默认显示全部；1级按需开启；用户选择的具体年份只改变时间焦点和仍在持续的状态，不应清空同章历史记录。
- 章节色带：点击可以回到章节起年，事件年份标记可点击进入当年资料；提供轻量文字提示章节切换，禁止遮挡地图的弹框。
- 事件=某时发生过的行为。状态=实际政治统治、持续设施或关系等，携带 start_year / end_year / observed_through_year 等证据范围；事件可按章节收纳，持续状态在可证年份继续显示。
- 尚未核实持久性的军事胜利只记录为事件点；不能以攻占一次城堡自动触发长期统治区域填色。

## 三、同地点多事件
- 一处坐标可绑定多个不同年份或不同主体事件，不允许后加入的数据覆盖前面的记录。
- 相近事件在当前缩放级别使用屏幕像素聚合。**默认数字主点，悬停或点击后展开该组独立SVG小事件图标**，再点击具体图标阅读历史资料；同时只有一组展开，点击空白收起。展开时避开邻点与地图边缘，地图视角不强制变化。
- 经纬度保留原始记录，禁止为了好点击而凭空移动史实坐标。
- 如某历史事件仅可定位到城市，可以展示城市代表位置并保留 `geo_precision` 字段；原始历史地点考证另行由研究分支推进。

## 四、数据发布门禁
- 研究分支的原始材料首先完整归档到 `research/`，经过来源验证及口径检查的才合并进 `data/atlas-*.json`。
- 1500—1509年：爱尔兰编年史补充1503、1507、1508、1509年地方城堡控制更替；加来羊毛商团汇款有学术重建，公开金额保留来源与计量单位，避免重复计算。
- 研究分支中的 `HYPOTHESIS_ENVELOPES.geojson` 为学术探索草图，默认留在研究目录，**不得作为殖民控制实心面自动导入主地图**。城市政治据点可以沿可证年份持续显示。

## 五、验收
- 在1500、1502、1504、1509年切换，左栏事件总数保持稳定，显示整个1500—1509章的所有正式事件。
- 1501—1502年在伦敦宫廷出现三名大西洋彼岸居民的事件，应能从事件列表及同地点聚合图标中单独打开，不受1502年英苏条约事件遮挡。
- 1503/1507两条卡里克弗格斯记录与1509奥马、1508恩尼斯基林分别可选。
- 图层关停与地图缩放不丢失研究记录，列表仍可用于跳转详情。
- 右侧简明叙述、文献折叠；网页正文没有机械重复的否定判断或学者评论段落。
- GitHub Pages 静态检查成功不等于真实网页验收，线上截图与操作检查另行记录。

## v0.7 已执行的显示规则（2026-10-12）
- 主图本章保留全部事件，按缩放显示合理密度。单个地点显示SVG；相距很近的事件默认合成小数字主点，悬停或点击后按需展开独立SVG，并从右侧、上方、左侧、下方选择可读位置。原始历史坐标不改动。此条以v0.9正式交互规范为准。
- 一层显示自然历史故事或简洁政治关系；二层“历史文献与详细考证”展示事实来源、历史影响、地理及财政处理，点击原文献链接追溯原研究。对应资料在 `data/historical-detail-notes.json`。
- 实验性疆界几何在 `data/geography-1500-hypotheses.geojson`，只通过独立虚线图层公开；该图层表现早期法令地名线或记载地点分布，实际控制面使用单独经过认证的研究成果。地图面积严禁直接用于统治面积或获利计算。
- 主图只放年份卡与压缩的时间轴；地图图层/图例在左侧折叠；右侧详情以覆盖方式打开，保留地图已有中心与缩放。
