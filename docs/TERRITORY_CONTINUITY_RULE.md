# 爱英TV｜跨十年领土控制连续性强制规范

**提出日期：2026-10-12｜适用范围：1497年至当代的全部历史十年章｜状态：研究分支待主编合并。**

## 首要原则

**十年是资料整理与地图展示窗口，不是政治控制状态的自动结束日期。** 从一个十年切片进入下一个十年时，必须首先继承上一阶段仍可能持续的控制区、政治附属关系、驻军城市、地方法权和有条件证据支持的疆界，然后逐项寻找新史料判断其延续、扩张、收缩、易手、撤军或终结。**不得因为本章没有新事件，就让上一章的控制区或其历史地图符号凭空消失。**

相反，**也不得因为上一章有控制点或地图符号，就无条件把实控扩展到下一个十年的全部地区**；证据只支持到某一具体年份时，应记录“待验证的延续”，保留调查问题和既有证据，不能冒称已经核实。

## 每个新十年开工的强制步骤

1. 读取主干上一年代的 `data/atlas-*.json`、城市控制层、附属关系图层、虚线参考图层；同时读取上一年代的 `research/periods/*/CONTROL_EPISODES.json` 和本仓库的跨十年连续台账。
2. 将上一年代每一条地区/政治关系按**稳定 identity ID**列出，记录其上一阶段的控制者、控制类型、已核实区间、地图表示及 geometry evidence。对上一十年确实结束的关系，也保留“终止记录”，不能仅因数据不在新章而隐去发生过的交还。
3. 针对每条记录标明 `continued`、`expanded`、`contracted`、`transferred`、`ended`、`split_or_merged`、`uncertain_continuity`、`not_a_control_area` 之一；若同一地不同时期出现多次变化，应分多个年代/日期的 episode 记录，避免一个标签抹平时间变化。
4. 对所有已核实的长期持续状态，审查下一十年是否存在有效来源及能否按年末切片继续展示；找不到新证据的，放在待查清单并明确表示“未核实”，**既不主动当作消失，也不宣布已证实持续**。
5. 每一块地图区域都要回答：**上一期是什么、这一期初是什么、何年何月变化、这一期末是什么、证据在哪里、能画哪一种边界**。画图优先，事件点和叙事其次。
6. 研究完成时，先生成“本期 vs 上期控制区差异表”，再交给主编：至少覆盖所有上一期持续状态，解释消失项；记录新增或变化项及对应的历史地理证据。检查空间数据连续性以及起止日期，不准只统计新发生的事件。
7. 更新 `research/continuity/` 的机器可读过渡台账和该期 `PROGRESS.md`；把已确认、待核查、明确结束、仅地理示意分开存储，再通过独立PR交主编。不得擅自覆盖 `main`。

## 地理绘制与证据等级

- **可复核的历史实际控制区域**：有年代和来源支持的历史边界，绘制实心面。不得用现代行政边界代替无证古界。
- **已证实占领/治理的城市，但古城墙界线未核实**：允许根据具名史料位置绘制已批准的实色城市核心面积符号。它只是屏幕视觉半径，不是实测历史领土面积。
- **有关联却非王室直接统治的附属关系、领主权、保护关系、公司权利**：独立颜色/斜线纹理/类型字段，保留地方政权，绝不统统当作直辖殖民区。
- **乡村区域、历史法令线或现代地名推导包络**：只作为淡色虚线参考，字段注明 `historical_boundary_confirmed=false`，不能混入 `colonial_polygons` 或计算面积。
- **短期战斗、军队掠夺、远航和外交声索**：若不能证明长期实际管治，仅保留事件层或标明限时军事占领；不自动变为持续领土面。
- 所有状态起止必须记录明确年份；若存在月份/日期，保留更精确日期，遵守主站“选定年份的年末快照”规则。区分“最后一次证实的年份（observed_through_year）”与“历史上证实的结束日期（end_year/end_date）”，两者不可互换。

## 数据交接的强制字段

每个跨期控制状态至少含：
`stable_id`、`name`、`controller`、`control_class`、`previous_period`、`next_period`、`previous_status`、`transition`、`evidence_interval`、`next_period_review`、`source_ids`及对应`source_file`、`geometry_status`、`geometry_source`、`publication_gate`。

`evidence_interval.last_documented_year` 不得被当作主权撤离日期；`publication_gate` 只由主编评定，研究台账不得直接等价于已获批上图。控制区与视觉辅助图层、历史实际面积是不同的数据层。

## 1519 → 1520 过渡的固定历史基准

- **加来**英王军事/行政城市控制继续；旧控制符号不要在1520年被清除。**吉讷**在1520年代文献中可另作具名要塞/边境中心，不得将另增一个地点标记写成英国新征服大片领土。
- **都柏林英王行政核心**延续，但不能据此假定爱尔兰全岛成为英王直辖领土；当地盖尔政治、自治领主和边境权力另分层。
- **泽西岛**为英王属地；**马恩岛**有特别领主制度；**奥克尼及设得兰**属于苏格兰王权关联政体。上述不是同一类“英国殖民地”，其图层和政治身份应继续区分并补核跨年资料。
- **图尔奈**：1513年9月23日英方接管城市、1519年2月交还法国，故1519年末及1520年代均不再展示英王控制核心面积符号；交还事件和终止证据必须留在历史台账中。
- **苏格兰王国**在1520年代仍独立；英苏边界冲突不自动赋予英王苏格兰各郡主权。
- **Monasteroris**等1521年短期占领：若撤军日期不明，标记有限证据与“待核”，不得机械延续至1529或填满现代郡县。
- 1527年John Rut在纽芬兰有抵港文献，但不表明有英国殖民行政控制；不能生成控制区。

对应的机器记录：[`research/continuity/TRANSITION_1519_1520.json`](../research/continuity/TRANSITION_1519_1520.json)。该表是地图发布前的研究交接/审核清单，不是新历史边界的权威证明。

## 发布门槛

对任何时期 `YYYY—YYYY`，主编至少需要见到：
- 上期每条可能延续的控制关系都在本期有**继续、转变、终止或未核实**的明确去向。
- 原有地图边界及控区面积符号在年份滑块跨过整十年时，不因读取新JSON被无说明地删除。
- 失去占领的地点在结束日期后不再保持英方填色；有证据继续的控制区不因十年划分而自动结束。
- 所有历史推定区域继续只显示虚线，不把地名包络或示意圆算入殖民领土面积。
- UI审核必须以实际运行行为和地理数据为准，不能靠某个函数名字或字符串形式判定史实正确。

**优先级**：本跨期规范补充 `docs/MAP_FIRST_CARTOGRAPHY_STANDARD.md` 和现有v0.9/v1.2交互规范；若有冲突，应保留已批准交互，同时由主编明确核对新旧修订后再合并。
