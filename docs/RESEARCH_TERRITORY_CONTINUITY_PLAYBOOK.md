# 爱英TV｜调查员跨年代疆域连续性工作纲领

**版本：v1.0 · 2026-10-12 · 用户确认采用的调查原则。**
本文件是所有新历史十年调查（1490年代至当代）的**开工与交接操作规程**。当前保存在研究 PR #10，待主编审核合入 `main` 后成为主干规范。详细历史地图画法继续服从 [地图优先规范](MAP_FIRST_CARTOGRAPHY_STANDARD.md) 和 [界面交互规范](APPROVED_MAP_INTERACTION_STANDARD.md)。

> **第一原则：时间切片不重置疆域。** 上一年代已存在的控制关系，进入下一十年时必须逐项交代；没有新事件并不代表撤军，没有新材料也不代表已证实持续。地图优先表达真实控制范围的增加、减少、易手和时间变化。

## 一、每十年必须执行的七步闭环

| 阶段 | 调查员动作 | 输出给主编 |
|---|---|---|
| **0 接棒** | 读取上期 `data/atlas-*.json`、实际控制城市/区域层、特殊政制层、研究虚线；取得上一年年末 snapshot 和未处理疑点 | 上期所有 `stable_id` 的完整清单，不因换十年更换身份ID |
| **1 建基线** | 逐一登记地名、当时统治主体、直接/间接控制关系、起止日期、最近一次有文献证实的年份、原控制区/坐标/几何来源 | 期初基线、继续/终止/待核三栏；新地图点不能冒充新征服 |
| **2 查变化** | 优先查**实际疆域**及驻军/税政/法权：扩张、收缩、换手、撤军、返还、争议、独立；将每一件变化精确到可证最小日期 | `transition`及`before/after`、证据等级、来源与作用地理范围 |
| **3 复核地理** | 有已核当期历史边界才画实心区域；证明确实治理但没有城墙边线的城市仅画**地图面积符号**；地名包络、过时法令线、想象海岸一律虚线且分层 | 带年代、几何类别、绘图方法、可靠性、来源/版权的 GeoJSON；**不填写虚假的面积** |
| **4 产出年表** | 区分**事件发生年份**与**政治状态有效年份**。逐年年末状态连起来；一个十年内多次易手则分多条 episode，不能仅显示十年最终归属 | 每年 `year_end_snapshot`、日期变化清单、旧/新控制区增减对照 |
| **5 数据审核** | 校验上期每个 `stable_id` 在本期得到交代；控制主体名称符合当时国家；参考区无实心绘制；`source_ids`均能追溯；浏览器检查换年视角/图层 | 自动校验记录、未能证实的疑点、主编候审数据和独立地图预览 |
| **6 保存交接** | 在独立分支分批提交，更新 `PROGRESS.md` 并建草稿 PR；本期年末状态传给下一调查员，以免再从空白地图开工 | 本期 transition JSON、地图差异 GeoJSON、`HANDOFF.md`、源链接和下一年代接棒种子 |

调查应首先解决“**哪些控制区确实变化**”，然后再充实袭击、财政、航海、人物等事件点；没有证据的扩张不因急于上图而创造。

## 二、控制区身份和真实控制的区分

1. 每处持续政体/城市/堡垒有跨十年不变的 `stable_id`；改名、王位更替、更新GeoJSON不自动产生一块“新征服”。同一旧领土中新建独立地点（如1520年代英属Guînes）保留 `parent_stable_id`。
2. `continued` = 有证据或历史关联支持持续，必须注明适用期限；`uncertain_continuity` = 延续待核，既不宣布丧失也不标作已证实；`ended` = 有证据到达已知终止日期，按日期退出；`transferred` = 归属转移，双方均记录。允许 `expanded`、`contracted`、`split_or_merged`，每个变化都须有地域证据。
3. **图层不能混同**：英王直辖/占领、王室属地、当地独立王国、领主自治、保护国、军事短暂占据、宣称或航行、经济网络分别归类。苏格兰1707年前独立；属于苏格兰的奥克尼与设得兰不能涂为“英属殖民地”。马恩岛与泽西岛也不能简单涂成英格兰郡县。
4. **确定性属于具体地点、具体年份、具体证据**，不能从邻地或某个现代省界推广至整个地区。城市被攻陷、城堡被拆、舰队抵港、某法令公布，不自动生成大块长期控制区。
5. 任何前一期控制边线延用都必须标记：`geometry_source_period`、`new_period_reverification`、`boundary_uncertainty`；原始参考范围可作为虚线继续指引阅读，**绝不把继承自动视作“已核验新一轮古界”**。

## 三、必须保留的三种时间

| 字段 | 记录的事实 | 禁止误用 |
|---|---|---|
| `historic_start_date` | 有证据支持的政治取得、设官或军事进入日期 | 地图第一次出现标记的年份不一定是历史开始 |
| `historic_end_date` | 确认撤军、交还、独立、合并或实际换手时间 | 未查到后续文件 ≠ 历史统治结束 |
| `last_documented_date` / `observed_through_year` | **本批史料**最后一次确认的日期 | 不能自动当成历史失控或假设长期一直持续到现在 |

正式年份滑块以**当年年末政治状态**为准；当年发生的交还事件可以仍在历史事件层出现。例如1518年签订归还条约，图尔奈直至1519年2月撤军；1519年末的英国控制城市核心应消失。

## 四、疆域是否能上色：强制安全闸门

- **实际控制区域实心 Polygon**：只有对应年代、控制主体及历史边线都得到可复核的独立证据，并获主编批准，才可显示。记录 `source_ids`、绘图/拓扑方式、有效年份和审批状态。
- **城市实心面积符号**：证明当时确实驻军或行政管治即可在具名城址使用可读半径；`geometry_type=Point`，记录像素尺寸，绝不称作“测得城市国土面积”。
- **无法精准确定的区域**：仅展示虚线、淡填色、可关闭的参考图层；标记 `historical_boundary_confirmed=false`、`fill_authorized=false`，不得计入 `colonial_polygons` 或统计平方公里。
- **短时军事事件、撤退中的驻军、临时远征与殖民宣称**：优先展示事件点/线及临时 episode；除有持续军政证据外，不画永久领土颜色。
- 新旧几何轮廓变化必须可从记录说明来源；**换文件或地图分辨率改变不等于史实上的边境扩张**。

## 五、强制数据文件与字段

每期开工复制 [固定过渡模板](../research/continuity/templates/DECADE_TRANSITION_TEMPLATE.json)，而不是复制上一期已确定的年份结果。至少提交：

1. `TRANSITION_<previous_end>_<next_start>.json`：本期前后状态完整表；涵盖上一阶段全部控制身份（含应退出者），标明 `stable_id`、`parent_stable_id`、控制者、`transition`、原状态与新状态、三种时间、来源及地理绘制准入。
2. `CONTROL_EPISODES.json`：本十年中每次取得、撤离、换手或短暂军事控制单列；地点、开始/结束与失去信息的缺口不混写。
3. `SOURCE_REGISTRY.json`：所有史料对应到**主张**（claim）与日期，明确学术转述和原档差别；统计口径、版权、GIS定位精度独立保存。
4. `MAP_DELTA.geojson`（若确有可画空间对象）和原参考图层：所有 Feature 需有时段、类型、`stable_id`、`source_ids`、`uncertainty`、`approval` 和是否真实控制区域；即使没有新实控多边形，也应写明“零个获核准新增面积”。
5. `PROGRESS.md`、[主编交接模板](../research/continuity/templates/EDITOR_HANDOFF_TEMPLATE.md)：列出上期几处继续、几处结束、哪些尚不确定、哪年增减、待查档案和提交SHA。

### 必须用于检查的机器约束

- 前期每个 `stable_id` 必须在新期台账找到去向。**已知结束**与**证据断档**不能使用同一个枚举。
- 新增位置分类为 `existing_site_newly_mapped`（原有领土中新增图标）、`documented_new_control`（新增统治有凭证）、`not_a_control_area`；无类别/无来源不得视作地图征服变化。
- 任何确认改变控制权的记录至少标明有效年、证据ID与文献路径；没有确认时间，标记待核而非补充猜测年月。
- 旧疆界保持虚线，除非明确更新到新期**经审核的历史疆界**；事件保留原始 `source_ids`，不能因为编辑去重就丢史实。

## 六、每次移交前的七项验收问题

- [ ] 前一期**每一处**历史控制关系都被追踪到下一期，没有“到新十年就突然消失”的记录
- [ ] 新增和消失有明确事件或标为证据不足；长期现状未因文件数据止于旧年就自动判终止
- [ ] 年内具体变化日期与年末快照一致（尤其归还、短期占领、多次易手）
- [ ] 直辖、间接关系、独立政体、临时军事行动没有因统一着色而混淆
- [ ] 历史Polygon与研究包络、现代城市代表点严格分层；有争议的历史边线仍为虚线
- [ ] 所有地点、变化、金额及面积（如有）均能追溯到来源，且未用来源不支持的精度
- [ ] GitHub独立分支有真实可见提交，PR有主编入口与机器审计结果，下一阶段已获完整接棒清单

## 七、已完成的案例基线与后续扩展

现有 [1497—1529年控制区总台账](../research/continuity/CONTROL_TIMELINE_1497_1529.json)、[33年整合交接](../research/continuity/EDITOR_HANDOFF_1497_1529.md) 可作为**填表方法参考**，而非不可质疑的史料结论；主编在有更可靠档案时可修正，但不能无记录地重置 `stable_id` 或丢失来源。

- 1509→1510：六处上期政治地点全部交代并延续。
- 1513：英军占领图尔奈，增加**城市控制标志**；周边Tournaisis研究包络仍为虚线。
- 1519：图尔奈交还法国，英国城市控制标记退出；1519历史事件保留。
- 1520：旧加来边区下的Guînes单独上图；新增地点≠新国土。
- 1529→1530：先从 [待核状态种子](../research/continuity/TRANSITION_1529_1530_RESEARCH_SEED.json) 接棒，禁止凭空宣布1530已经核实的全部疆界。

## 八、保存与发布职责

研究员负责**来源 → 历史变化 → GIS → 年度状态 → 自检 → 提交分支 → 交接**。主编负责**复核和是否准入 → 合并生产数据及UI → 浏览器验收 → 部署**。两个阶段可以相互协作，但研究分支的草稿成果绝不意味着已发布。网页首屏尽量简洁，具体地理不确定性保存在数据字段与文献面板中。

版本修改要有 Git 提交及理由；若与用户已批准的地图交互规则不一致，不能在本研究规范内绕开审批。
