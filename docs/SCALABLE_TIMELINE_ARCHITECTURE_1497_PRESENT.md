# 可扩展历史时间轴交互架构｜1497—当代

状态：**v1.6 三级时间轴已实装于正式网站代码并处于发布校验阶段（2026-10-13）**。设计已获用户批准，以下说明兼做持续维护的交互约束。 核心约束：重大事年精确、持续领土不按十年清零、地图视角与史料抽屉保持、桌面优先、不让技术说明抢占地图。

## 现状和失效点

目前 `index.html` 中所有十年章节卡直接放进 `.chapter-track`，一年轴 `1497—1529` 又铺在同一面板上；扩展到50年时章节卡密度已上升，500年约50个章节只能被迫压缩至无法阅读。旧CSS里多个写死的 `nth-child` 百分比与年代数量相关，增添第五章就可能出现刻度错位。不应通过缩小字号或无限加宽面板解决。

## 推荐：总览 / 章节 / 年份三级时间轴

### 第一级：全历史总览（100年为单位）

- 一条固定高度、简化的世纪连续带。示例：`[1497—1599] [1600年代] [1700年代] [1800年代] [1900年代] [2000—至今]`。
- 每个世纪保持可读固定标签宽度；总览可以左右滑动，不要把500年的章节卡都压成一排。
- 点击世纪段只更换浏览窗口，**不直接改变当前选中历史年**，避免用户意外改变地图内容。可用二级定位菜单跳转其第一个有数据的十年。
- 总览的窄进度线可概览连续政治控制状态和出版覆盖范围，但不夸张编码无可靠面积的殖民地。

### 第二级：十年章节窗口（虚拟滚动，最多5张）

- 固定宽度，例如五个按钮槽位：`←` `1510年代` `[1520年代 当前]` `1530年代` `1540年代` `→`。只有当前十年前后最多两个章节卡存在于DOM中。
- 按左右箭头、滚轮水平滚动或顶部世纪切换查看不同章节；绝不缩窄卡片以挤出第六章。鼠标悬停显示该章简短标题；当前章始终居中。
- 选择章节，将年份设置为该章起始年，保持Leaflet地理视角/缩放、右栏开合及符合时态的持续领土；若尚未发布资料则保持当前年份不变并给简短提示。
- 完成整个世纪也只增加数据，不增加DOM卡片数。

### 第三级：本章10年精细滑杆

- 固定10年宽度（特殊首章1497—1499仅3年），默认刻度 `1520 21 22 ... 29`，滑杆在十年内逐年精准选择。这样整页500年也能每年足够宽地拖动。
- 上方固定大号当前年份和 `◀ 前一年 / ▶ 后一年 / 播放`。播放连续跨章；经过十年边界时二级章节窗口自动切换到下一章，不重置地理控制区或视角。
- 提供一个紧凑「跳转年份」入口（键入4位年份回车），并允许历史章节目录检索；读者不必拖动几十个世纪。
- 地图事件层的时间过滤仍由 `occurredByYear` 控制；疆域由状态起止年过滤。时间展示窗口只影响UI，不改变史料模型。

## 交互与数据接口

- `selectedYear` 为唯一历史事实时间，`focusedDecade` 为仅用于显示的导航窗口；二者不能互相偷偷覆盖。
- 由动态 `chapters.json`（章节起止年、标题、资源路径、审核状态）生成导航，无 `chapterOne`/`chapterTwo` 或 `nth-child` 硬编码。
- `selectYear(year)`：仅变动历史年；`browseDecade(decade)`：只滚动章节窗；`jumpToDecade(decade)`：跳到有效首年；`play()`：逐年延续到下一章。
- 时间轴刻度用 `(year - visibleStart)/(visibleEnd-visibleStart)` 计算，不应依赖年份常量、CSS child-index。
- 左侧列表/聚合只展示已发生事件；已形成政治关系状态按史料有效范围独立保留；跨章关闭默认未来档案。
- 事件双击定位仍只平移、不自动缩放；开放的史料栏不因浏览十年列表自动关闭。

## 两批实施（需要主编确认）

A. 先将年份选择/时间数据与可视UI解耦，建立纯函数和关键年浏览器用例（1497、1500、1510、1519、1520、1529、1530、1599、1600、1707、1800、1900、1997），**不改变当前显示**。

B. 以独立UI分支实现三级时间轴，保留已批准的颜色、字体和主地图布局。桌面检查1920px、1440px、1280px宽度，并在50年/500年合成章节列表上检验可读性、性能、滑动连续性和键盘操作。用户批准截图后替换主站；不得在本次航线热修复中顺手替换整个时间轴。

## v1.6 实际实现与验收

- `data/chapters.json` 维护已审核章节的起止年份、标题、数据路径和发布状态；尚未发布的十年仅为目录入口，不创建虚构历史事件。第一个非完整十年仍为1497—1499。
- 上层固定15—21世纪，浏览世纪只调整 `browsingDecade`；二级十年视窗最多同时生成3张可视章节卡（相邻前/中/后），左右箭头及水平滚动支持跳过百年；点击未发布章节不触发 `setYear`。
- 底层 `yearRange` 每次只覆盖当前正式章节（通常10年），每格一年；本章已发生事件的节点按 `(year-chapter.start)/(chapter.end-chapter.start)` 布局，保证未来扩展不再修改刻度CSS。
- `jumpYear` 支持输入已发布的四位年份后回车直达。底层上一年/下一年和播放可以跨越章节边界，但始终受已发布年份上限约束。
- 1500/1510/1520/1530的地图政体连续、单击打开史料、双击定位不缩放、详情栏保留、史料不提前泄露等之前已批准的地图行为仍属于回归契约。
- `scripts/test_timeline_scale.js` 测试50年、500年导航容量与史料清单；`scripts/browser_smoke.py` 验证实际Chromium中只保留三张卡片、浏览未发布世纪不影响地图，以及1920/1440/1280px桌面宽度。
- 本次**未接入1540年代及以后研究史料**，不得将可浏览的世纪按钮理解为已有对应地图。后续需先让调查员史料通过PR独立审核，再扩展正式Atlas资料。

## v1.6.1 半世纪翻页升级（2026-10-13）

用户批准中层使用**五章一页**，每次点击左右箭头直接翻50年。常规翻页严格按世纪上下半叶对齐：1500—1549 → 1550—1599 → 1600—1649 → 1650—1699，直到2050—2099。1497—1499属于特殊序章，拥有1490—1539的独立序章浏览窗（相邻保留已出版1500年代）；当读者选择1500及以后的正式年份，自动回到对齐的五十年页面。浏览不影响 `year`、地图缩放与侧栏。

此变动替换v1.6中的“三张”窗口约束，历史上已发布的五章数据不受影响。未来章节只在 `data/chapters.json` 获得审核发布资格后才能跳转真实年份。浏览器回归测试固定每页5卡、1500—1549↔1550—1599整页翻转、500年多页行走以及1280/1440/1920桌面不溢出。研究PR #25独立更新后第五章已增加到27事件、8制度地点，新史料数值不作为实际殖民净利。
