# 可扩展历史时间轴交互架构｜1497—当代

状态：产品设计方案（2026-10-13）。**本文件为建议，不代表已替换正式网站时间轴。** 核心约束：重大事年精确、持续领土不按十年清零、地图视角与史料抽屉保持、桌面优先、不让技术说明抢占地图。

## 现状和失效点

目前 `index.html` 中所有十年章节卡直接放进 `.chapter-track`，一年轴 `1497—1529` 又铺在同一面板上；扩展到50年时章节卡密度已上升，500年约50个章节只能被迫压缩至无法阅读。旧CSS里多个写死的 `nth-child` 百分比与年代数量相关，增添第五章就可能出现刻度错位。不应通过缩小字号或无限加宽面板解决。

## 推荐：总览 / 章节 / 年份三级时间轴

### 第一级：全历史总览（100年为单位）

- 一条固定高度、简化的世纪连续带。示例：`[1497—1599] [1600年代] [1700年代] [1800年代] [1900年代] [2000—至今]`。
- 每个世纪保持可读固定标签宽度；总览可以左右滑动，不要把500年的章节卡都压成一排。
- 点击世纪段只更换浏览窗口，**不直接改变当前选中历史年**，避免用户意外改变地图内容。可用二级定位菜单跳转其第一个有数据的十年。
- 总览的窄进度线可概览连续政治控制状态和出版覆盖范围，但不夸张编码无可靠面积的殖民地。

### 第二级：十年章节窗口（虚拟滚动，最多5张）

- 固定宽度，例如五个按钮槽位：`←` `1510年代` `[1520年代 当前]` `1530年代` `1540年代` `→`。只有当前十年前后最多两个章节卡存在于DOM中。
- 按左右箭头、滚轮水平滚动或顶部世纪切换查看不同章节；绝不缩窄卡片以挤出第六章。鼠标悬停显示该章简短标题；当前章始终居中。
- 选择章节，将年份设置为该章起始年，保持Leaflet地理视角/缩放、右栏开合及符合时态的持续领土；若尚未发布资料则保持当前年份不变并给简短提示。
- 完成整个世纪也只增加数据，不增加DOM卡片数。

### 第三级：本章10年精细滑杆

- 固定10年宽度（特殊首章1497—1499仅3年），默认刻度 `1520 21 22 ... 29`，滑杆在十年内逐年精准选择。这样整页500年也能每年足够宽地拖动。
- 上方固定大号当前年份和 `◀ 前一年 / ▶ 后一年 / 播放`。播放连续跨章；经过十年边界时二级章节窗口自动切换到下一章，不重置地理控制区或视角。
- 提供一个紧凑「跳转年份」入口（键入4位年份回车），并允许历史章节目录检索；读者不必拖动几十个世纪。
- 地图事件层的时间过滤仍由 `occurredByYear` 控制；疆域由状态起止年过滤。时间展示窗口只影响UI，不改变史料模型。

## 交互与数据接口

- `selectedYear` 为唯一历史事实时间，`focusedDecade` 为仅用于显示的导航窗口；二者不能互相偷偷覆盖。
- 由动态 `chapters.json`（章节起止年、标题、资源路径、审核状态）生成导航，无 `chapterOne`/`chapterTwo` 或 `nth-child` 硬编码。
- `selectYear(year)`：仅变动历史年；`browseDecade(decade)`：只滚动章节窗；`jumpToDecade(decade)`：跳到有效首年；`play()`：逐年延续到下一章。
- 时间轴刻度用 `(year - visibleStart)/(visibleEnd-visibleStart)` 计算，不应依赖年份常量、CSS child-index。
- 左侧列表/聚合只展示已发生事件；已形成政治关系状态按史料有效范围独立保留；跨章关闭默认未来档案。
- 事件双击定位仍只平移、不自动缩放；开放的史料栏不因浏览十年列表自动关闭。
