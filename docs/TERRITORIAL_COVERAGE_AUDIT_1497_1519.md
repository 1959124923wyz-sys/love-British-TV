## 面状绘画等级

- **A级**：具备历史测绘或足够考证的矢量疆界 → **真实历史区域多边形**，可计算历史面积。
- **B级**：证实某城市或群岛归属/制度，但缺当年边界 → **位置明确的实色或纹理面积符号**，可点击史料，禁止用符号计算国土面积。
- **C级**：史料可支持概略地方分布、强弱影响而无精确边线 → **淡色虚线与纹理参考范围**，来源与方法入 Git。
- **D级**：短期军事/外交/经济史事 → 点线事件层，按年显现；后果另按政治状态时段绘制。

## 未来搜集与绘图优先队列

1. **补齐岛屿几何**：以可授权公开地理资料获取马恩、泽西、奥克尼和设得兰的海岸线，随后核定本章历史法权。现代海岸轮廓必须标为地图参考形状，不能代替历史政区。
2. **攻克Calais Pale边界**：英国国家档案馆、地方历史地图和学术史地文献交叉验证。确定边线可涂实心；只知城市统治先保留城市核心符号。
3. **爱尔兰Pale与地方政治势力**：核对1488法令地名、城市和城堡驻军实际时序、自治地方领地与法律辖区；根据证据分别画面，禁止一色涂满。
4. **Tournaisis**：在经批准可复核的独立历史疆界出现前，保留城核实色与乡村虚线的证据区分。
