# 爱英TV｜地图界面改为两个可叠加开关：版图 / 事件

**状态**：候审实现，独立分支 `ui/map-modes-simple-20261013`，未合并主站。  
**修订依据**：用户明确指示：**只保留「版图」「事件」两个层级，允许同时勾选；战争要素按含义归入两者；1548年多行统计卡已由其他改动解决，不要在此修改。**

## 最终交互行为

| 版图 | 事件 | 地图结果 |
| --- | --- | --- |
| ☑ | ☑ | **默认**：国界与历史控制区、战时实际驻军及交战带，同屏叠加战役、掠夺、航海与政治事件图标 |
| ☑ | ☐ | 只保留历史版图／控制点、军事控制地带、蓝紫条纹争夺带等；关闭战斗事件与航海符号，以便单独读版图 |
| ☐ | ☑ | 只显示历史事件／航行／登陆／王权宣称标记及地图基础地理，不显示主权彩色面、军事控制圆和交战面 |
| ☐ | ☐ | 只显示基本地形路网底图、地图时间轴与历史事件目录，不叠加研究对象 |

**战争拆分原则**：
- **版图侧**：英格兰、苏格兰、法国各国家底色；经过来源审核的占城和驻军地点；英军控制/军控概略面；蓝紫交战区与战线，以及法军对抗据点等。这些图形只证明对应的历史控制、军事影响或争夺，未审核的边线依旧虚线。
- **事件侧**：平基战役、1548年哈丁顿围城、1544焚掠爱丁堡、撤军、航海等有年份的历史事件图标及聚合；不会重复生成殖民土地面积。
- **两个选项相互独立**：普通HTML复选框，**不是单选模式**；不因滚动时间轴而自动强制切换；勾选操作立即刷新，保留原地图中心、比例和历史年份。
- 仅做地图对象筛选，**左栏历史事件目录始终保留**；需要聚焦某一条被关闭的事件仍可从目录查看其档案详情。

## 技术更改及已有代码保护

- `index.html`：右上仅两个勾选框 `#mapLayerTerritory`、`#mapLayerEvents`，**两者默认勾选**，左栏留一个折叠式「地图图例与精度说明」。过去十项底层复选框仍有唯一隐藏节点 `#internalLayerFlags`，是兼容各旧函数的内部状态，不提供用户操作。
- `app.js`：`syncMapLayers()`把新版图开关联到原史料`toggleTerritorialFootprints`、`toggleControlAreas`、`togglePoliticalRelations`、`toggleKingdom`、`toggleHypotheses`；新事件开关联到`toggleRoutes`、`toggleCandidates`、`toggleClaims`、`toggleEvents`。蓝紫战区和驻军附近军控分布由版图层开关统一控制；**完全删除第三个「战况」模式**。
- 「事件」层未勾选时，常态事件标记隐藏；史料列表仍可查询；版图层可在较大的比例尺（缩放≥6）重新显示细小驻军点，避免全国视角一片密密麻麻的圆圈。
- `css/dark-atlas-v2.css`：仅新增双复选框与折叠说明样式，保留原本的`map-year-card`、`year-control-status`和统计卡相关CSS原封不动。
- **1548年统计卡**：`app.js`中`renderAnnualControlSummary()`已经完整恢复为当前主分支的版本；本PR**不重新设计、不缩短、不修改统计卡**。避免与其他维护对话已解决的调整相互覆盖。主编若已在别的分支修改此卡，以最新合并版本为准。
- 这次提交不改变`data/atlas-*.json`、`war-occupied-zones`、`war-contested-zones`、`military-control-points`等史料或几何，不捏造点位与边界。
- 尚未合并的 [PR #38](https://github.com/1959124923wyz-sys/love-British-TV/pull/38) 1547—49苏格兰英军北推紫色军事影响带，需要主编在合并时接到**版图层**。不能恢复独立「战况」模式。

## 主编验收清单

1. 两个 checkbox 可以独立勾选／取消，**4种状态均可用**；起始默认两者勾选。
2. 1548年勾选「版图」显示主权底色、英军驻点与蓝紫争夺带；取消「事件」应消除大号战役事件聚合圈，但保留军事控制图形。
3. 勾选「事件」时仍能看到战役和掠夺事件符号；取消「版图」应消除紫色疆域填充、英军驻地控制圈、蓝紫争夺带，而不是仅隐藏某一种细分图层。
4. 双选时可同时看到版图与战争事件；全关只剩基础地理与历史时间轴。
5. 切换年份、放大缩小、再次开关均保留用户所选状态。小比例尺低优先级密集标记自动收敛；具体驻点按缩放展开。
6. 不能改变既有1548年统计卡的布局与数据，也不能在PR合并时覆盖维护分支对该卡的新修改。
7. 现有来源精度、历史虚线、蓝紫条纹含义和点击史料详情不可丢失。
8. 本PR静态代码与四组合模拟QA完成后再合并；**浏览器真实渲染与跨设备验收尚需编辑进行，不能预先宣称完成**。

**结论**：用户无需理解十个底层概念。地图只问“要不要显示版图？”和“要不要显示事件？”，两种信息按照常见地图应用的叠加图层习惯独立切换。
