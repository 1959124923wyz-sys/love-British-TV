# 爱英TV｜地图显示模式简化：主编交接

**分支**：`ui/map-modes-simple-20261013`（基于当前 `main`）  
**状态**：界面候审实现，未合并正式网站。  
**问题截图**：1548年地图左栏有十个难懂的独立图层开关；关掉一个“历史疆域”之后驻军圈还出现或突然消失，让读者误以为史实变化；地图缩放至整个不列颠时许多驻军圆圈压在爱丁堡及海峡上；年份总结框占地图太多空间。

## 交互设计：用户只表达一个目的

右上角固定三项选项，**不再要求普通用户理解底层十个图层**：

| 用户模式 | 看到什么 | 自动隐藏 | 默认 |
| --- | --- | --- | --- |
| **版图** | 国家主权底图、已有疆域与合法附属/特殊政治关系、英王城市控制点和局部驻军（大比例尺才出现） | 战争斜纹和进军效果、历史事件聚合点、航海点 | 供随时选择 |
| **战况** | 国家主权底图、已证据城镇/驻军、英军驻点附近虚线参考面、蓝紫争夺地带 | 非军事政治纹理、事件聚合圆、航海点、主权声索 | **进入1540年代时自动采用** |
| **事件** | 历史事件、重要地点、远航与登陆点、国家主权底图 | 概略军区、大型虚线占领面、蓝紫条纹、孤立驻军虚线环 | **进入1497—1539时自动采用** |

普通阅读路径为：**年份滑块选择1548年 → 默认看战况 → 放大到苏格兰后据点分散显现 → 点击具体地图对象读资料**。历史节点的来源与研究数据未减少，只隐藏对当前用途无帮助的视觉标记。

**用户主动切换后保留所选模式**，直到再次点击；只有未曾主动选过时按时代自动选模式。各按钮`aria-pressed`标识，键盘可操作，触控目标明显。图例合并为侧栏中一个默认折叠的“地图图例与精度说明”，仅四种日常可见符号说明，不再公开十个实现层的专业名称。

## 已实施修改

- `index.html`：移除可见的十个checkbox及13条重复图例；右上新增`#mapModeSwitch`三按钮；左栏只保留默认折叠说明`#mapModeHelp`。为了不破坏原Leaflet图层函数，原十个开关节点仍存于`#internalLayerFlags[hidden]`，只供三种模式设置，不作为界面控制。
- `app.js`：新增`mapModePresets`、`syncMapMode`及按时期的自动默认值；依模式同时控制地图已有图层，保留原有点击事件和史料弹窗；版图/战况模式在地图缩放小于6时不绘制密集政治地点聚合与大型军驻圆圈，放大才显示；战争虚线/斜纹仅在战况模式出现。
- `css/dark-atlas-v2.css`：三选一紧凑按钮、移动设备自适应、折叠图例样式，1548年原先4—5行的战事统计卡改为**一行简报**，不再占据大面积地图。
- 缓存版本查询更新为`map-mode-ui1`，避免合并后浏览器继续引用旧JS/CSS。

## 设计边界

1. **史料与战区范围不改变**：不修改历史地理文件、占领边界、事件记录、来源ID及年度统计的原始口径；仅改显示。颜色强度不代表统治百分比。
2. **真实据点和示意战争范围仍有差别**：战况模式是显示分类，不会把条纹区当成英国领土。
3. **地图按缩放收敛**：缩到整个英国看概况，放大到具体地区看点；**不是丢弃研究数据**。
4. **事件清单与点击详情继续可用**：左栏“已发生事件”保持独立，可打开其档案；点位通常在“事件”模式下呈现。
5. **主编尚未合并的PR #38紫色进军带**：本PR没有悄悄复制PR38到生产环境。建议先审核其历史精度，再在战况模式的Leaflet图层条件中增加该候审`warReach`覆盖；不能在“版图”模式把军事影响误当领土。

## 验收场景与结果

| 场景 | 预期 |
| --- | --- |
| 进入1548年的第六章 | “战况”自动选中；出现蓝紫交战区、紫色据堡参考；左栏不见大堆checkbox |
| 不列颠全国视图（缩放<6） | 大型军驻虚线圆圈隐藏；年份小卡只有简洁一行交战摘要；苏格兰仍蓝 |
| 放大到哈丁顿、劳德尔（缩放≥6） | 有史实依据的驻军标记重新显示；点击可打开史料 |
| 切为“版图” | 保留主权底图和地点/附属关系；战区斜纹和事件大圆消失 |
| 切为“事件” | 事件聚合和已记载航行出现，军控虚线环与争夺区隐藏 |
| 切换年份 | 若用户未手动改模式，则1497—1539偏向“事件”、1540—1549偏向“战况”；手动模式保留 |
| 移动版宽度 | 模式选择向右下方避开左侧年份卡；图例继续折叠 |
