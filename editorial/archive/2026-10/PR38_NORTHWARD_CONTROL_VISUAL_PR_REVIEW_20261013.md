# 第六章地图修订候审｜英军紫色为何需要北推，但不能把爱丁堡画成英占

**问题截图**：1540年代战争已延伸至爱丁堡和平基战场，主权底图苏格兰维持蓝色，而英军紫色只呈少量孤立“驻军大饼”，英格兰边界以北缺少战争军事活动伸入感。用户要求紫色随军势北推、英苏前线使用蓝紫条纹、收复后紫色回退。

**处理分支**：`research/1540s-scottish-warfront-visual-20261013`，直接以最新`main`为基线，独立候审PR，不修改主站`main`。  
**产出**：`data/war-front-corridors-1540-1549.geojson` + `app.js` 接线 + `index.html` 图例 + `css/dark-atlas-v2.css`图例与可点击样式。

## 证据支持什么、不支持什么

- 苏格兰历史环境局 [平基战役官方遗产登记（BTL15）](https://portal.historicenvironment.scot/apex/f?p=1505:300:::::VIEWTYPE,VIEWREF:designation,BTL15) 记载英军1547年由Berwick沿东海岸北进，于9月10日在Musselburgh附近击败苏军，骑兵追击近爱丁堡城门。它**不证明英军1547年占领爱丁堡或长期统治整片东洛锡安**。文件同时记载英军1544年通过Leith摧毁Edinburgh的袭击事件，不等于当年稳定占有。
- 苏格兰历史环境局 [哈丁顿18个月围城叙述](https://blog.historicenvironment.scot/2022/07/the-story-of-scotlands-longest-siege/) 解释，英军1548年通过在东苏格兰建立多个据堡以扩大地方军事影响、压服领主。约2,000守军被约12,000苏法军围攻；法苏力量与英军各自在不同地点活动。**要塞能出击／互通补给，不等于沿途全部乡村均受英王稳定行政统治**。
- 第六章正式数据 `military-control-points-1540-1549.geojson` 已有Eyemouth、Hume、Dunglass、Lauder、Haddington等有据守点，现有`war-occupied-zones`只有各驻地小紫色示意范围，`war-contested-zones`有交战条纹，却没有跨驻军网络的独立紫色军事活动层，这正是截图违和感。

## 新增第四种地图层：英军进军／补给影响走廊

**这不是第三类领土主权、也不是准确“实际控制区”边界。** 对读者必须显式显示“军事推进／影响范围（示意）”，不可把Polygon面积加入英国疆域统计；行政/政治主权仍用苏格兰底色，英军确实驻守的城堡仍用旧Point和驻地紫色局部层。

| 年份 | 紫色覆盖的历史事实及处理 | 实控声明 |
| --- | --- | --- |
| **1544** | Leith—Edinburgh地区短时英军袭击、焚掠；独立淡紫孤立阴影，不连到英国本土 | **仅袭击，没有全年英占爱丁堡** |
| **1547** | Berwick→苏格兰东海岸→Pinkie/Musselburgh→爱丁堡东郊附近的**军队推进示意带**，颜色淡紫、虚线；叠加已有平基蓝紫斜线战事标志 | 有真实战役及追击，但**不能称整条走廊为年末稳定英控** |
| **1548** | Border/Eyemouth→Dunglass→Haddington主体及Lauder补给枝线，显示英军军堡网络北上，法苏围城斜线保留 | **紫色控制影响不是一片连续行政领地，真实已证是城堡驻军点** |
| **1549** | 哈丁顿英军退出；紫色主体向东南／边境方向收缩，只保留Eyemouth、Dunglass、Lauder作为军事网络概略参考 | 哈丁顿不能在1549年末继续显示英军实控；非精准撤军日期 |

**几何**：`data/war-front-corridors-1540-1549.geojson`共4组Feature（1544/1547 Polygon、1548/1549 MultiPolygon），内有6条封闭环。它们由研究员围绕有史料的沿海行军、城堡及城镇地名手绘简化顶点，无16世纪实测政治边线；GeoJSON所有Feature满足`fill_authorized:false`、`historical_boundary_confirmed:false`、`area_sqkm:null`、`area_statistics_forbidden:true`，附已有Atlas中可引用的`source_ids`与HES原文URL。

**核心禁忌**：
1. 1547年进军至平基、追至爱丁堡城门 ≠ 英军攻占并治理爱丁堡。
2. 1548年Lauder、Haddington补给线路 ≠ 英国控制所有线路之间的田野与村庄。
3. 1549年Haddington已失，年末紫色必须撤退；Hailes于1548同年被苏军收复，不能再延续。
4. Dundee/Broughty更远据点属于独立飞地，不与南部虚线补给带硬连。
5. 现代县界、HES战场**指定保护范围**都不是英军1540年代控制疆界，勿复制保护区Polygon当英国领土面积。

## 网站渲染接入与交互设计

- `app.js` 原本仅把`war-occupied-zones`按活动驻军点渲染成小紫块、`war-contested-zones`绘制蓝紫条纹。现在又读取新`data/war-front-corridors-1540-1549.geojson`，创建`warReachPane`（层级461）置于交战条纹462和现有驻地局部紫色463**下方**。因此战争冲突区的蓝紫纹理不会被北推的紫色覆盖。
- 地图年份在1544、1547、1548、1549切换时，新紫色低透明度带随数据显隐、缩放时更新；1549年回退。其它年份不出现新紫色军事进军面。
- 和原来驻军/交战层共享现有地图开关「地理轮廓」与「实际控制城市与局部驻军」，不新增用户界面上的额外隐藏按钮。缩放 >9仍关闭低精度宽带，防止像是精确宅基地界线。
- 新虚线Polygon可鼠标悬停／点击，调用已有`openTerritoryDossier(feature, 'war-reach')`，展示年份、史料ID/来源链接、精度声明和**禁止称为整片英国统治的提示**。
- 图例增加“**紫色虚线延伸带 · 战时进军／补给影响（非实际占领边界）**”，区别原有“驻军驻点附近紫色”和“蓝紫争夺区”。
- 未添加统计英占领土面积算法；不改变原有`data/atlas-1540-1549.json`、`military-control-points`及主权边界数据。

## 主编要验收的具体画面

- 切**1547**，苏格兰东部Purple视觉从Berwick起经东海岸延至Pinkie/爱丁堡东方，但**Edinburgh城市本身没有英占城圈**；蓝紫战斗层仍在紫色阴影上方。
- 切**1548**，东海岸至Haddington与Lauder的英军军事伸入与要塞支撑更清楚，苏格兰底色仍蓝；Dundee/Broughty仍为孤立点，不连一整块紫。
- 切**1549**，Haddington年末英军据点与附近北推紫色同步退去；沿边境与其他驻军仍见模糊带。切1546时不能出现1547以后才有的进军。
- 点击任一新紫色区均弹出年份、历史说明及“**不等于全域稳定占领**”和实际来源。
- 地理图层关闭后不再显示紫色走廊；zoom 10+隐藏近似面，不遮盖真实地图。
- 修改为**候审改动**；正式Pages需主编合并并作浏览器实际检验后才可见。此分支的JS语法和GeoJSON环闭合/自交/史料ID校验已经独立完成，但**尚不能宣称网页视觉经过实际浏览器测试**。

## 与第七章1550—1559衔接

第七章PR #33已研究1550英军从苏格兰多堡撤出、爱尔兰1556定居殖民、1558英属Calais Pale失地。本次1549紫色退潮原则必须与1550后英军在苏格兰的实际撤走连续衔接；第七章不得在主权蓝底上凭空复活任何北推英国领土。沿海阵地和海岛另设孤立驻军层，法军驻军也不代表法国吞并苏格兰。
