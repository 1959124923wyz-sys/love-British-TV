# 主编直用｜1510—1519年历史事件预审包
**编制日期：2026-10-12｜状态：主编审阅候选，未合入生产地图**
来自研究员1号及持续研究分支 `research/territorial-1510-1519-20261012`（Draft PR #6）。本文件所在分支从主干 `main` 独立创建，仅提交审核准备资料，不修改已上线的地图或正式数据。

## 主编只需先打开三份文件
1. [ATLAS_REVIEW_CANDIDATE.json](ATLAS_REVIEW_CANDIDATE.json) — **15条已整理事件、7条持续政治据点、22条绑定来源**。使用与主站 `data/atlas-1500-1509.json`一致的主要字段：`id/year/start_year/end_year/name/category/icon_code/lat/lng/geo_precision/description/source_ids/certainty/significance`。缺精确地点的事件坐标为`null`，仍可在本章事件列表显示。
2. [DECISION_MATRIX.json](DECISION_MATRIX.json) — 原始研究的**19条事件逐一映射**至15条预审与4条继续研究项目；没有丢弃史料。每条有历史源ID和主编需要注意的具体风险。先选择性审核即可。
3. [SOURCE_PROVENANCE.json](SOURCE_PROVENANCE.json) — 22个直接显示的文献ID、网页及阅读等级，特别列出原始手稿未读、晚出编年史、图尔奈主权解释与1517 Rastell父子重名问题。

高颗粒度历史材料仍在研究分支的 `research/periods/1510-1519/`，原始史料线索与经济记录等 **全部保留**。主编不需要为了一条事件浏览该专题下所有的研究JSON。

## 可以优先确认的时间线
- **1513-09-23** 图尔奈被英军攻下、英王设置总督/驻军；地方市政议会保留其部分权力。前端政治地点从1513年开始。
- **1518-10-04** 签署图尔奈交还法国的条约，但当年英军还在图尔奈。
- **1519年2月** 图尔奈实际交还法国。若时间滑块1519表示**年末局势**，`tournai-occupied-city-1513` 不应显示；但1519年交城历史事件始终保留在该章列表。
- **1513-09-09** 弗洛登战役苏格兰国王战死，苏格兰仍为独立王国，不修改苏格兰为英王属地。
- **1515** 爱尔兰改革报告；**1517** 王室支持的拉斯特尔北美定居计划中止。该定居计划有文献，**北美实际统治面为空**。
- **1519** 王室决定撤换基尔代尔，**萨里正式任命与赴爱尔兰的后续事态属于1520年代**。旧研究用词已更正。

## 主编实际操作（小范围）
1. 核验 `ATLAS_REVIEW_CANDIDATE.json` 中15条文字及图标，保留 `source_ids`；重大事件可通过 `DECISION_MATRIX.json` 打开相应研究条目。
2. 当确认要上线时，把经过审查的候选转为 `data/atlas-1510-1519.json`。不得直接按阶段性档案的source URL生成年代政治多边形。
3. 在 `app.js` 年代/章节加载机制新增1510—1519阶段，同时继续显示`places`中已经证实延续的Calais、Dublin、Scotland等历史地名代表点；图尔奈城市状态在1519年末退出。
4. 若要保留研究地图GeoJSON，将它挂在**默认关闭的虚线参考图层**，不能当正式实际控制面积；图尔奈1.15公里圆形仅代表城市位置，**外围Tournaisis须按乡村司法/财政史料另行研究**。
5. 上线前运行 `python3 editorial/1510-1519/check_candidate.py` 及主项目 `python3 scripts/validate_atlas.py`（原主项目脚本仍以1497与1500年代为基准，接新阶段时应增补1510年代数据验证）；实际GitHub Pages部署结果单独核查。

## 本包保留的关键区别
- **有效王权治理**与**殖民性质**分开：Tournai是英王军政统治城市，Davies(1998)及Murphy(2014)强调其法律身份和保留下来的市政权力与Calais不同；不要未经辨析就照Calais模式画帝国吞并。
- **市内治理**与**外围Tournaisis影响区**分开：里尔大学乡村教区研究与瓦隆历史地图提示可能更广的管辖联系，但现代地图仍版权受限，旧1.15km实验圆是象征符号。
- **档案记录**与**经过实测的财政收益**分开：1516市方声称50,000 crowns与16,000 livres负担，只是诉争当事方说法；1518赎城600,000 crowns属于条约承诺，尚不能当英王已收净利。
- **本地盖尔政权**与**英王总督战事**分开：Omagh、Sligo由当地领主实际治理；Roscommon短时驻军只证明有限军事接触。
- **1515年度治理报告**与**地理测绘**分开：英国图书馆Add MS4792 ff96–110、TNA SP60/1 no9与其他抄本需校勘；“四郡半数受王法”无法直接转换成现代县级50%填色。
- **重名人物**：权威加拿大传记辞典链接 `rastell_john_1F.html`，1517年殖民筹备由**父亲John Rastell the elder**组织，传记标题是儿子；不能把父亲的失败定居计划与儿子的后期航行混写。

## 四条保留在研究层、暂不进入可上图候选的事件
`E1512-ROSCOMMON`、`E1513-WARK`、`E1516-OCARROLL`、`E1516-1517-PERT-VOYAGE-CLAIM`，具体原因及来源均列于 DECISION_MATRIX。**暂缓表示当前证据或坐标未达到审稿要求，不意味着这些历史活动未曾发生**。
