## 未来调查员每次接手只用做这三件事

1. 读 [长期交付制度](../../docs/CARTOGRAPHY_RELEASE_PIPELINE.md)及 [AI工作入口](../../AGENTS.md)，认清每章真实状态和最新已合并 main 数据。**研究PR不等于正式网站。**
2. 按史料核对**上一年末真实控制→本年度控制增减**，提交可读取的GeoJSON、逐年状态、source registry、未核清单到自己的独立PR。没有历史实测界线则Point/虚线/争夺带，绝不画实心伪领土。
3. 若主编准备增加新正式章节，把 [发布卡模板](templates/CHAPTER_CARTOGRAPHY_RELEASE_TEMPLATE.json) 填入对应 [releases](releases/) 文件，并逐年检查桌面/移动端双开关显示，只有真实通过才填“已验收”。

**机器怎么监督？** [发布检查器](../../scripts/validate_cartography_delivery.py)已经纳入旧有CI和Pages。以后“只研究、没有地图状态”可以如实标候审，但**不能通过把章节标成已发布而跳过地图和视觉验收**。既有1540—1549只是历史基线，不冒充新流程的已签名视觉验收。

**用户不需要看数据文件或编程**：用户只需明确“继续第七章/第八章并按地图交付制度交接”。调查员主编应自主更新本看板及相应交付卡。
