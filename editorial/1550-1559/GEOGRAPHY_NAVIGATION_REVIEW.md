# 第七章历史事件地图遗漏纠正

## 原因和处理
第七章29条事件中有许多记录缺乏精确地点，因此旧版地图仅渲染有经纬度的事件而跳过爱尔兰设郡与土地没收、西非与白海贸易、1555年奴役事件。旧页面缺少离开不列颠岛视窗的导航。

使用新的 data/seventh-event-geographic-anchors.geojson 提供四处有引证的现代参考位置，独立于原Atlas的null经纬度。不能视为当时具体事件所在地、史实航线或英国控制地理面。只用原有「版图／事件」开关，关键年份随时间出现；点击地区只平移，保持缩放，右侧呈现已发生的关联史事及来源。

1. 爱尔兰Portlaoise：旧Fort Protector军事堡址及殖民地理参照，另有Daingean旧Fort Governor。1556法令制定和土地没收宗地不能定位到一个堡，也不把现代两郡当英王实控。
2. 西非Elmina：现代遗址位置，葡萄牙自1482年筑堡并控制；仅作几内亚航次关联地理参照，不表示1553—57每次船抵Elmina，更不表示英国曾占该堡；1555 Lok五名遭奴役非洲人有Historic England记录。
3. 俄国Kholmogory：Getty TGN现代位置，Lancaster考证钱塞勒沿北德维纳前往俄国贸易网络；非1553船舶精确登陆地；1555英王给商人的公司特许不等于俄国主权。
4. 伦敦：现代市中心是商人及特许权讨论参考位置，绝不暗示John Lok具体回港、被奴役者到岸港口或公司特许签署的房间。
