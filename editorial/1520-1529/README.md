## 最短操作路径
1. 先看[ATLAS_REVIEW_CANDIDATE.json](ATLAS_REVIEW_CANDIDATE.json)：**21条事件、7处持续政治地点、28个直接关联来源**，与主站`data/atlas-1500-1509.json`的关键字段兼容（name、category、icon_code、year、start_year、end_year、source_ids、lat/lng、significance等）。有10条事件地理点尚不能有据确定，`lat/lng:null`，仍应在本章历史列表出现。
2. [DECISION_MATRIX.json](DECISION_MATRIX.json)：研究中**24件史事→21件候审、3件保留研究**，不会遗失早期资料。暂缓项是1521爱尔兰议会及1522、1523年已由具体城镇事件涵盖的宏观战争叙述，暂不让同一战争重复出一堆图标。
3. [SOURCE_DELTA_INDEX.json](SOURCE_DELTA_INDEX.json)：本章28条直接来源与前一期已整理的137条档案记录对照，8个网址已在前期出现、20个属于本期新链接；同URL不同史实仍保留各自ID、等级和来源路径。
4. [GEOGRAPHY_REFERENCE.geojson](GEOGRAPHY_REFERENCE.geojson)：参考用旧加来/爱尔兰虚线边界＋英属Guînes、法属Ardres的区别（无新实心政治面）。
5. 研究源与原件任务：`research/territorial-1520-1529-20261012/research/periods/1520-1529/`，包括财政细目7项、长期控制状态13项、原始档号待查任务15项。主编无需从头阅读所有资料。

## 这一章地图上的实质性变化
- **没有必要在地图上添加新的大片英王长期领土。** 1519年2月图尔奈已交还法国，1520年代的城市占领状态不能继续存在。
- **加来和吉讷属英王控制**：1520会盟，1521起Newembridge桥头堡加强、1525吉讷委员会、1529具有歧视性租佃与语言规定的殖民定居法规。图标分别 POL/INF，尽量避免重复大段备注。
- **法国和苏格兰战争**：1522 Morlaix被英军洗劫、1523苏格兰Jedburgh受破坏、1523对法国远征；都是**事件**，不要自动制造殖民领土面。
- **爱尔兰**：1520—22萨里担任英王大规模军政代理，1521 Monasteroris攻城留守军；1528 O'Connor Faly俘获德尔文副总督，证明本地王权/盖尔军队的政治行动。政治主体分清。
- **北美**：1527 John Rut实航到达纽芬兰，8月3日在圣约翰港寄出报告。圣约翰港事件坐标采用加拿大自然资源部官方地名 **AAWED**，经纬度`47.5655556,-52.6980556`，不是拉布拉多同名`AAWEG`，也不是英国永久殖民地。
- **苏格兰王国**继续独立：1526贵族间军事冲突、1528James V摆脱监护开始亲政，不形成英格兰跨国统一面。

## 源可靠性与文字口径
- 1525委员会、1529Guînes法律约束已经由Neil Murphy（2025）学术著作概要佐证，**尚未逐页核原法条**，不能说真实被逐租户有多少，亦不能填整个农村作为新征服土地。
- Newembridge在1521前已有桥头关卡：以1521—1526强化据点写，不描绘“1525英国首次殖民纽纳姆桥”。
- 爱尔兰财政 `£3,536 17s 8d`（截至1522复活节两年合计）含`£1,500 15s 11½d`拨军费子项，欠缴`£511 6s 1d`是应收未到；附[研究财务表](https://github.com/1959124923wyz-sys/love-British-TV/blob/research/territorial-1520-1529-20261012/research/periods/1520-1529/FINANCIAL_EVIDENCE.json)，**本次不强行向公众显示未经原账验证的“殖民净赚”**。
- 1522 Morlaix遭袭已证，准确日期在地方传统/其他研究中不同；公众只写“1522年7月”。
- 皇家会议在英属Guînes与法属Ardres之间中立区举行，不意味着英国在当地新取得疆域。
- Scotland的独立君主政治实体与英格兰军事进攻分开。1530年代以后发生的改革宗教/英国兼并不能倒填。
