## 其他编辑怎么开始
可直接打开 series/T01.json 至 series/T35.json 领取叙事系列。T33暂时为空队列，仍保留研究计划，不应为填满地图创造事件。地域分工：T01—T13美洲与奴役贸易；T14—T28印度、东南亚、非洲；T29—T35爱尔兰、苏格兰、澳大利亚与17世纪续接。
优先批次：T07阿卡迪亚1755；T14和T15孟加拉1757—1773；T17迈索尔1792/1799；T30爱尔兰1798；T34/T35澳大利亚1788—1799；T04/T05牙买加及圣文森特强迫流放。
先核实真实历史行为、当事主体、日期和具名地，再核来源、现代参考坐标和历史地理类别。一个跨年组不等于整个时间范围每年连续发生、也不等于一个地理点。英王/东印度公司/独立苏格兰/定居者/地方政府/土著等责任主体分开。
按16世纪成熟范例写文章并建立经核的Atlas事件ID，正文真实的 [[ID|行动词句]] 链接必须实现单击切年定位、双击事件档案及返回。没有可核历史边界不得生成实心英国控制Polygon；局部影响区须有依据并用淡色虚线表达，禁止用示意面积统计领土。
编辑在独立分支保存成果，完成各年实际控制续接、GIS审计和桌面交互测试后给主编审查。这里的 E18-MRG-Txx-yy 仅是编辑组合ID，**绝不直接作为正式Atlas事件ID**。
