# E20-T030 / T031 伊拉克占领、委任统治与独立后英国特权（第65窗口）

Issue #578；T030 与 T031 的分界为1932年加入国际联盟并终止委任统治。后者应独立记录为独立后英国介入。此文件为研究底稿，未写入正式地图、未完成文章及独立出版。

## T030：1914—1932
| 时间 | 已找到的证据与论证边界 | 原始来源或学术入口 |
|---|---|---|
| 1914—1918 | 英印军队与奥斯曼军队在美索不达米亚战争，战后英国留驻。战争范围与后续行政统治分列。 | A1 |
| 1917 | 巴格达成为英军占领城市，英方关于解放的政治宣言与后续统治作比较。 | A1、A2 |
| 1920年6月23日 | 下院辩论对当地财政负担提出批评，议员引用年度收入与税收数字，口径及原预算待核，不把辩论数字直接写为净掠夺。 | A3 |
| 1920年6月25日 | 上院辩论比较1918—19及1919—20财政，讨论税负、行政成本；分别记录发言者与政府答复。 | A4 |
| 1920年中 | 伊拉克反殖民革命，当地各群体参与；纳杰夫出现地方自治组织，英国镇压及地方政权证据分别追查。 | A2、A5、A6 |
| 1920年 | 伊拉克报刊与反殖民政治、第一届本地内阁；不能只以英方行政报告替代当地报刊。 | A7 |
| 1920—1922 | 英国图书馆 IOR/L/PS/10/759 包含镇压、宪制与民族主义政治档案；目录并非原始文件正文，逐卷页提取后方可确定财损及责任。 | A8 |
| 1922年10月10日 | 英伊同盟条约；1923年议定书及附属协议与国际联盟决议构成委任统治安排。 | A9、A10 |
| 1924年9月27日、1926年3月11日 | 国际联盟理事会决议；注意法律安排非单一1920年一纸完整委任状。 | A9、A11 |
| 1930年 | 新同盟条约作为退出委任的条件，后续军事特权另入T031。 | A10、B1 |
| 1932年 | 委任统治结束及伊拉克加入国际联盟；精确日期与原始入盟决议、边界文书待核。 | A10、A12 |

## T031：1932—1958
| 时间 | 证据与论证边界 | 来源 |
|---|---|---|
| 1930/1932 | 同盟条约生效安排及英国军事权益；以条约和附件原文核准基地、使用权及到期条款。 | B1、B2 |
| 1931 | 美国外交档案记录石油特许经营竞争与英国对美条约义务的解释，涉及英资企业；禁止把公司投资、产量、政府税收和企业利润混为英国所得。作为跨期前因，实际1932后账目另查。 | B3、B4 |
| 1933年3月15日 | 英国议会说明按1930年条约，须在伊拉克加入国际联盟后五年内撤出Hinaidi及摩苏尔；追查实际移交日期。 | B2 |
| 1941年4月 | 美国驻伊外交报告记载拉希德·阿里政府的成立及英伊外交分歧；各国立场与本地政治责任分列。 | B5 |
| 1941年5月 | 美国同期报告记录伊方对英国空中行动影响平民及医疗交通的指控；是同期指控，追英国档案和伊拉克医院、地方报刊，未核损失暂不计数。 | B6 |
| 1945年7月5日 | 英国情报研究文件目录记录伊拉克报刊、议会对修订1930年条约的要求。 | B1 |
| 1948年1月5日 | 美国外交档案记录巴格达学生因拟议英伊条约与警察冲突。 | B7 |
| 1948年1月15—21日 | 朴次茅斯条约签署，伊拉克国内大规模反对，摄政宣布条约未达民众愿望；新约最终未实施。伊拉克警察实施的镇压不直接改写为英军行动。 | B8、B9 |
| 1955年3—4月 | 英国加入土伊条约，1930年条约安排终止；英国议会明确提出机场移交及逐步撤回英国驻军。法律承诺与实际执行分开。 | B10、B11 |
| 1955年12月21日 | 英国议会说明新的特别协议、设施使用和采购安排。具体实际付款、财政负担及财产归属待账册。 | B12 |
| 1958年7月14日 | 英国外交大臣转述驻伊使馆报告，伊拉克共和国宣布成立；英国条约权益后续实际终止及基地移交另查。 | B13 |

## GIS 与去重
- 已检索main正式serial 1910–1959五个十年chronology中的伊拉克、美索不达米亚、巴格达、巴士拉、摩苏尔、哈巴尼亚等中文名称，未发现同词命中；生产前还必须按英文异名、事件ID、旧章节atlas及spatial文件复核，不能仅凭一次检索宣布无重叠。
- 首批具名地点：巴格达、巴士拉、纳杰夫、摩苏尔；基地应以历史原址档案定位，禁止使用现存机场面积替代条约范围。真实历史委任统治界线须查同时期地图、国际联盟文件和摩苏尔边界决定；有据不确定的范围用虚线，无依据不画。
- 未采用任何未核伤亡数字、无证村落损失、战术路线、武器信息或石油获利额。重点补英军镇压命令、伊拉克地方居民证言、原始财政账簿、特许合同及收益账目。仅完成研究，不批准出版。
