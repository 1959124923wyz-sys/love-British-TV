# E20-T032/T033 巴勒斯坦委任统治研究交叉表（第66窗口）
Issue #578。T032 1917–1939（土地、政治权利、1936–39起义及集体惩罚），T033 1939–1948（移民限制、拘禁、紧急法与权力终止；塞浦路斯拘禁延至1949仅作有证后果）。本文件是研究候选，不批准发表，不绘未核历史疆界。

## T032：英国行政、土地政策与镇压

| 日期 | 核实事项及责任界限 | 来源 |
|---|---|---|
| 1917-11-02 | 贝尔福宣言；后纳入委任统治文本。准确区分英国政策承诺、当地政治权利与私人土地权。 | A1、A2 |
| 1920-04-25 | 圣雷莫会议将委任任务分配给英国，英国1947年备忘录回顾此事。 | A3 |
| 1922-07-24 | 国际联盟理事会批准委任统治文件；第2、6条同时写入犹太民族家园、移民与土地安置以及其他居民权利。批准日与正式生效日分列，1923-09-29生效须继续取国际联盟原记录。 | A1、A4 |
| 1922 | 巴勒斯坦枢密院令及高级专员权力；第XXVIII条要求年度蓝皮书，涉及财政、土地农业、人口和立法。逐年调取账簿才能谈实际资源转移。 | A5 |
| 1930 | 英国政策声明Cmd.3692，土地和移民问题及居民权利条文；核完整文本与Hope Simpson报告，勿把所有私人买卖归为英国政府没收。 | A6 |
| 1936年春 | 巴勒斯坦阿拉伯全国委员会、阿拉伯高级委员会与总罢工；当地史学资料记载政治动员、土地与就业背景。 | A7、A8 |
| 1936-06-24 | 英国议会质询雅法旧城拆屋、居民安置，并转述Gazour村搜查、拘押及财物没收指控；议员质询与政府答复分列，具体受害财产继续核验。 | A9 |
| 1936-07-01 | 下院继续质询雅法拆除及居民替代住所问题；PalQuest历史图像可用于核实实际房屋毁损，质询人数非最终实测。 | A10、A11 |
| 1937年7月 | 皮尔委员会建议分区；建议的地图为未实施政策方案，不绘为实际行政或主权边界。 | A7、A12 |
| 1937-10 | 英国行政机关宣布阿拉伯高级委员会及全国委员会为非法组织，拘押并驱逐政治人物。 | A13 |
| 1937-10（1938-11-04答复） | 英国政府确认五名政治人士被流放至塞舌尔，四人为阿拉伯高级委员会成员；核个别姓名、拘禁地及释放时间。 | A14 |
| 1938-03-09 | 英国政府在下院书面答复确认部分村庄房屋作为集体惩罚拆除；雅法1936年拆除与该统计分开，补偿表述不等于逐户实际付款。 | A15 |
| 1936–1939 | 同行评议研究讨论殖民镇压、酷刑及集体惩罚；逐项调原件，以当地受害者身份、责任单位及有据地点优先。 | A16、A17 |
| 1939年5月 | 英国发表白皮书，作为T032的政策结局与T033移民管制的前因；只复用同一事件ID。 | A18 |

## T033：限制移民、紧急法、拘禁与退出

| 日期 | 核实事项及责任界限 | 来源 |
|---|---|---|
| 1939年5月 | 白皮书限制犹太移民并提出政治制度安排；与T032共用事件，关注纳粹迫害背景中的难民处境。 | A18、B1 |
| 1940年2月 | 土地转让条例设A、B及自由区并设例外。法规适用区非族群领土或军事控制线；须取原始附表及历史地图。 | B2 |
| 1945-09-27 | Defence (Emergency) Regulations，PalQuest所载原公报文本。拘押、审判、财产没收等法律权力按条逐项核；实际个案另列。 | B3 |
| 1946年8月 | 英国对未获准入境的犹太难民施行塞浦路斯拘禁政策。美国大屠杀纪念馆与JDC档案互证；区分难民、普通居民和政治军事组织。 | B4、B5、B6 |
| 1947年4月—5月 | 英国将问题交联合国，UNSCOP成立，档案目录及报告追查；不得把英国的移交请求视为委任已终止。 | B7、B8 |
| 1947-11-29 | 联合国大会第181(II)号决议提出分区及经济联盟；计划并未按原样实施，地图仅可作有源政策方案。 | B9 |
| 1948年初 | 联合国巴勒斯坦委员会与英国讨论移民配额、塞浦路斯被拘押人员与行政过渡。 | B10、B11 |
| 1948-04-29 | 英国《Palestine Act 1948》；第1条关于5月15日或另定更早日终止英国司法管辖。 | B12 |
| 1948年5月 | 英国通知联合国委任终止日期，5月14日以色列宣布建国，委任管治法定终止与英国军队实际撤出分列。 | B13、B14、B15 |
| 1947–1949后果 | 巴勒斯坦难民、犹太难民及地区战争分别按执行主体、地点、时段记录；英国撤退政策的后果与其他各方直接行动不能混为一个责任口径。 | B15、B16 |
| 1949年2月 | 塞浦路斯最后一批拘禁营关闭；作为1946英国拘禁的后续，不扩展为英国继续管治巴勒斯坦。 | B4、B5 |

## GIS、重叠核查及待办
main 1910–1949 serial chronology 已按中英文地点及事件名扫描，未发现与本两题相关的匹配；E20-CORK-BALFOUR为1926年自治领宣言，不是1917贝尔福宣言。制作前仍须检查旧章节Atlas、spatial、T034及十九世纪地权专题。具名雅法、耶路撒冷、海法、塞舌尔、塞浦路斯地点须取得固定地名坐标和同期具体证据；不能用现代国界替代历史委任统治界，不能将1947分区建议当成实际控制。历史城镇拆除区需原图与地籍；仅有城市/岛屿证据时用具名参考点，不猜测拘禁设施或行动路线。对原始赔款、受害财产、难民人数及不同统计口径逐项核查。以上34项来源键含原件、机构研究、目录及摘要，仍需生产阶段原件深读。
