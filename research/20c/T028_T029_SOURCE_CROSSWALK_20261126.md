## T028 1922–1956：独立后的驻军、特权和冲突

| 日期 | 证据与叙述边界 | 来源 |
|---|---|---|
| 1922-02-28 | 英国承认独立，四项保留事务为帝国交通、埃及防务、外国利益及少数群体保护、苏丹；不将埃及全境继续记作保护国。 | A1；复用 E20-CORK-EGYPT |
| 1936-08-26 | 英埃同盟条约签署。英国的运河交通及驻军权利、埃方政府条约立场按原文逐条核对。 | A2；复用 E20-SALT-EGYPT |
| 1942-02-04 | 美国驻埃外交官当天电报记录英国以军事压力迫使国王接受政府人选。外交报告证明政治强制，不扩展至无证的全国实控。 | A3 |
| 1952-01-25 | 伊斯梅利亚英军与埃及警察发生冲突。1952-01-31英方政府报告与埃及国家纪念材料互证当地事件；二者对责任与背景解释不同，不采用尚未厘清的伤亡口径。 | A4、A5 |
| 1954-07-27 | 英埃谈判者草签原则协议；涉及撤军、民用技术人员维护基地及重新使用条件。 | A6 |
| 1954-10-19 | 正式协议签署，取代1936同盟条约；12月6日开罗交换批准书。撤军安排、基地使用条件需要查正式文本及附录，不将7月原则与10月最终协议混用。 | A6 |
| 1956年6月 | 开放大学研究回顾最后一批英国军队撤出；确切日期需核同期英埃档案。 | A7 |

## T029 1956：国有化、英法以合作、平民损失及撤出

| 日期 | 证据与叙述边界 | 来源 |
|---|---|---|
| 1956-07-26 | 埃及国有化苏伊士运河公司；法令第1条将公司资金、权利义务移交国家，同时规定股东补偿。具体实际支付须另核。 | B1 |
| 1956年10月 | 美国外交史料编者根据当事人材料记录英法以秘密协调，英方参与责任可核；不复盘具体军事实施过程。 | B2、B3 |
| 1956-11-02 | 联合国大会通过第997(ES-I)号决议，官方表决64赞成、5反对、6弃权。 | B4 |
| 1956年11月 | 英法军事行动涉及塞得港，主站已有 E20-KEN-SUEZ；不得再以新ID重复记录同一事件。 | B5 |
| 1956-11-07 | 大会第1002(ES-I)号决议要求英法、以色列撤出。 | B5、B6 |
| 1956-11-21 | 英国防务大臣答复塞得港居民生命、建筑损失、医院供给问题；英方估计为当时口径，不能将其与后续调查相加。 | B7 |
| 1956-12-20 | 英国政府承认损害估计存在冲突，介绍Edwin Herbert调查；待取报告原件、核图及当地医院、家庭记录。 | B8 |
| 1956-12-22 | 联合国维和历史记录英法撤出完成、紧急部队接管塞得港地区；以军另于1957撤出，责任和日期独立。 | B5 |
| 1956年12月 | 埃及代表团提出评估英法以军事行动造成损害的决议草案A/3471；并非已通过的赔偿裁判，也非实际到账款。 | B9 |
