# T002 生产史料与地图审计

13节28段、3948正文字符、33项来源、28新增互动年表、10按年份登记的城市图元（8个不同具名地点）。1900–1947五个年代数据，未重复T001及19世纪T16/T17/T20。旁遮普原法使用India Code OCR，PDF截图请求超时；其余法律修订汇编与历史文本区分；Bardoli 1929仅见目录。1927平均20%为1928年7月9日英国政府声明口径；7月23日宣布没收约65000英亩、已售1618英亩（原属非农业经营者），分别登记，绝不等同实际没收地界。图元仅代表据实发生的调查中心、城市会议及巴尔多利税区具名参照点，不代表完整行政区；暂无历史地籍及配准地图，不作假边界。1947年法案提出，不提前记作废除地主制。后续补原始地籍、税册、地方债务委员会报告、1946–47村级记录及准确图界。

补查：孟加拉1940土地收入委员会卷二原件文字转录（附录一和表VIII(d)），确认1938年11月5日加尔各答任命决议、1940阿利波尔出版与样本22.5%农业雇佣家庭；IGNOU教材印页209确认1946加尔各答决议与汗普尔村殖民警察镇压。原件PDF截图返回服务器错误，依可读取文字登记。马德拉斯1938法公报日期核自印页567。4个新按年地点图元；汗普尔村位置未独立核定，保持空坐标。
