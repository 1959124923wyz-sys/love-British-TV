# 爱英TV｜跨世纪英国实际控制区史料体系 v0.2（研究交接规范）
日期：2026-10-11｜状态：**待审核的研究规则**，不直接改动网页主干。
适用于：多位对话研究员与一位网页维护员并行协作。

## I. 数据库最终应回答的五个问题
1. **谁**（英文/当时政治实体、政府机关、公司/军队）在某年发出权力命令？
2. **权力实际实施在哪里**（行政、法律、驻军、税收、土地产权；争议控制与地方自治单独记录）？
3. **什么时候开始/结束**（法律文件日期、实际驻扎日期、撤退/移交日期分开；未知不凑整年）？
4. **如何提取利益**（土地税、关税、工资强制、奴隶劳动、贸易特权、军需契约等；净收益能不能考证）？
5. **对谁造成什么影响**（受影响群体与责任归属；不同文献的冲突、反抗与独立过程）？

控制的客观事实、殖民性质的评价、经济净收益、历史事件的视觉显著性分别是不同字段。研究主题可以集中于殖民掠夺，不能预设每片受控区都使伦敦财政出现净盈余。

## II. 控制关系的分层判定，不用“颜色填满”的逻辑倒推史料

| 研究代码 | 判定基本依据 | 默认制图 |
|---|---|---|
| `CLAIM_ONLY` | 授权、条约中的法律要求、王室主张，但缺当地执行 | 主张点/条约说明；**不显示实控面** |
| `TRADE_ONLY` | 航行、商业据点/商站及通商权，不涉及一般行政统治 | 港口点/路线，不能自动围出内陆面 |
| `GARRISON` | 实际驻守堡垒、船坞、军港等设施 | 已证实据点或局部防御区；其射程并不等于管辖权 |
| `TEMP_OCCUPATION` | 有明确起讫的军事控制，未必稳定民政 | 有效期控制的独立军事图层 |
| `CIVIL_CROWN` | 王室/英国殖民行政在当地实际运作，司法税收或地政记录持续 | 证实区域才可画统治面 |
| `COMPANY_RULE` | 获授权公司确实在该地行使司法、税收、土地/军政统治 | 独立公司统治纹理，不把特许贸易误算成统治 |
| `INDIRECT_RULE` | 当地王国/酋邦/土邦继续掌握一些民政，但英方控制外事、军事、财政等重要事务 | 保护/间接治理纹理，说明谁仍是地方统治者 |
| `JOINT_CONTESTED` | 两个或以上主体在同一时段竞争权力，或英方只控制狭窄走廊与城镇 | 虚线边界及争议注记；允许重叠而非强行二分 |
| `UNKNOWN` | 史料不足，或虽称殖民地但查不出具体范围 | 空白或“未查明”标签，**不能默认无人治理** |

一手官方文书可以证明政府**说过什么**，不能自动证明当地居民接受、命令生效、官员到任、地方经济受其控制。研究员必须另外查反证、地方档案、原住民/地方政体记录或可信学术研究。

## III. 空间证据要素（绘图闸门）

每张历史面图需元数据：`map_title`, `cartographer`, `map_date`, `map_represents_period`, `scale`, `shelfmark`, `rights`, `geo_referencing_version`, `transformation`, `RMS_error_if_available`, `lineage`。

地理确定性维度：
- **L0** 无法确定地理范围：`geometry=null`；可以有史实时间线。
- **L1** 可确认历史地名/地理单位，但无法重建范围：地名文字或点，仅用于导航（必须 `representative_marker=true`）。
- **L2** 可确定局部堡垒、河岸、边防地名或走廊：谨慎绘制相应局部线段/点，不自造闭合线。
- **L3** 有完整历史边界图且来源可审、历史测量误差可接受：可以提请绘制带虚线/宽度的近似面。
- **L4** 有多种独立同时代依据与可靠地理配准：可绘制实心面，但仍写出处、年代和争议。

**重要**：L4不是“一定真”，任何时代的地图都可能夸大主张；`approval`由史实证据和地图误差共同决定。图层的地图“精度”与“政治实际控制”是正交维度。不能为了整齐把L2升为L4。古代地图上的空白不代表无人居住。

## IV. 时间线数据规则
- 十年单位只是UI主刻度，真实时间必须以事件起讫、月日（若有）存储。
- `start_earliest`/`start_latest`、`end_earliest`/`end_latest`支持事件只在一个区间中发生的知识状态。
- `observed_at`说明资料记录**某年已存在**控制；不要擅自以10年初当作起点。
- 同年存在王室宣称、贸易站、军政建立，按独立 `episode` 存放，避免一个有毒“统治开始”日期。
- 1490s王国为英格兰与苏格兰分别；1603年共戴君主不改变为统一国家；1707年大不列颠王国；1801年大不列颠及爱尔兰联合王国。另见 `HISTORICAL_ACTOR_TRANSITIONS.json`。

## V. 证明等级，不将机器检查等于史实核证
- **lead**：从检索结果/书目得知线索。
- **guide_checked**：官方档案系列／书目入口及覆盖时段核实。
- **abstract_checked**：同行评审研究摘要能直接支持此论断，未读全文或一手原件；**不能对外称已读原始档案**。
- **document_checked**：逐页看过原文或档案影像并留页码/档号与原始文句的最短必要引文。
- **corroborated**：来自不同证据传统的史料支持重要结论，且记录异议。
- **editorially_approved**：来源、年份、几何和版权均过审；才可合入主图。
文献级证据评级与史料公开许可评级分开；“官员命令已签署”和“命令在当地被执行”不是同一条可证论断。
本分支的 `SOURCE_* `仅至 `guide_checked`；爱尔兰Pale文件的部分摘要证据至 `abstract_checked`。

## VI. 经济收入严禁“统一帝国利润”未经依据的加总
分成：当地税收 `local_public_revenue`；地方公共支出 `local_public_expenditure`；英国财政拨款/驻军费用 `uk_public_spend`；汇往英国国库的余额 `uk_treasury_remittance`；公司经常性收益 `company_operating_profit`；私人种植园/商人利润 `private_profit`；货物流转总额 `gross_trade`；奴隶主补偿 `slaveholder_compensation`；土地转移/租金 `land_transfer/rent`；以及不可定价的人口/社会损失。

`net_transfer` 只在具有同一核算主体、相同时间口径、已排重的对应账目时计算。比如某殖民地政府年度收税100，并不意味着伦敦收到100；某产地强迫劳动不能依据运输船数直接推算私人最终利润。
**财务史料示例**：1823年英国议会讨论出现殖民地方财政收支与英国政府军费分别记账的议论；这只能说明原文存在这种记账区分，不能直接引用辩论中的数值作为已审计帝国净盈余。[来源](https://api.parliament.uk/historic-hansard/commons/1823/feb/25/colonial-revenue-and-expenditure)。

## VII. 来源引证与版权
- 一条来源以 `SOURCE_ID` 为主键；精确文献必须尽可能加 `shelfmark`, `piece`, `folio`, `page`, `quote_locator`, `year`, `institution`, `permalink`, `seen_at`, `language`。
- 英国国家档案馆的 **索引指南 ≠ 档案原件**；英国图书馆 `IOR/A/1` 公司特许、`IOR/X` 地图、`IOR/L/E` 经济卷宗功能不相同。
- Natural Earth 用于**现代参照**，官方标为公共领域；CShapes2.0的美国国会图书馆副本标注 CC BY-NC-SA 4.0，不能当作无条件公有领域；World Historical Gazetteer 受来源逐条许可证约束且API通常需令牌。
- 第三方历史地图或扫描件**只保存链接和出处，不成批下载重发**；核实实际许可证后另行批准复制与改绘。

## VIII. 数据并发与跨对话同步
- 每位研究员独立 `research/<专题名>` 分支；不要多人同时修改同一个 `main` 文件。
- 每批**先保存 sources 与论断清单**，后续才整理几何和财务，以防任务超时导致整批未落盘。
- `PROGRESS.md` 记录已验证文件路径、commit SHA、已读原文的具体页码、已解决/未解决问题，绝不只写“找到很多材料”。
- 重要更改通过 Draft PR 交给维护者；请维护者选择审核后合并主干，不能自动把 `research` JSON 当成前端可渲染数据。
- 合并时给每条 `control_episode_id` 稳定键；引文、图件、财务表都引用该键；版本变更记录字段与旧键映射，避免动态时间轴重复计数。

## IX. 研究开端推荐顺序
1. 1490年代爱尔兰四郡／Pale；目前仅有二级历史研究摘要，不能画完整polygon。
2. 1607詹姆斯敦：定居点作为点可考证，但不能把整片特许殖民地画实色。
3. 1650年代爱尔兰：Down Survey等地籍记录为土地转移线索，不能用土地产权地图等同政治控制区。
4. 之后各地区同法批量扩充，不应因为资料更多就放松来源审核。
