## 二、地图的两层分工，特别说明“非洲到底怎么画”

**版图（可独立勾选）**：1560—69苏格兰独立、英国王室属岛和爱尔兰有限行政／据堡网络保持前十年的继承；**1562年末勒阿弗尔为英国驻军实际控制的港城**，1563年7月法国收回，**1563年底不能仍呈英占**。勒阿弗尔现今城市Reference Point可直接入图，但真实1562港墙界**不能依现代勒阿弗尔市区涂色**，当期历史测绘图在法国市档1FI227等待配准。

**事件（可与版图同时勾选）**：霍金斯奴役活动、奴隶强制横渡、大西洋航行、海岸捕掠、里奥阿查胁迫交易、1568圣胡安-德乌卢阿海战、爱尔兰起义与镇压、1560利斯围城、苏格兰女王退位/1568朗赛德战役。

**西非“从宽从大”的实现**：不做几个误导性的“准确登陆点”。根据霍金斯1567—68本人叙述，画以Cap Vert（**塞内加尔达喀尔海角，非佛得角岛国**）→ Rio Grande（上几内亚沿岸历史水道）→ Sierra Leone（塞拉利昂）为地理框架的**大片虚线斜纹活动带**。不同航次`start_year/end_year`分别出现；每片Polygon内部**不是人人都被掠卖，也不是英国军管土地**。`render_as_hatched_event_activity_band:true`仅允许事件层渲染，`fill_authorized:false`表示绝不允许作为“英国疆域面积”；展示活动带可用非领土底纹但不应触发英国占地统计。版图层中，1560年代**不存在被证实的英国属西非土地面**。

**奴隶贸易数字**：1568年英方叙述约250名被掳者、里奥阿查售卖约200名很可能互有重叠；RMG/Historic England给出的约1200名被贩运者是总体机构概数，不能把三个数字相加，也没有可审核英国财政**净掠夺利润**。1569伦敦海事法庭文件属经济证据，不是当年有第四次霍金斯舰队到非洲。

## 四、必须保持的史料矛盾与手稿机会

1. **勒阿弗尔同一市政档案两份材料不一致**：进驻分别是1562年10月4／8日，法国重新占领分别是1563年7月28／29日。故制图按已证**年月**切换，不造精确日界。原1563-07-15 **Warwick Plan**（勒阿弗尔市档`1FI227`，1880年代历史复制）是解决战壕／城堡边线的首选，比目前随意绘制的地带更可靠。
2. **利斯古垒已找到考古配准研究**：2016学术论文`10.1080/00794236.2015.1123442`将1560绘图与Great Junction Street和West Bowling Green Street发掘联系起来；只有核原图版权与工程后才画准确围城阵地。HES Leith Links旧炮台山的身份另有学界争议。
3. **爱尔兰1569第一手镇压军报**：爱尔兰手稿委员会编辑的`Campaign Journals of the Elizabethan Irish Wars`，含Gilbert在芒斯特1569年9—12月五份书信原档 TNA SP63/29/64、68、82a、82b、83，已列至待查任务。军中第一手自述常有偏见，不能把泛论“屠杀/饥荒”自动归到某个未核具体1569村庄。
4. **西非旧地名**：“Cape Verde”在1564及1567文本语境是**Cap Vert peninsula**；`Rio Grande`河口精确现代对应以及1568年1月被焚城市仍需原文比对。用宽活动区不是替代真实坐标的借口；原地点不明时就要清楚写不明。
5. **1570接续**：1569末的爱尔兰反抗不能一翻到1570便消失。霍金斯第三次船队的残余人员归来/伦敦诉讼与西非年末真正军事控制无关，1570不要把1568西非捕掠活动带无故延长为“英占海岸”。
