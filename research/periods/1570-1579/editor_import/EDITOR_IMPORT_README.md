# 爱英TV 第九章 1570—1579｜殖民暴力、人口掳掠与经济剥削历史地图包

**成果状态：独立研究支线，供主编直接读取、审核、分步导入，尚未进入正式站点。** 采用主站**已发布第七章（1550—1559）**和[第八章研究 PR #52](https://github.com/1959124923wyz-sys/love-British-TV/pull/52)的**候审**1569控制状态为基线；若主编后来更新第八章，以已发布`main`第八章实际1579年前一年1559→1569末年继承数据为准，**不得直接覆盖更新后的生产Atlas**。

## 一、明确结论

本章不是1570年代英王领土大规模扩张：主要是**阿尔斯特私人殖民计划/当地反抗/镇压与屠杀、加勒比金银劫掠、因纽特人遭绑架和北极临时采矿、1579年美洲私掠与象征性领土声索、1579德斯蒙德战争爆发**。只有**卡里克弗格斯原有英军城堡核心**和**阿兹1572年有限殖民据点**能谈具体英国军事/殖民在地行为，且绝不能自动把阿兹、安特里姆、泰隆、加利福尼亚、加拿大或巴拿马全域画成英国控制区。

**三层分类**：`effective_local_garrison`真实驻堡点；`land_grant_planned_colony`殖民授地但未实现占领；`scorched_earth_massacre_abduction_looting_trade`战争经济暴力、绑人、金银私掠与贸易点。项目仍只有**「版图」「事件」两个可同时勾选层**。新增古疆域`Polygon=0`。

## 三、重大发现：必须直观表现但不要把损失算错

### 1. 阿尔斯特殖民掠夺与爱尔兰屠杀

- **1571年史密斯土地授予**：官方文件声称王室将阿兹/克兰德博伊土地给私营“殖民公司”，不是已经夺取盖尔地主实土。University College Cork所藏`1572 A Letter sent by I.B.`首版宣传册附有授地地图和认购条款，值得下一轮古地图配准，**但绘前需取得扫描/授权/地理依据**。
- **1572年8月31日**殖民队约百人在阿兹登陆，建立Newcastle Comber小据点；其据守范围远小于王室授地意图。遭地方领主抵抗后1573—75动摇，到1575年主要殖民工程崩溃。
- **1574年9月**埃塞克斯率兵扫荡泰隆，焚烧庄稼、夺牛直至Lifford，这是**经济毁灭性武装行动**，并未产生英军长年控制的现代“泰隆郡紫面”。
- **1574年11月贝尔法斯特附近**埃塞克斯在宴饮后逮捕Brian MacPhelim O'Neill并杀害其随从**约200人**，包括妇女儿童；后送都柏林处决首领。屠杀年份、施害军官与被害社群有学术传记支持。
- **1575年7月26日拉斯林岛**：约**200名守军＋300—400避难平民**遭英军处决和杀戮。另一本学术传记约`600`总死者属于同一事件的近似统计，**绝不能统计成1200人或在七月占岛后延续整个十年英属拉斯林**。Norreys指挥登陆军、Drake参与舰船运输、Essex是幕后主使之一，不能只记“海盗德雷克某日屠岛”。
- 埃塞克斯殖民计划**最终失败**：史述记录王室总支出约£80,000、埃塞克斯私人耗费约£35,000；曾预计每年给王室£5,000租金属于**没实现的规划收益**，£10,000王室贷款、近£40,000未来设堡预算也不是同一口径的花费。

### 2. 德雷克的商业性武装劫掠与利润

- **1572 Nombre de Dios突袭失败**，不把巴拿马港口涂成英属。
- **1573巴拿马地峡金银驮队掠夺**：美国国会图书馆史述约`£20,000`金银，**属于抢得财物的二手估计，实际英王净收益无审计记录**；德雷克与法国Guillaume Le Testu合作，帮助他的巴拿马`Cimarrons`是逃脱奴役者社群，**不许把他们误写成德雷克的被奴役私人奴隶**。
- **1579年3月1日Cacafuego劫船**：大宗金银战利品事实得到美国国会图书馆证实，但抢劫点海上精确位置及西班牙原始货单未核，地图**不能放准确夺船GPS点**。船队**1580年9月才回英格兰**，所以1579年不能填英王当年财库实际净利润。
- **1579北加利福尼亚“新阿尔比恩”**是德雷克象征性声索，原住民Coast Miwok并未被英国驻军实际接管。国家公园指出原登陆地点争议，而且昔日所谓古代“铜牌”已被科学证实为近代赝品：**没有依据在1579年将整块加州涂英国紫色**。
- **1579特尔纳特丁香贸易**不产生殖民统治。当地苏丹国仍应作为本地政治主体。

### 3. 英国在因纽特祖居地的掠人和失败采矿

- **1576**俘虏一名因纽特男子带到英格兰，遭羁押并死亡（实际获俘湾未确证）。
- **1577**俘虏**Arnaq、Nutaaq（其子）及Kalicho**，英国博物馆叙述三人均死于英国，船员曾在巴芬岛向因纽特人开枪；**绝不是平等“自愿参观英国”**，亦无依据断言被出卖到种植园。
- **1576—78**英国船队反复在Kodlunarn等地企图开采“黄金”，加拿大公园称开采约**1400吨没有经济价值的矿石（跨三次航行总量）**，曾拟建100人越冬基地但未能建成，只留考古石屋。伊丽莎白1577年投资约**£1000**属于资金投入，不是黄金收入。
- 加拿大自然资源部Kodlunarn岛官方地名经纬度为`[-65.416667,62.816667]`；这是**历史矿址所在岛屿**，不等于1577被掳人员所在海湾、不等于英国拥有巴芬岛及格陵兰。

### 4. 1579—1583德斯蒙德战争与跨年代交接

- **1579年7月**FitzMaurice小队于丁格尔登陆，反抗迅速升级；8月1日在Tralee政府官员遇害。这是**反抗者对英王人员的暴力**，施害者身份和英军杀戮不能混写。
- 学术论文关于人口减少、饥荒、农业毁灭与日后爱尔兰没收土地的总体分析跨**1579—1583整场战争**，**后四年暴行和人口统计必须交给第十章按发生年份处理**。第九章不预先填整个芒斯特为英国直接实控，也不让1579年的战区进入1580后自动消失。

3. 版图层仅显示**有史料可用的局部英王旧军堡点**；不能自动按授地文件或屠杀地点涂紫色。事件层显示1574焚粮、1574与1575屠杀、1576/77人口绑架、1578矿石开采、1572/73与1579金银掠夺及1579 Desmond抗争。
4. `VIOLENT_EXTRACTION_ROUTE_REFERENCES.geojson`是纯辅助虚线，不能通过线路宽度推定英军占地。全数据不新增实测16世纪`Polygon`。
