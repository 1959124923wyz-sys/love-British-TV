# 爱英TV｜编辑6｜17世纪长期调查任务书：分身C

**非洲亚洲、海上掠夺与商业财政制度**

研究分支：research/1600-1699-c-africa-asia-maritime
母编号：ARC-EIC / ARC-RAC / ARC-ATL-TRADE / ARC-NAV / ARC-FISCAL
研究规划： https://github.com/1959124923wyz-sys/love-British-TV/pull/148

## 专属任务范围与优先顺序

**你主攻西非、印度洋、南亚和东南亚英格兰海上活动，兼顾全球航运、私掠、公司、海军与战争借贷制度。**逐步查1600东印度公司特许及早期航次、英荷香料贸易冲突，苏拉特、霍尔木兹、马德拉斯、孟买、孟加拉等据点的取得/条约/管辖性质；1686—90公司与莫卧儿交战和失败。不能提前画成18世纪英国统治印度的大国土。
系统梳理西非贸易公司系谱（1618、1663、1672、1698等关键制度阶段）；核查冈比亚河及开普海岸等堡垒的真实占领、非洲政治组织和贸易中介；查皇家非洲公司 T70账簿、王室特许、航次、金属货物与公司投资人，区分贸易站与内陆治理。
以 SlaveVoyages 等可审计数据库建船次主台账：船籍、国籍归属、公司所有权、非洲登船点、美洲卸载港、人员规模、死亡/未知、海上运输和跨洋被奴役者，已记航次与估计航次分开；口岸和被奴役者登陆后状态交乙负责，彼此以航次ID互链。
调查1651、1660及1663航海法、1652—54/1665—67/1672—74英荷战争、1664/1667新尼德兰转手的外交和海战背景、英西/英法海上掠夺、私掠许可与海盗差别、1695埃弗里袭商和1688—97战争网络。南美沿岸及欧洲贸易港的英国远征也不能遗漏。细查海战是否改变殖民统治，避免把单次临时侵扰当成吞并。
调查公司融资、海关收入、商品贸易、船队建设、战争费用、1694英格兰银行成立及国家信用。把公司利润、私掠所得、殖民经济毛额、国库税款和债务融资分账，禁止编造殖民掠夺直接带来全部国家收入的数字。
首轮旗舰专题：1600—1699东印度公司；1663—1698皇家非洲公司与非洲堡垒；1600年代奴隶航次主台账；航海法与英荷战争；1690年代海盗及1694借贷制度。
**优先史料入口：** https://searcharchives.bl.uk/ （IOR/B和IOR/E）；https://discovery.nationalarchives.gov.uk/details/c/F161609 （RAC/T70）；https://www.nationalarchives.gov.uk/help-with-your-research/research-guides/african-ancestors-an-overview/ ; https://legacy.slavevoyages.org/voyage/downloads ; https://www.bankofengland.co.uk/about/history 。
**边界：**乙独立研究美洲殖民地法与地方结果和哈德孙湾公司的北美地方关系；甲研究英爱苏国内镇压和地权；丙主核商业公司、海上船次、贸易/融资制度与非洲亚洲据点。

## 必须遵守的研究制度
1. 任务不是一轮就结束：以1600—1699年为重点，先查1590年代前史，给跨1700及后续数百年的母专题保留接续接口。必须复用编辑6 Word 总表的 ARC- 母编号，不得因换十年而给同一历史进程编造终止年份。
2. 区分英格兰、苏格兰（1603共主并非1707合并）、共和国/护国公政体、王室公司、殖民地政府、民间私掠者，以及当地盟友和抵抗力量。没有证据不能把个人海盗行为当作国家行为。
3. 逐条记录中英文题名、起止年/月日及精度、当事主体、行为、被影响群体、结果、时间与空间状态，至少一项可信来源的作者/文献/卷页/URL；原始档案、学术研究、官方科普、仅见目录四级严格区分；引用目录不得伪称读到原文。数字、财政收益和伤亡必须独立证明统计口径。
4. 先专题、后事件、最后扫尾：先全面搜集，围绕已证的长进程成篇写历史专题，再按年提取具体事件、候选点线面与具名地点、抵抗者视角；寻找少见史事，但绝不凑数。
5. 地图：有据的具名地允许现代参照点并标注地理精度；行动路线需有先后证据且不得假装实测航线；有据战争波及区才能虚线标注；无可审计历史边界绝不造实心殖民面；商贸特许、短占、实际统治、土地权属、原住民地方政体不得混同。
6. 在本组分支分批保留研究文件：research/periods/1600-1699/<组别>/ 下的 TOPIC_INDEX.md、TOPIC_DRAFTS/*.md、SOURCE_REGISTER.csv（或 json）、EVENT_CANDIDATES.json、SPATIAL_CANDIDATES.geojson（有据才创建）、CONTINUITY.md、QUESTIONS_AND_CONFLICTS.md、PROGRESS.md、HANDOFF.md。来源和待核事项须逐条与候选事件关联。
7. 确保每个持续控制点使用稳定 stable_id，注明各十年变化及 last_documented_date 与 historic_end_date 的区别；段落预留 prev_segment_id/next_segment_id、relation_type。跨章只增加阅读切片，不强制截断真实历史。
8. 每完成一批可靠研究就提交GitHub（保留commit SHA）和更新 PROGRESS.md；尽早建立Draft PR供编辑6复核，遇到超时先提交已有资料并记录恢复路线；不合并main，不修改已批准UI、不搞手机端，不直接往已发布 atlas/stories/chapter 数据写未经批准的事实。
9. 必读规范：AGENTS.md、docs/HISTORICAL_SPATIAL_NARRATIVE_STANDARD.md、docs/HISTORICAL_SPATIAL_REVIEW_CHECKLIST.md、docs/RESEARCH_TERRITORY_CONTINUITY_PLAYBOOK.md。
10. 首批交付：专题目录及优先级、正文草稿（含原始史料与争议）、具名事件候选、经济/社会/军事后果与来源、空间候选和连续性审核、交接说明。以后每轮自行选择有价值的问题深挖，不设杜撰的事件数目标。独立分支成果≠正式地图上线。
