## 最小化主编负担的原则
调查员完成“史料→主张→正文→时间→空间→程序”的6级核查，交出通过项目与逐项阻塞证据。编辑6只需审查阻塞高风险主张及重大故事结构，主编最后判断公众发表、疆域及实站部署。**程序绿灯不是史学绿灯，研究档案合并不是网站上线**。

## 特别纠偏
- 英格兰银行贷款£1.2m、银行资本认购、王室债务、公司营业额不能汇总成殖民掠夺收益。
- 银行部分创设商人涉奴役贸易有官方研究依据，但不能代替逐投资人资本来源和财务去向审计。
- 贸易法授权、强制运输提案、船舶港口到达和亚洲实际统治范围必须分别证实。
- 不用1699年强行截断ARC长期进程；1698只表明这**两篇R08研究稿**目前记述到的最后具体事件年。
- 不把读者长文缺漏藏在技术上合法JSON里：当前两篇仍为`draft_research_only`，研究完整性改善不等于通过独立史学编辑。
