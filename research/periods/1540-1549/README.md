## 本期的实质性疆域变化

- **法国布洛涅**：1544年9月13日英军攻取布洛涅城后建立军驻、定居和土地重分配制度，英方控制延续至1549年末；1550年交还法国留给下一期。以现代旧城堡地标画实际控制 **Point**，周边用**800米纯示意虚线圈**（屏幕可读性尺寸，不是英王据地实测面积），不能以圈代替当时Boulonnais边界。
- **法国两处外围英军炮台**：Ambleteuse城堡1546年4月开工、1549年8月25日遭法军攻陷；Mont Lambert／Boulemberg炮台1546年5月开工、1549年法军进攻时英军撤离。两者均应在1549年末消失，**布洛涅城市英占仍延续至1550年**。现代村镇地标和示意虚线圆均不是古代要塞实测占地。
- **苏格兰是独立王国**。英军1547年控制Broughty Castle、Inchcolm和Eyemouth；1548年因奇科姆英军3月撤退、Haddington与Lauder成为要塞、英军取得Hailes Castle；1549年Haddington撤军。每个据点独立按年份显示，**不能把东洛锡安或整个苏格兰填橙色**。
- **新增的两处已核军事据点**：洛赫马本城堡1544年被英军占领、1545年由苏格兰收复；东洛锡安Dunglass的英军山岗营垒于1548—1549年用于哈丁顿驻防。均采用官方遗产遗址Point，Dunglass营垒实址在庄园宅邸以西，现代遗产区地理中心不是1548年营墙。
- **本次深挖补充**：Hume Castle 1547年9月22日英军占领，1548年12月苏格兰收复；Tour d'Ordre旧灯塔英军炮台1544年开始、Forthill与布劳蒂不同的英军炮台1548年建立。法国Outreau从1545年起的炮台属于**法国反攻设施**，单独蓝色图层。根西岛作为前一期已存在的特殊王室属地Point跨年继承。爱尔兰1542年Tyrone封号、1543年Thomond授爵与1546年英军进入盖尔中部需分名义臣服和实际军驻。
- **Hailes记录必须谨慎**：只确认1548年军驻；1549年既无证实撤军，也未确认继续占据，台账保留为`uncertain_continuity`，不把它冒充已结束或持续的已核实实色控制。
- **爱尔兰**：1541王室称号变动（官方现代法规引用《Crown of Ireland Act 1542 c.1》），1543年本地领主授予伯爵头衔。英王的法律主张不等于对整座爱尔兰岛实行一致军事、税收和司法控制。
- **加来、吉讷及其他海岛**：保留上一时期的7处具名地理身份，外加独立苏格兰整体政治关系。上一时期的轮廓原样延用并标不精确；威尔士1535/36内部法律改革现代参考范围继续保留，不算新征服。

## 数据史料与版权口径

**无任何获验证的16世纪边疆实测Polygon。** 继承的Calais Pale/爱尔兰Pale是不精确旧地名包络，五岛形状为现代海岸线参考，威尔士为现代法律地理参考。新添加的10个透明虚线圆，只是帮助读者找得到布洛涅/英军苏格兰堡垒，不是历史据地面积，更不能计算平方公里。旧现代海岛GeoJSON适用项目既有GPL-3.0-or-later来源与许可提示。原历史军事测绘例如National Library Scotland英式棱堡档案和British Library Cotton图仅作为追索对象，**没有复制或临摹受限制地图**。

史料中，剑桥大学出版社Murphy 2019 Boulogne专著提供重要殖民统治概览，但原著全文受访问限制，**此次阅读的是开放的章节摘要**。苏格兰军驻/撤离优先使用Historic Environment Scotland官方史料说明。TNA 1545 £119,581是官方页面转述的史学估值，**不是法国殖民地利润或一手原账核实金额**。
