# 爱英TV | 实际控制地区证据库：接力入口
信息搜集人1号 · 基础批次 2026-10-11

## 此目录是什么
用于研究 **英格兰／苏格兰／大不列颠／联合王国在何时、何地、以哪种机制实际控制土地** 的共同资料底座。它刻意将原始证据、主权宣称、有效行政与财富归属分开。不是现成的全球殖民控制多边形，也不是可直接上图的历史数据库。

## 新同事阅读顺序（最多三步）
1. **`SOURCE_REGISTRY.json`** — 11个按优先度编码的权威机构来源；含原始网址、档案号、证据用途、限制、访问方式、许可待核状态。先查目录，避免每个对话从零搜资料。
2. **`CONTROL_METHODOLOGY.md`** — 什么算实际治理；何时必须留空／用虚线；如何区分王室、公司、地方政府、驻军，如何设置审核门槛。
3. **`PILOT_CONTROL_CASES.json`** — 3个试点：1490年代爱尔兰、1607詹姆斯敦、1650年代爱尔兰土地重分配。**所有试点均未获准输出殖民控制polygon。**

## 对多位研究同事的分工建议
- **A：早期爱尔兰与英格兰本土权力范围** — 1490—1600，查Pale、地方政府、都铎扩张，先补可靠历史参考书和地图。
- **B：早期海外定居与英属殖民行政** — 1570—1782，按单个据点和条约而非今天的国家划界，依 CO 1/5、Colonial State Papers。
- **C：后期各类英国殖民地/保护国/托管地区** — 1782之后，依 CO/DO/FCO、条约和CO 700等地图；核对CShapes是否真的适用于个别地区。
- **D：英国在南亚的公司及王室统治** — 1600—1947，先查I​OR/A法律授权，再查地方行政实证与IOR/L/E财政口径。
- **E：空间资料与许可证审核** — 对历史地图逐幅记录年代、测图性质、使用许可、地理配准误差；禁止凭图像表面漂亮就判定真实版图。

## 接力交付标准
每位研究员独立 `research/control-<region>-<era>` 分支；每批至少交来源索引（ID稳定不重复）、控制阶段事实条目、史料原始位置/页码、可审计的边界来源、区域问题清单、`PROGRESS.md` 和 Git 提交SHA；正式纳入 `main` 由维护者审稿及转档。
史料不足时可以保留 `polygon: null` 的有价值结论，**不得为了地图好看而画空想疆界**。
