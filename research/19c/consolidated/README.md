# 爱英TV｜十九世纪殖民史研究交接

本卷以 1800–1899 年为主。A、B、C 三组的 273 个原案经复审，245 案纳入 59 个专题、150 个章节。314 个导读节点用于编审，详细年表保留 1,980 条记录，连同 1,520 条史料、数字口径及 1,317 条地图线索一并归档。

## 关联主键

- 本目录以 `19c/consolidated` 为专题命名空间，`T01` 等专题号只在本目录内使用。章节号形如 `T03.2`，与年表的 `章节号` 连接。
- `事件编号` 沿用研究原号。已有地图号见 `既有事件ID`，正式导入前与当前图层核对主体、地点和日期。
- 年表中的 `可对齐史料编号` 可有多个，用 `、` 分隔。每个编号前加 `原案号` 首字母和斜杠，即为史料表的 `引用键`。例 `A03-S01` 对应 `A/A03-S01`，`C` 组公共史料同理。
- 电子表格和脚本读取 CSV 时采用 `UTF-8 with BOM`。外部档案链接、卷号、原统计范围及分母按资料原字段保存。
- [归档清单](manifest.json)提供文件角色、条数和上游版本指纹。更新本卷后用 `python3 research/19c/consolidated/verify.py` 核对联接、文件路径、研究范围和出处。

## 使用边界

本卷交接到研究目录，地图发表另走主编核史、制图和审查。先区分条约权利、实际控制、驻军、人口转运和军事行动。有据但边缘未定的地区范围用虚线。各十年以史实核对延续、转移、结束及不确定事项，空坐标由后续考证。参见[项目制图标准](../../../docs/HISTORICAL_SPATIAL_NARRATIVE_STANDARD.md)。

28 个完整原案与另 15 条零散记录移出正文目录，合计 114 条年表记录。分章年表保留仍有用的前情、后记和跨卷互证。底稿保留原来的措辞、编号和不同意见，混合原卷以分章分配为准。

来源版本为编审交付 `19C-editorial-dossiers.zip` 和上游总包 `19C-research.zip`，文件大小与 SHA-256 见[归档清单](manifest.json)。大型 PDF 和馆藏扫描件沿用上游总包。仓库提供公开来源链接、调卷信息和原附件定位。
