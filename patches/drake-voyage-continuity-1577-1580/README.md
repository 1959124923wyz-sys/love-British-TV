## 问题与根因

原`data/atlas-1570-1579.json`中只有1578年莫查→瓦尔帕莱索→拉塞雷纳两条局部线和1579年卡亚俄→北加州→特尔纳特两条线，缺少1577—1578出航至麦哲伦海峡、1578末至1579年卡亚俄的连接。1579北加州到特尔纳特原来按±180°拆成两段；矩形全球地图在左右边缘有缝，移动到太平洋中心时可能无法显示一条连续路线。另外主地图按章节只选择当前`atlas.routes`，1580年回到下一章时1577—79航线会丢失。

本补丁**不改旧年代事件，也不重复复制旧私掠事件**，单独新增跨章航行数据并在地图显示时抑制对应四条旧方向线重复叠画。

## 年份与史实
- **1577年12月13日**普利茅斯出发：在地图上保持原有起航事件点；**不会提前显示直到1578年才抵达的佛得角**。
- **1578年**普利茅斯→佛得角→拉普拉塔河口参考海域→圣胡利安港→麦哲伦海峡→莫查岛→瓦尔帕莱索→拉塞雷纳。拉普拉塔河口、海峡内部为地理示意点，**非确定到访泊位**；拉塞雷纳攻击未遂，不代表英军成功占领。
- **1579年**拉塞雷纳→卡亚俄→瓦图尔科→北加利福尼亚海岸参考区→菲律宾群岛方向→**11月抵达特尔纳特**。北加州Point Reyes附近仍为争议着陆区；现代菲律宾代表点只表明10月望见群岛的方向，不是准确岛名或GPS登陆点。
- **1580年**特尔纳特→爪哇岛方向参考→好望角→**9月26日返回普利茅斯**。不会在1579年提前画出归程。
- **1581年后**不再叠加已经完成的1577–80航线；1585–86另一场德雷克加勒比远征数据原样保留。

## 制图限度
路线上**仅真实有据节点的顺序、年份得到史料支持**。两端之间为示意海段，无任何逐日船位原始GPS。渲染用中间坐标仅用于让线画得更连贯，不能升级为历史停靠点、英国所占港口或有证遭劫城市。全部`verified_English_territorial_control:false`、`actual_area_sqkm:null`。

矩形全球地图在180°经线本来就有左右两侧接缝，**不能在平面全世界视图里真正用一根线把画面左右边缘物理接起来**；此补丁让海线穿过太平洋地图中心时连续，并以相邻世界副本保证横跨左右边缘时两侧相互对应。显示越过海岸只代表已知端点直线示意，并不代表近岸全程实际航迹。
